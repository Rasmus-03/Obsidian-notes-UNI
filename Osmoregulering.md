# Osmoregulering

> [!tip] **Hovedprincip:** Osmoregulering er kroppens evne til at opretholde en **stabil osmolaritet** (saltholdighed) i kropsvæskerne på trods af varierende væskeindtag og -tab. Dette sker primært via nyrerne, ADH og tørstmekanismen.

## Definitioner

| Begreb | Forklaring |
|--------|-----------|
| **Osmolaritet** | Antal osmotisk aktive partikler pr. liter opløsning (mOsm/L) |
| **Osmoregulering** | Aktiv opretholdelse af vand- og saltbalancen |
| **Osmose** | Vanddiffusion gennem en semipermeabel membran |
| **Isotonisk** | Samme osmolaritet som blod (~300 mOsm) |
| **Hypotonisk** | Lavere osmolaritet end blod |
| **Hypertonisk** | Højere osmolaritet end blod |

## Menneskets osmoregulering

### Nøgletal
- **Plasma-osmolaritet (normal):** 280–295 mOsm/L
- **Urin-osmolaritet:** 50–1200 mOsm/L (afhængig af hydreringsstatus)
- **Daglig vandbalance:** ~2,5 L ind (drikke + mad + stofskifte) = ~2,5 L ud (urin + sved + respiration + afføring)

### Reguleringsmekanismer

| Mekanisme | Stimulus | Effekt |
|-----------|----------|--------|
| **Tørst** | Plasma-osmolaritet > 290 mOsm (osmoreceptorer i hypothalamus) | Drikker vand → fortynder blodet |
| **ADH** | ↑ Plasma-osmolaritet → ↑ ADH | ↑ Vandreabsorption i nyrerne → koncentreret urin |
| **RAAS** | ↓ Blodtryk/↓ Na⁺ | ↑ Na⁺-reabsorption → ↑ blodtryk |
| **ANP** | ↑ Blodtryk/↑ volumen | ↑ Na⁺-udskillelse → ↓ blodtryk |

## Sammenligning på tværs af arter

| Organisme | Miljø | Strategi |
|-----------|-------|----------|
| **Ferskvandsfisk** | Hypotonisk | Drikker ikke → fortyndet urin → aktiv saltoptagelse via gæller |
| **Havfisk** | Hypertonisk | Drikker havvand → koncentreret urin → aktiv saltudskillelse via gæller |
| **Amfibier** | Ferskvand/land | Hudpermeabel → fortyndet urin når i vand |
| **Ørkenpattedyr** | Ekstremt tørt | Ekstremt koncentreret urin (kænguru-rotte: op til 5000 mOsm) |
| **Mennesker** | Varierende | Urin: 50–1200 mOsm/L (afhængig af hydrering) |
