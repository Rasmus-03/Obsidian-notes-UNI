# Homeostase og Feedback-systemer

> **Kernekategori:** [[Homeostase]] er fundamentet for al fysiologi — kroppens evne til at opretholde et stabilt indre miljø trods ydre ændringer.

---

## 🔄 Negativ feedback — den vigtigste mekanisme

> [!INFO] **Eksamensspørgsmål: "Redegør for negativ feedback og giv tre eksempler"**

| Komponent | Funktion | Eksempel (blodsukker) |
|-----------|----------|----------------------|
| **Sensor** | Måler parameteren | β-celler i pancreas |
| **Integrator** | Sammenligner med setpunkt | Pancreas |
| **Effektor** | Udfører korrektion | Lever, muskel, fedtvæv |
| **Response** | Modvirker ændringen | Glukoseoptagelse ↑ |

**Sekvens:**
```
Stimulus (blodsukker ↑) → Sensor (β-celler) → Integrator (pancreas) 
→ Effektor (insulin ↑) → Response (glukoseoptagelse ↑)
→ Blodsukker ↓ → Negativ feedback på β-celler
```

> [!example] **3 eksamenseksempler på negativ feedback:**
> 1. **Blodsukkerregulering:** Insulin/glukagon — se [[Blodsukkerregulering]]
> 2. **Termoregulering:** Kulde → rysten, varme → sved — se [[Termoregulering]]
> 3. **Blodtryksregulering:** Baroreceptorer → RAAS-system — se [[Blodtryksregulering]]

## 🔁 Positiv feedback — sjælden, men vigtig

> [!WARNING] Positiv feedback forstærker ændringen → kan være farlig eller nødvendig

| Eksempel | Mekanisme | Resultat |
|----------|-----------|----------|
| **Fødsel** | Oxytocin → uterus-kontraktion → mere oxytocin | Barn født |
| **Amning** | Sugning → oxytocin → mælkeejektion | Baby mættes |
| **Blodkoagulation** | Trombinkaskade → flere enzymer aktiveres | Koagel dannes |
| **Aktionspotentiale** | Na⁺-indstrømning → depolarisering → flere Na⁺-kanaler | Signal formeres |

## 🌡️ Termoregulering pathway

> [!INFO] **Eksamensspørgsmål: "Hvordan opretholder mennesket konstant kropstemperatur?"**

```
Hypothalamus (termostat) ← sensorisk input fra hud & kerne
        │
        ├── Kulde-stress → Varmeproduktion:
        │   ├── Rysten (skeletmuskel)
        │   ├── Ikke-rystende termogenese (brunt fedt, UCP1)
        │   ├── Vasokonstriktion (hud)
        │   └── Adfærd (tøj, krumning)
        │
        └── Varme-stress → Varmetab:
            ├── Sved (fordampning)
            ├── Vasodilatation (hud)
            ├── Piloerektion (ubetydeligt hos mennesker)
            └── Adfærd (skygge, færre lag)
```

| Varmeproduktion | Varmetab |
|----------------|----------|
| Basal metabolisme (BMR) → se [[BMR]] | Stråling |
| Muskelaktivitet → rysten | Konvektion |
| Fordøjelse (termisk effekt af mad) | Konduktion |
| Ikke-rystende → UCP1 i brunt fedt | Fordampning (sved) |

> [!question] Eksamensspørgsmål
> **"Forklar hvordan negativ feedback styrer termoregulering hos mennesker"**
> *Svar: Hypothalamus fungerer som termostat (setpunkt ~37°C). Hud- og kernereceptorer sender signaler. Ved kulde: hypothalamus aktiverer rysten, vasokonstriktion og brunt fedt. Ved varme: hypothalamus aktiverer svedproduktion og vasodilatation. Dette er negativ feedback fordi responsen modvirker stimulus.*

## 📐 Allometri og Kleibers lov

> [!INFO] Eksamen: "Hvorfor har små dyr højere metabolisk rate pr. kg end store?"

**Kleibers lov:** BMR ∝ M^(3/4) (hvor M = kropsmasse)

| Dyr | Masse (kg) | BMR (kcal/dag) | BMR/kg |
|-----|:----------:|:--------------:|:------:|
| Mus | 0,025 | 3 | 120 |
| Menneske | 70 | 1.800 | 26 |
| Elefant | 5.000 | 70.000 | 14 |

**Forklaringer:**
1. **Overfladeareal/volumen:** varmetab ∝ overflade, varmeproduktion ∝ volumen
2. **Fraktal geometri:** transport-systemer (blodkar, lunger) skalerer sub-lineært
3. **Metaboliske begrænsninger:** kapillær-netværkets effektivitet
