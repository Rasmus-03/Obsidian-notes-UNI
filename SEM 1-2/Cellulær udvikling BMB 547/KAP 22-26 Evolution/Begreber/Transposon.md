# Transposon

> [!INFO] **Definition**
> **Transposoner** (hoppende gener) er **DNA-sekvenser** der kan **flytte sig** (transponere) til nye positioner i genomet. De findes i stort set alle organismer og udgør en betydelig del af genomet (menneske: ~45%).

> **Kilde:** Campbell Biology (12. udgave) – Kapitel 21, s. 437-441

---

## Typer

| Type | Mekanisme | Eksempel | Genomandel (menneske) |
|------|-----------|----------|:---------------------:|
| **DNA-transposoner** | Cut-and-paste (enzym) | Ac/Ds (majs) | ~3% |
| **LTR-retrotransposoner** | Copy-and-paste (via RNA) | Endogene retrovirus (ERV) | ~8% |
| **Non-LTR retrotransposoner** | Copy-and-paste (via RNA) | LINE'er, SINE'er | ~34% |

## Retrotransposoner (vigtigste hos pattedyr)

### LINE'er (Long Interspersed Nuclear Elements)
- **Længde**: ~6.000 bp
- **Autonom**: Koder selv for transpositionsmaskineri (ORF1p, ORF2p)
- **Menneske**: ~20% af genomet (L1-familien)
- **Aktiv**: Stadig aktive hos mennesker (nye insertioner kan give sygdom)

### SINE'er (Short Interspersed Nuclear Elements)
- **Længde**: ~300 bp
- **Ikke-autonom**: Bruger LINE-maskineri til transposition
- **Menneske**: ~13% af genomet (Alu-elementer — ~1 million kopier!)
- **Primatspecifik**: Alu findes kun hos primater

## Effekter på genomet

| Effekt | Beskrivelse | Eksempel |
|--------|-------------|----------|
| **Mutation** | Insertion → gen-disruption | Hæmofili A (faktor VIII) |
| **Gen-duplikation** | Transposon-medieret | Retroposition → processerede pseudogener |
| **Genregulering** | Nye promotorer/enhancere | Alu → alternativ splejsning |
| **Genom-størrelse** | Tilføjer DNA | C-value paradox (delvis) |
| **Evolution** | Genomisk plasticitet | Eksaptation → nye gener |

## McClintocks opdagelse
- **Barbara McClintock** (Nobel 1983) opdagede transposoner i **majs** (1940'erne)
- Ac/Ds-systemet → farvevariation i majskorn
- Først mødt med skepsis → nu anerkendt som fundamental genomisk mekanisme

## Evolutionær betydning
- **Horisontal genoverførsel**: Transposoner kan spredes mellem arter (via vira?)
- **Genomisk innovation**: Transposonsekvenser kan "tæmmes" → blive til gener
- **RAG1/RAG2** → V(D)J-rekombination (adaptivt immunforsvar) → stammer fra transposon!
- **Telomerase** → beslægtet med retrotransposon-revers transkriptase

## Eksamensspørgsmål
1. *Hvad er et transposon?* — DNA-sekvens der kan flytte sig i genomet ("hoppende gen")
2. *Hvad er forskellen på DNA-transposoner og retrotransposoner?* — DNA: cut-and-paste; Retro: copy-and-paste via RNA
3. *Hvor meget af menneskets genom består af transposoner?* — ~45% (heraf ~34% retrotransposoner)
4. *Hvordan kan transposoner drive evolution?* — Skaber mutationer, duplikationer, regulatorisk variation; kan blive til nye gener
