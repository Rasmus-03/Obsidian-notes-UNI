# Genflow (genstrøm)

> [!INFO] **Definition**
> **Genflow** (gene flow, genstrøm) er overførsel af **alleler mellem populationer** via migration af individer eller bevægelse af gameter. Genflow modvirker genetisk differentiering mellem populationer og kan **introducere eller fjerne** genetisk variation.

> **Kilde:** Campbell Biology (12. udgave) – Kapitel 23, s. 478-480

---

## Mekanismer
1. **Migration** → dyr flytter sig til ny population og formerer sig
2. **Pollen-spredning** → planter: pollen flytter med vind/insekter
3. **Frø-spredning** → frø spredes til nye områder
4. **Gameter** → sæd fra havdyr spredes med havstrømme
5. **Horisontal genoverførsel** → bakterier: plasmidoverførsel

## Effekter på populationer

| Effekt | Beskrivelse | Eksempel |
|--------|-------------|----------|
| **Homogenisering** | Populationer bliver mere ens → mindre differentiering | Mennesker: global migration reducerer genetiske forskelle |
| **Introduktion af nye alleler** | Øger genetisk variation | Pollen fra GM-afgrøder → vilde slægtninge |
| **Modvirker speciation** | Genflow holder populationer sammen → forhindrer reproduktiv isolation | Ringearter: genflow gennem ringen |
| **Genredning (gene rescue)** | Indførsel af nye alleler redder truet population | Florida-panter: indførsel af Texas-panter øgede variation |

## Genflow vs. genetisk drift

| Træk | Genflow | Genetisk drift |
|------|:-------:|:--------------:|
| **Mekanisme** | Migration af individer/gameter | Tilfældig overlevelse/reproduktion |
| **Effekt på variation** | Kan øge eller reducere | Reducerer (især i små populationer) |
| **Retning** | Retningsbestemt (ind/ud) | Tilfældig |
| **Modvirker speciation** | Ja — holder populationer ens | Nej — fremmer differentiering |

## F-Statistik (Wright's F_ST)
- **F_ST** måler graden af genetisk differentiering mellem populationer
- **Lav F_ST** (< 0,05) → meget genflow, populationer er ens
- **Høj F_ST** (> 0,25) → lidt genflow, populationer er forskellige
- **F_ST = 1** → populationerne er fikseret for forskellige alleler

## Eksempler
- **Mennesker**: F_ST ≈ 0,15 på verdensplan — nok genflow til at vi er én art
- **Galápagos-finker**: Begrænset genflow mellem øer → adaptiv radiation
- **Bakterier**: Ekstremt genflow via HGT → pan-genom
- **Plante-populationer**: Pollenspredning kan nå flere kilometer

## Eksamensspørgsmål
1. *Hvad er genflow?* — Overførsel af alleler mellem populationer via migration
2. *Hvordan modvirker genflow speciation?* — Holder populationer genetisk ens → forhindrer reproduktiv isolation
3. *Hvad måler F_ST?* — Graden af genetisk differentiering mellem populationer (0=ens, 1=helt forskellige)
4. *Hvorfor er genflow vigtigt i bevaringsbiologi?* — Kan genoprette genetisk variation i truede populationer (genredning)
