# Biological Species Concept

> [!INFO] **Definition**
> **Biological Species Concept (BSC)** definerer en art som **en gruppe af naturligt forekommende populationer, der kan krydse sig og producere frugtbart afkom**, og som er **reproduktivt isoleret** fra andre sådanne grupper. Denne definition blev formuleret af **Ernst Mayr** (1942).

> **Kilde:** Campbell Biology (12. udgave) – Kapitel 24, s. 502-505

---

## Hovedprincipper
1. **Reproduktiv kompatibilitet** → medlemmer af samme art kan parre sig
2. **Frugtbart afkom** → afkommet skal også kunne reproducere
3. **Reproduktiv isolation** → ingen (eller begrænset) genudveksling med andre arter

## Styrker ved BSC
- ✅ Klar **operational definition** — man kan teste om to populationer tilhører samme art
- ✅ Fokuserer på **reproduktion**, som er evolutionært relevant
- ✅ Velegnet til **dyr med kønnet formering**
- ✅ God til at identificere **sympatriske arter** (der lever samme sted)

## Begrænsninger/svagheder

| Problem | Eksempel |
|---------|----------|
| **Aseksuelle organismer** | Bakterier — formerer sig ukønnet, kan ikke testes for krydsning |
| **Fossiler** | Kan ikke teste reproduktion → må bruge morfologi |
| **Hybridzoner** | Nogle arter kan hybridisere (f.eks. grå + sort ræv) |
| **Allopatriske populationer** | Mødes aldrig i naturen — kan de? |
| **Ringearter** | A kan krydse med B, B med C, men A kan IKKE krydse med C |
| **Planter** | Hybridisering meget almindelig → utydelige artsgrænser |

## Alternative artskoncepter

| Koncept | Definition | Anvendelse |
|---------|-----------|------------|
| **Morphological Species Concept** | Baseret på fysiske træk (morfologi) | Fossiler, aseksuelle |
| **Phylogenetic Species Concept** | Mindste monofyletiske gruppe i fylogeni | Universel |
| **Ecological Species Concept** | Baseret på niche / miljøtilpasning | Økologiske studier |
| **Genetic Species Concept** | Baseret på DNA-sekvensforskelle | Molekylær taksonomi |

## Eksempler på BSC i praksis
- **Hund + ræv** → forskellige arter (ingen frugtbare hybrider)
- **Hund + ulv** → samme art? (nyere forskning: ja, Canis lupus — de kan producere frugtbart afkom)
- **Nøgen rotte + almindelig rotte** → forskellige arter (reproduktiv isolation)
- **Løve + tiger** → forskellige arter (liger/toner er sterile)

## Eksamensspørgsmål
1. *Hvad er Biological Species Concept?* — En art = gruppe af populationer der kan krydses og give frugtbart afkom
2. *Hvorfor duer BSC ikke for bakterier?* — Aseksuelle — ingen krydsning, så konceptet er meningsløst
3. *Hvad er en ringeart?* — Populationer i en ring omkring en barriere; enderne kan ikke krydses, men der er genflow gennem ringen
4. *Hvorfor bruger man Morphological Species Concept til fossiler?* — Fordi man ikke kan teste reproduktion hos uddøde organismer
