# Arytmier

**Nøgleord:** Arytmi, dysrytmi, atrieflimren, ventrikelflimren, takykardi, bradykardi, ekstrasystole, AV-blok, EKG

**Kort beskrivelse:**  
**Arytmier** er uregelmæssigheder i hjerterytmen. De opstår ved fejl i impulsdannelse (SA-knude) eller impulsledning (AV-knude, His-Purkinje).  

**Typer:**  
- **Takykardi** → >100 slag/min (sinustakykardi, atrieflimren, ventrikeltakykardi)  
- **Bradykardi** → <60 slag/min (sinusbradykardi, AV-blok)  
- **Atrieflimren** → kaotisk elektrisk aktivitet i atrierne, risiko for blodpropper  
- **Ventrikelflimren** → kaotisk ventrikelaktivitet → hjertestop (kræver defibrillering)  
- **AV-blok** → forsinket eller blokeret ledning mellem atrier og ventrikler (grad 1-3)  
- **Ekstrasystole** → for tidligt slag (ofte ufarligt)  

Behandling: β-blokkere, Ca²⁺-kanalblokkere, antiarytmika, pacemaker, ICD (implanterbar defibrillator).

**Relationer:** EKG, SA-knuden, AV-knuden, β-blokker, Depolarisering, Hjerteinsufficiens, Hjertefrekvens
