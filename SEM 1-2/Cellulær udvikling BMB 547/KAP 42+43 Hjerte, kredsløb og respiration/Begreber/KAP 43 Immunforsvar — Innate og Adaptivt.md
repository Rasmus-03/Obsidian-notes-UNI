# Immunforsvaret — Innate og Adaptivt

> **Kerne-pathway:** Immunforsvaret består af to sammenkoblede systemer, der samarbejder om at eliminere patogener.

---

## 📋 Overblik — Forsvarets 3 linjer

| Linje | System | Tidsramme | Specificitet | Hukommelse |
|:-----:|--------|:---------:|:------------:|:----------:|
| **1.** | Fysiske/kemiske barrierer | Øjeblikkelig | Bred | Nej |
| **2.** | [[Innate immunsystem]] | Minutter-timer | Bred (PAMP/PRR) | Nej |
| **3.** | [[Adaptivt immunsystem]] | Dage | Meget specifik | Ja |

---

## 🛡️ Innate immunsystem — hurtig respons

> [!INFO] Genkender **PAMP** (Pathogen-Associated Molecular Patterns) via **PRR** (Pattern Recognition Receptors, f.eks. Toll-like receptors)

| Komponent | Funktion | Mekanisme |
|-----------|----------|-----------|
| **Neutrofile** | Fagocytose | Første ankomst (timer) |
| **Makrofager** | Fagocytose + antigenpræsentation | Æder og præsenterer |
| **NK-celler** | Dræber virus-inficerede celler | Perforin/granzymer → apoptosis |
| **Dendritter** | Antigenpræsentation → bro til adaptivt | Modne → lymfeknuder |
| **Komplement** | Opsonisering, lyse, inflammation | Proteinkaskade |
| **Inflammation** | Rekrutterer immunceller | Histamin, cytokiner, vasodilatation |

**Inflammations-pathway:**
```
Vævsskade/infektion → Mastceller frigiver histamin
    → Vasodilatation (rødme, varme)
    → Øget kapillærpermeabilitet (hævelse)
    → Kemotaxis (neutrofile/makrofager rekrutteres)
    → Fagocytose + cytokin-frigivelse
    → Kronisk/akutfase-respons
```

## 🎯 Adaptivt immunsystem — specifikt med hukommelse

> [!INFO] **Eksamensspørgsmål: "Forklar forskellen på humoral og celle-medieret immunitet"**

### Humoral immunitet (B-celler → antistoffer)

```
Patogen → B-celle (genkender antigen via BCR)
    → Aktiveres (med TH2-hjælp)
    → Prolifererer → Plasmaceller (antistof-sekretion)
                      → Memory B-celler (langtidshukommelse)
```

**Antistof-klasser:**

| Klasse | Funktion | Lokation |
|--------|----------|----------|
| **IgM** | Primært respons, komplement-aktivering | Blod (pentamer) |
| **IgG** | Sekundært respons, opsonisering, neutralisering | Blod, væv (monomer) |
| **IgA** | Mukosal immunitet | Slimhinder, tårer, modermælk |
| **IgE** | Parasitter, allergi | Mastceller, basofile |
| **IgD** | B-celle-receptor | B-celle-overflade |

### Celle-medieret immunitet (T-celler)

```
APC (dendrit) → MHC-II → TCR på CD4⁺ T-celle
    → TH1 → Aktiverer makrofager (intracellulære patogener)
    → TH2 → Hjælper B-celler
    → TH17 → Neutrofile rekrutteres
    → Treg → Immunsuppression

APC (enhver celle) → MHC-I → TCR på CD8⁺ T-celle
    → Cytotoksisk T-celle → Perforin/granzymer → apoptosis
```

## 🔗 Broen: Antigenpræsentation

> [!INFO] **Eksamensspørgsmål: "Forklar MHC-klasser og antigenpræsentation"**

| MHC-klasse | Ekspression | Præsenterer | Aktiverer |
|:----------:|:-----------:|:-----------:|:---------:|
| **MHC-I** | Alle somatiske celler | Cytosolsk antigen (virus) | CD8⁺ T-celler |
| **MHC-II** | Professionelle APC (dendritter, makrofager, B-celler) | Ekstracellulært antigen | CD4⁺ T-celler |

**Cross-præsentation:** Dendritter kan præsentere ekstern antigen på MHC-I → aktiverer CD8⁺ mod virus der ikke inficerer dendritter.

## 🧪 ELISA — diagnostisk værktøj

> [!INFO] Enzym-linked immunosorbent assay — påviser antistoffer eller antigen

**Indirekte ELISA (påviser antistoffer):**
```
1. Antigen coatet på plade
2. Patient-serum tilsættes (antistof binder)
3. Enzym-koblet sekundært antistof tilsættes
4. Substrat tilsættes → farvereaktion = positiv
```
