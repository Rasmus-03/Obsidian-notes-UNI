# Hjertecyklus og Elektrisk Ledning

> **Kerne-pathway:** Hjertet pumper blod gennem en koordineret sekvens af elektrisk aktivering → mekanisk kontraktion. Denne note binder [[Hjertecyklus]], [[SA-knuden]], [[AV-knuden]], [[EKG]], [[Depolarisering]] og [[Hjertefrekvens]] sammen.

---

## ⚡ Elektrisk ledningspathway

> [!INFO] **Eksamensspørgsmål: "Redegør for den elektriske ledning i hjertet"**

```
SA-knuden (pacemaker, ~70/min) — højre atrium
    │
    ├── → Atriel muskel (gap junctions) — depolarisering spredes
    │       → Atrier kontraherer (atriel systole)
    │
    ├── → AV-knuden (forsinkelse ~0.1 s) — mellem atrier/ventrikler
    │       → Tillader ventrikler at fyldes færdig
    │
    ├── → His' bundt — septum
    │
    ├── → Højre og venstre gren — mod ventriklerne
    │
    └── → Purkinje-fibre — ventrikelmuskulatur
            → Ventrikler kontraherer (ventrikulær systole)
```

**Hvorfor AV-forsinkelse?** Uden den ville atrier og ventrikler kontrahere samtidigt → ventriklerne ville ikke fyldes ordentligt → 20-30% mindre slagvolumen.

## 🔄 Hjertecyklus — mekanisk pathway

| Fase | Varighed | EKG | Hvad sker der? | Hjertelyd |
|------|:--------:|:---:|----------------|:---------:|
| **1. Atriel systole** | 0,1 s | P-bølge | Atrier kontraherer → sidste 20% af ventrikelfyldning | - |
| **2. Isovolumetrisk kontraktion** | 0,05 s | QRS-kompleks | Ventrikler kontraherer → tryk ↑ → AV-klapper lukkes | S1 ("lub") |
| **3. Ejektion** | 0,25 s | ST-segment | Semilunarklapper åbner → blod til aorta/pulmonalis | - |
| **4. Isovolumetrisk relaxation** | 0,05 s | T-bølge | Ventrikler relaxerer → semilunarklapper lukkes | S2 ("dub") |
| **5. Diastole (fyldning)** | 0,4 s | - | AV-klapper åbner → passiv fyldning | - |

> [!question] Eksamensspørgsmål
> **"Forklar sammenhængen mellem EKG og hjertecyklus"**
> *Svar: P-bølge = atriel depolarisering (atriel systole). QRS-kompleks = ventrikulær depolarisering → ventrikulær systole (isovolumetrisk kontraktion + ejektion). T-bølge = ventrikulær repolarisering → ventrikulær diastole. S1 = AV-klapper lukkes (start systole). S2 = semilunarklapper lukkes (start diastole).*

## 🩸 Blodtryk og regulering

> [!INFO] **Eksamensspørgsmål: "Hvordan reguleres blodtrykket?"**

**Blodtryk = Cardiac output × Perifer modstand**
- CO = Slagvolumen × Hjertefrekvens
- Perifer modstand = diameter på arterioler (vasokonstriktion/dilatation)

**Korttidsregulering (baroreceptor-refleks):**
```
Blodtryk ↑ → Baroreceptorer (carotis, aorta) → Medulla oblongata
    → Parasympatikus ↑ (hjertefrekvens ↓) + Sympatikus ↓ (vasodilatation)
    → Blodtryk normaliseres
```

**Langtidsregulering (RAAS):** Se [[Blodtryksregulering]] og [[Aldosteron]]

## 🫁 Fosterets cirkulation

> [!INFO] Fosteret bruger ikke lungerne → særlige strukturer omgår lungekredsløbet

| Struktur | Funktion | Efter fødslen |
|----------|----------|--------------|
| **Foramen ovale** | Højre → venstre atrium (omgår lunger) | Lukkes → fossa ovalis |
| **Ductus arteriosus** | A. pulmonalis → aorta (omgår lunger) | Lukkes → ligamentum arteriosum |
| **Ductus venosus** | Navlevene → v. cava (omgår lever) | Lukkes → ligamentum venosum |
| **Placenta (moder)** | Ilt/næring → navlevene | Stødes ud |
