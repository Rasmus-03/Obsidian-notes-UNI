# Blod og Gasudveksling

> **Kerne-pathway:** Ilt og CO₂ transporteres via blodet mellem lunger og væv — en tæt kobling mellem respiration, cirkulation og syre-base-balance.

---

## 🩸 Blodets sammensætning

| Komponent | Andel | Funktion |
|-----------|:-----:|----------|
| **Plasma** | 55% | Vand, proteiner (albumin, globuliner, fibrinogen), ioner, næring |
| **Erytrocytter** | 45% (hæmatokrit) | O₂-transport via [[Hæmoglobin]] |
| **Leukocytter** | <1% | Immunforsvar — se [[Immunforsvaret]] |
| **Trombocytter** | <1% | Koagulation |

> [!INFO] **Hæmatokrit = procentdel af blodvolumen udgjort af røde blodlegemer** (norm: ~45% mænd, ~40% kvinder)

## 🔵 Hæmoglobin og O₂-dissociationskurven

> [!INFO] **Eksamensspørgsmål: "Forklar O₂-dissociationskurven og hvad der påvirker den"**

```
        ┌── 100% ──── Mættet (lunger: PO₂ ~100 mmHg)
        │       /
        │    /   ← Plateau: sikrer mætning selv ved lav PO₂
        │  /
        │/  ← Stejl del: O₂ frigives let i væv (PO₂ ~40 mmHg)
        └─── 0% ────
```

**Bohr-effekten** (højre-forskydning af kurven → O₂ frigives lettere):
| Faktor | Effekt på O₂-afgivelse | Mekanisme |
|--------|:----------------------:|-----------|
| ↓ pH (H⁺ ↑) | ↑ (højreforskydning) | H⁺ stabiliserer deoxy-Hb → lav affinitet |
| ↑ CO₂ | ↑ (højreforskydning) | CO₂ → HCO₃⁻ + H⁺ (via carbonic anhydrase) |
| ↑ Temperatur | ↑ (højreforskydning) | Øger Hb-konformationsændring |
| **2,3-BPG** | ↑ (højreforskydning) | Binder til deoxy-Hb → stabiliserer lav-affinitetsform |

> [!example] **Hvorfor er det smart?** I væv med høj metabolisme (arbejdende muskel): pH lav, CO₂ høj, temp høj → O₂ frigives lettere → præcis hvor der er mest brug for det!

## Haldane-effekten — CO₂-transport

> CO₂-transport er tæt koblet til O₂-status

| CO₂-transportform | Andel | Forklaring |
|-------------------|:-----:|-----------|
| **HCO₃⁻ (bicarbonat)** | 70% | CO₂ + H₂O → H₂CO₃ → H⁺ + HCO₃⁻ (via carbonic anhydrase) |
| **Opløst CO₂** | 10% | Fysisk opløst i plasma |
| **Carbamino-Hb** | 20% | CO₂ bundet til hæmoglobin (især deoxy-Hb) |

**Haldane-effekten:** Deoxy-Hb binder mere CO₂ og H⁺ end oxy-Hb → i væv (lav O₂) optages mere CO₂, i lunger (høj O₂) frigives CO₂.

> [!question] Eksamensspørgsmål
> **"Forklar sammenhængen mellem Bohr-effekten og Haldane-effekten"**
> *Svar: Bohr = H⁺/CO₂ ↓ Hb's O₂-affinitet → O₂ frigives i væv. Haldane = deoxy-Hb binder mere CO₂/H⁺ → CO₂ transporteres til lunger. Tilsammen kobler de O₂- og CO₂-transport: I væv → O₂ ud, CO₂ ind. I lunger → O₂ ind, CO₂ ud.*

## 🫁 Alveoler og gasudveksling

| Struktur | Funktion | Egenskab |
|----------|----------|----------|
| Alveoler | Gasudvekslingsoverflade | Stor (100 m²), tynd (0,2 μm) |
| Surfactant | Reducerer overfladespænding | Forhindrer alveole-kollaps |
| Kapillærer (omkring alveoler) | Tæt kontakt med luft | 1 lag endotelceller |

**Diffusion:** O₂ → alveole → kapillær (høj→lav PO₂). CO₂ → kapillær → alveole (høj→lav PCO₂).
