# Hjerte og Respiration — Gasudveksling og Kontrol

> **Kerne-pathway:** Respirationen kobler ekstern (lunger) og intern (væv) gasudveksling gennem ventilation, perfusion og diffusion.

---

## 🫁 Lungeanatomi og Ventilation

| Struktur | Funktion |
|----------|----------|
| **Trachea** | Luftrør → bronkier → bronkioler → alveoler |
| **Alveoler** | Gasudveksling (100 m² overflade) |
| **Surfactant** | Reducerer overfladespænding → forhindrer kollaps |
| **Pleura** | Forsegler lungerne til thoraxvæggen |

**Ventilation:**
```
Inspiration: Diafragma + interkostalmuskler → thoraxvolumen ↑ → tryk ↓ → luft ind
Ekspiration: Passiv (elastisk recoil) → tryk ↑ → luft ud
    (Ved træning: interkostalmuskler + abdominalmuskler aktive)
```

**Lungevolumener:**
| Volumen | Værdi (ca.) | Definition |
|:-------:|:-----------:|:----------:|
| TV | 500 mL | Tidalvolumen (normal vejrtrækning) |
| IRV | 3.000 mL | Inspiratorisk reservevolumen |
| ERV | 1.200 mL | Ekspiratorisk reservevolumen |
| RV | 1.200 mL | Residualvolumen (kan ikke udåndes) |
| **VC** | **4.600 mL** | **Vitalkapacitet (TV+IRV+ERV)** |
| **TLC** | **5.800 mL** | **Total lungekapacitet** |

## 🔵 Hæmoglobin og O₂-dissociationskurve

Se detaljer i [[KAP 42 Blod og Gasudveksling]] — her fokuserer vi på respiration:

**Bohr-effekt:** ↓ pH / ↑ CO₂ → kurven forskydes → O₂ frigives lettere i væv
**Haldane-effekt:** Deoxy-Hb binder CO₂ bedre → CO₂ transporteres til lunger

### Inotropi — kontraktilitet af hjertet

| Type | Effekt | Eksempel |
|:----:|:------:|:---------:|
| **Positiv inotropi** | Kontraktionskraft ↑ | Adrenalin, digitalis, Ca²⁺ |
| **Negativ inotropi** | Kontraktionskraft ↓ | β-blokkere, Ca²⁺-kanalblokkere |

## 🧠 Respirationskontrol

> [!INFO] **Eksamensspørgsmål: "Forklar hvordan respirationen styres"**

```
Kemoreceptorer (O₂ ↓, CO₂ ↑, pH ↓)
    │
    ├── Perifere (carotis + aortaknogler) → O₂ ↓ først ved <60 mmHg
    ├── Centrale (medulla oblongata) → CO₂ ↑ / pH ↓ (vigtigst!)
    │
    ├── Medulla oblongata: præ-Bötzinger-kompleks (rytmegenerator)
    │       → Inspiratoriske + ekspiratoriske neuroner
    │
    └── → Diafragma (n. phrenicus) + interkostalmuskler (intercostalnerver)
```

> [!QUESTION] Eksamensspørgsmål
> **"Hvorfor er CO₂ den vigtigste driver for respiration, ikke O₂?"**
> *Svar: Centrale kemoreceptorer (medulla) reagerer på CO₂/pH i CSF. Perifere (carotis) reagerer først på O₂ ved <60 mmHg — altså først ved svær hypoxi. Ved normal fysiologi → CO₂ er primær driver. Det er derfor KOL-patienter med kronisk CO₂-retention kan være O₂-afhængige.*
