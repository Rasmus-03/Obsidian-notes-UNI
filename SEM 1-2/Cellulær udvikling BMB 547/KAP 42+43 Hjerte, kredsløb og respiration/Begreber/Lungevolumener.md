# Lungevolumener

## Lungens statiske volumener

```
  ┌──────────────────────────────────────────────────┐
  │  Total Lungekapacitet (TLC) ~6000 mL             │
  │  ┌────────────────────────┬───────────────────┐  │
  │  │ Vitalkapacitet (VC)    │ Residualvolumen   │  │
  │  │      ~4800 mL          │    (RV) ~1200 mL  │  │
  │  │ ┌──────┬───────────┬───┤                   │  │
  │  │ │ TV   │ IRV       │   │                   │  │
  │  │ │ 500  │  3100     │ERV│                   │  │
  │  │ │      │           │   │                   │  │
  │  │ │      │           │1200                   │  │
  │  └─┴──────┴───────────┴───┴───────────────────┘  │
  └──────────────────────────────────────────────────┘
```

| Volumen | Forkortelse | Definition | Normal (mL) |
|---------|:----------:|-----------|:----------:|
| **Tidalvolumen** | TV | Normal indånding/udånding | ~500 |
| **Inspiratorisk reservevolumen** | IRV | Ekstra luft efter normal inspiration | ~3100 |
| **Eksspiratorisk reservevolumen** | ERV | Ekstra luft efter normal eksspiration | ~1200 |
| **Residualvolumen** | RV | Luft tilbage efter maksimal eksspiration | ~1200 |
| **Vitalkapacitet** | VC | IRV + TV + ERV = max eksspiration efter max inspiration | ~4800 |
| **Inspiratorisk kapacitet** | IC | TV + IRV | ~3600 |
| **Funktionel residualkapacitet** | FRC | ERV + RV (lungevolumen efter normal eksspiration) | ~2400 |
| **Total lungekapacitet** | TLC | VC + RV = alle volumener | ~6000 |

> **Bemærk**: RV og FRC kan **ikke** måles med simpel spirometri – bruges helium-udvaskning eller bodypletysmografi.

## Dynamiske volumener (spirometri)

### FEV₁ (Forced Expiratory Volume i 1 sekund)

- Volumen udåndet i første sekund ved maksimal kraft
- **Normal**: >80% af FVC (FEV₁/FVC > 0.8)
- **↓ FEV₁/FVC**: Obstruktiv lungesygdom

### FVC (Forced Vital Capacity)

- Maksimal volumen udåndet efter maksimal inspiration (kraftfuldt)

### FEV₁/FVC ratio

| Tilstand | FEV₁ | FVC | Ratio |
|----------|:---:|:---:|:----:|
| **Normal** | 4.0 L | 5.0 L | **0.80** |
| **Obstruktiv** (astma, KOL) | ↓↓ 1.5 L | → 4.0 L | **<0.70** |
| **Restriktiv** (fibrose) | ↓ 3.0 L | ↓↓ 3.5 L | **>0.85** |

### Peak Expiratory Flow (PEF)

- Maksimal flowhastighed under FVC-måling
- Normal: ~400-600 L/min (afhænger af køn, alder, højde)
- ↓ PEF → Astmaforværring

## Lungevolumener — værdier og variation

| Parameter | Mand (70 kg) | Kvinde (60 kg) |

| TV | 500 mL | 400 mL |
| IRV | 3100 mL | 1900 mL |
| ERV | 1200 mL | 800 mL |

| VC | 4800 mL | 3100 mL |
| TLC | 6000 mL | 4200 mL |
| FRC | 2400 mL | 1800 mL |

### Aldersbetingede ændringer

- **30 → 70 år**: VC ↓ ~25%, RV ↑ ~50%, TLC uændret
- Årsag: Tab af elastisk recoil + ↑ luftindfangning

## Dødrum

| Type | Definition | Volumen |
|------|-----------|:-------:|
| **Anatomisk dødrum** | Ledende luftveje (ingen gasudveksling) | ~150 mL |
| **Fysiologisk dødrum** | Anatomisk + alveoler uden perfusion | ~150-200 mL (stiger ved lungeemboli) |
| **Total ventilation** | TV × frekvens = 500 × 12 = 6 L/min | — |
| **Alveolær ventilation** | (TV − dødrum) × frekvens = (500-150) × 12 = 4.2 L/min | — |

## Kliniske målinger

### Spirometri — fortolkning

```
FVC = 4.0 L (normal ~5.0) → 80% af forventet
FEV₁ = 2.0 L (normal ~4.0) → 50% af forventet
FEV₁/FVC = 2.0/4.0 = 0.50 → OBSTRUKTIV (KOL)
```

### Bodypletysmografi

- Måler TLC, FRC, RV (ikke muligt med spirometri)
- Patient sidder i lukket kammer og puster mod modstand
- Basis: Boyles lov (P₁V₁ = P₂V₂)

### Diffusionskapacitet (DLCO)

- Måler CO-optagelse over alveole-kapillærmembranen
- **↓ DLCO**: Emfysem, fibrose, lungeemboli
- **↑ DLCO**: Astma, polycytæmi, lungeblødning
