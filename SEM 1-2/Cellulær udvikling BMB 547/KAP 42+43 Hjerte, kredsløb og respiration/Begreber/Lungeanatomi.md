# Lungeanatomi og ventilation

Åndedrætssystemet består af **ledende luftveje** (transport) og **respiratoriske strukturer** (gasudveksling).

## Anatomi

### Øvre luftveje
```
Næsehule
   ↓
Svælg (pharynx)
   ↓
Strubehoved (larynx) ← epiglottis (forhindrer aspiration)
```

### Nedre luftveje
```
Trachea (8-12 cm, 16-20 bruskringe)
   ↓
Hovedbronkier (højre: stejlere, bredere, kortere → aspiration hyppigere i højre)
   ↓
Lobarbronkier (3 i højre, 2 i venstre)
   ↓
Segmentbronkier (10 i højre, 8-9 i venstre)
   ↓
Bronchioli (ingen brusk, glat muskulatur)
   ↓
Terminale bronchioli (ledende zone → slutter her)
   ↓
Respiratoriske bronchioli (⇢ gasudveksling starter)
   ↓
Ductus alveolares
   ↓
Sacculi alveolares
   ↓
Alveoler (gasudveksling)
```

### Ledende zone vs. Respiratorisk zone

| Zone | Anatomi | Funktion |
|------|---------|----------|
| **Ledende** | Mund/næse → terminale bronchioli | Opvarmning, befugtning, filtrering (intet gasudveksling) |
| **Respiratorisk** | Resp. bronchioli → alveoler | Gasudveksling (O₂/CO₂) |

> **Anatomisk dødrum** = ledende zones volumen (~150 mL hos voksne)

### Alveolerne

- ~300 millioner alveoler pr. lunge
- **Overfladeareal**: ~70 m² (størrelsen af en tennisbane)
- **Vægtykkelse**: ~0.2-0.5 μm (ekstremt tynd)
- **Alveolær væg**: Type I-pneumocytter (95%, flade, gasudveksling) + Type II-pneumocytter (5%, producerer **surfactant**)
- **Surfactant**: Dipalmitoylfosfatidylcholin (DPPC) → reducerer overfladespænding → forhindrer alveolær kollaps

## Respiration (ventilation)

### Inspiration (aktiv)
1. **Diafragma** kontraheres → flader ud → ↓ tryk i thorax
2. **Ydre interkostalmuskler** kontraheres → ribben løftes → ↑ tværsnit
3. **Intrapleuraltryk** falder til ~-6 cmH₂O (fra -3 i hvile)
4. Luft strømmer ind (Boyle's lov: P↓ → V↑)

### Eksspiration (passiv i hvile)
1. Diafragma relaxeres → ↑ tryk
2. Elastisk recoil af lungerne
3. Luft strømmer ud
4. **Aktiv eksspiration** (under træning): Indre interkostalmuskler + abdominis-muskler

### Trykforhold

| Tryk | Definition | Hvileværdi |
|------|-----------|:----------:|
| **Intrapleuraltryk** (Ppl) | Tryk i pleuraspalten | -3 cmH₂O (eksspiration) til -6 cmH₂O (inspiration) |
| **Alveolærtryk** (Palv) | Tryk i alveolerne | 0 (mellem åndedrag) → -1 (inspiration) → +1 (eksspiration) |
| **Transpulmonalt tryk** | Palv − Ppl | 3 cmH₂O (ved FRC) |

### Lungecomplians

\[
C = \frac{\Delta V}{\Delta P}
\]

- **Normal**: ~0.2 L/cmH₂O
- **↓ complians** (stive lunger): Lungefibrose, ARDS
- **↑ complians** (elastiske tab): Emfysem

### Luftvejsresistens

\[
R = \frac{\Delta P}{\dot{V}}
\]

- Hoveddeterminant: **bronkiernes diameter** (R ∝ 1/r⁴, Poiseuilles lov)
- **Bronkokonstriktion**: Astma (↓ diameter → ↑ R)
- **Bronkodilatation**: β₂-agonister (salbutamol) → ↑ diameter → ↓ R
