# Blodtype

**Nøgleord:** AB0-systemet, Rh-systemet, A/B-antigener, RhD-antigen, anti-A/anti-B antistoffer, agglutination, transfusion, blodtypeforenelighed

**Kort beskrivelse:**  
**Blodtype** bestemmes af antigener på overfladen af røde blodlegemer.  

**AB0-systemet:**  
- Type A → A-antigen, anti-B antistof  
- Type B → B-antigen, anti-A antistof  
- Type AB → A- og B-antigen, ingen antistoffer (universel modtager)  
- Type 0 → ingen antigener, anti-A og anti-B antistof (universel donor)  

**Rh-systemet:**  
- Rh-positiv → har RhD-antigen (85% af befolkningen)  
- Rh-negativ → intet RhD-antigen  

*Transfusionsregler:* Modtagerens antistoffer må ikke genkende donorcellernes antigener → ellers agglutination (sammenklumpning) og hæmolyse.  

Rh-negativ mor med Rh-positivt barn kan udvikle anti-Rh antistoffer → risiko for **hæmolytisk sygdom hos nyfødte** (forebygges med anti-D immunglobulin).

**Relationer:** Blodets bestanddele, Hæmoglobin, Immunforsvar, Plasma
