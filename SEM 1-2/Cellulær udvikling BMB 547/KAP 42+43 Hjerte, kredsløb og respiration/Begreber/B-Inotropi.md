# Inotropi

**Nøgleord:** Inotropi, kontraktilitet, positiv inotropi, negativ inotropi, Ca²⁺, sympatikus, Ca²⁺-kanaler, hjertekraft

**Kort beskrivelse:**  
**Inotropi** handler om styrken af hjertets kontraktion (inos = fiber).  
- **Positiv inotropi** → kraftigere kontraktion (sympatikus via β₁-receptorer → øget Ca²⁺-influx → mere aktin-myosin-krydsbinding)  
- **Negativ inotropi** → svagere kontraktion (β-blokkere, Ca²⁺-kanalblokkere, hjertesvigt)  

Inotropi påvirker **slagvolumen** uden at ændre præload. Øget inotropi ses ved adrenalin/træning, nedsat inotropi ved hjertesvigt eller visse lægemidler.  

Kontraktiliteten måles ofte som **ejektionsfraktion** (EF = SV/EDV, normalt >55%).

**Relationer:** Kronotropi, Slagvolumen, Hjerteflow, Hjertemuskulatur, β-blokker, Ca²⁺-signalering
