# Pulmonalarterien (lungepulsåren)

**Nøgleord:** Truncus pulmonalis, højre ventrikel, pulmonalklappen, lungekredsløb, deoxygeneret blod, lavtrykssystem, pulmonal hypertension

**Kort beskrivelse:**  
**Pulmonalarterien** er den **eneste arterie der fører iltfattigt blod** (deoxygeneret). Den udspringer fra **højre ventrikel** via pulmonalklappen og fører blod til lungerne.

**Forløb:** Truncus pulmonalis → højre/venstre pulmonalarterie → forgrener sig i lungerne → kapillærer omkring alveoler → CO₂ afgives, O₂ optages.

**Tryk:** 15-30 mmHg systolisk, 4-12 diastolisk (~1/5 af systemisk tryk) → beskytter lungekapillærerne.

*Klinik:* **Pulmonal hypertension** → kan skyldes KOL, hjertesvigt, lungeemboli → belaster højre ventrikel → **cor pulmonale** (højresidig hjertesvigt).

**Relationer:** Højre ventrikel, Lungekredsløb, Aorta, Hjerteopbygning, Alveoler, Kapillærer
