# Bohr-effekt og Haldane-effekt

To komplementære fysiologiske effekter der forbinder O₂- og CO₂-transport.

## Bohr-effekten

> **Definition**: ↑ PCO₂ / ↓ pH → ↓ Hb's affinitet for O₂ → O₂ frigives lettere til væv

### Mekanisme

\[
\text{H}^+ + \text{HbO}_2^- \rightleftharpoons \text{HHb} + \text{O}_2
\]

1. Væv producerer CO₂ → omdannes til H⁺ + HCO₃⁻ (via kulsyreanhydrase)
2. H⁺ protonerer **histidinrester** på Hb (især His146 på β-kæder)
3. Protionering stabiliserer **T-formen** (deoxy-Hb) → ↓ O₂-affinitet
4. O₂ dissocieres → diffunderer til væv

### Betydning for O₂-transport

```
Væv med høj metabolisme:
  ↑ CO₂  →  ↓ pH  →  Bohr-effekt  →  ↑ O₂-frigivelse
  
         UDEN Bohr:          MED Bohr:
Vævs-PO₂ = 40 → mætning 75%   → mætning ~65%
         = 5 mL O₂/dL           = 7 mL O₂/dL (40% mere!)
```

- **Højreforskydning** af O₂-dissociationskurven
- P₅₀ stiger (fra 26 → >30 mmHg ved acidose)
- **Double Bohr-effekt** i placenta:
  - Fosterblod har ↑ CO₂ → frigiver O₂ lettere til fostervæv
  - Moderkage: Moderbob har ↓ CO₂ → optager O₂ lettere

### Klinisk relevans

- **Diabetisk ketoacidose** → ↓ pH → Bohr → ↑ O₂-frigivelse (kompensatorisk)
- **KOL** → kronisk ↑ CO₂ → højreforskydning → kompenseret O₂-afgivelse
- **Hyperventilation** → ↓ CO₂ (respiratorisk alkalose) → venstreforskydning → O₂ holdes tilbage → kan give svimmelhed

## Haldane-effekten

> **Definition**: Deoxygenering af Hb → øger blodets evne til at transportere CO₂

### Mekanisme

\[
\text{HbO}_2 \rightarrow \text{Deoxy-Hb} + \text{O}_2
\]
\[
\text{Deoxy-Hb} + \text{H}^+ + \text{CO}_2 \rightleftharpoons \text{Hb-NH-COOH} \ (\text{carbamino-Hb})
\]

1. Når O₂ frigives i væv → deoxy-Hb er **svagere syre** (stærkere base) end oxy-Hb
2. Deoxy-Hb binder **H⁺** → buffer → ↑ HCO₃⁻-dannelse i røde blodlegemer
3. Deoxy-Hb binder **CO₂** direkte til aminogrupper → **carbamino-Hb** (20% af CO₂-transport)
4. I lungerne: O₂-binding → oxy-Hb er stærkere syre → frigiver H⁺ → CO₂ dissocieres → udåndes

### Betydning for CO₂-transport

| Parameter | Uden Haldane | Med Haldane |
|-----------|:-----------:|:----------:|
| CO₂-optag i væv | 1× | ~3× højere |
| CO₂-frigivelse i lunge | 1× | ~2× højere |

### Opsummering — samspil

```
VÆV (perifert):
  ↑ CO₂ → ↓ pH (Bohr)  → Hb frigiver O₂
  ↓ O₂  → ↑ CO₂-optag (Haldane) → Hb optager CO₂/H⁺
  
→ Effektiv O₂-levering OG CO₂-fjernelse

LUNGE:
  ↑ O₂  → Hb binder O₂ → H⁺ frigives → CO₂ dannes → udåndes
  ↓ CO₂ → ↑ pH (omvendt Bohr) → Hb binder O₂ bedre
  
→ Optimal gasudveksling i alveolerne
```
