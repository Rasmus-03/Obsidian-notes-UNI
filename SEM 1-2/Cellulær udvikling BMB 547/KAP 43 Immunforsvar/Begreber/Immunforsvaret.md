# Immunforsvaret (overblik)

> [!tip] **For en 5-årig:**  
> Immunforsvaret er kroppens forsvar mod ubudne gæster (bakterier, vira, parasitter). Det har en hurtig "dørmand" (medfødte immunforsvar) der stopper de fleste, og en "specialstyrke" (adaptive immunforsvar) der husker tidligere ubudne gæster og reagerer hurtigere næste gang!

## Definition
Immunforsvaret beskytter kroppen mod **patogener** (bakterier, vira, svampe, parasitter) og **cancer**. Det består af medfødt (uspecifikt) og adaptivt (specifikt) immunforsvar.

## Medfødt immunforsvar (innate)

### Fysiske barrierer
- **Hud**: keratin, hudens sure pH
- **Slimhinder**: mukus, cilier, lysozym (tårer, spyt)
- **Mave**: mavesyre (pH 1-2)

### Celler
| Celletype | Funktion |
|-----------|----------|
| **Neutrofile** | Fagocytose, første forsvar mod bakterier |
| **Makrofager** | Fagocytose + antigenpræsentation (APC) |
| **Dendritiske celler** | Antigenpræsentation → aktiverer T-celler |
| **NK-celler (Natural Killer)** | Dræber virusinficerede celler og tumorceller |
| **Mastceller** | Allergi, parasitter (histamin) |
| **Eosinofile** | Allergi, parasitter |

### Proteiner
- **Komplementsystemet**: membranangreb (MAC), opsonisering, inflammationssignal
- **Akut-fase-proteiner**: CRP, mannose-bindende lektin
- **Cytokiner**: IL-1, TNF-α, IL-6, IL-8, type I interferon

## Adaptivt immunforsvar (acquired)

### Celler
| Celletype | Funktion |
|-----------|----------|
| **B-celler** → **Plasmaceller** | Producerer antistoffer |
| **B-celler** → **Hukommelses-B-celler** | Hurtig respons ved geninfektion |
| **T-celler (Cytotoksiske, CD8+)** | Dræber virusinficerede celler |
| **T-celler (Hjælper, CD4+)** | Aktiverer B-celler, makrofager, CD8+ |
| **T-celler (Regulatoriske)** | Undertrykker immunrespons |
| **Hukommelses-T-celler** | Langtidshukommelse |

### Antistoffer (immunglobuliner)
| Klasse | Funktion |
|--------|----------|
| **IgG** | Mest almindelig, langtidshukommelse, passerer placenta |
| **IgA** | Slimhinder (tarm, luftveje, modermælk) |
| **IgM** | Første respons (akut infektion) |
| **IgE** | Allergi, parasitter (mastceller) |
| **IgD** | B-celle-receptor |

## MHC-systemet (HLA hos mennesker)
| Klasse | Funktion |
|--------|----------|
| **MHC I** | Alle celler → præsenterer intracellulært antigen → CD8+ T-celler |
| **MHC II** | APC'er (dendrit, makrofag, B-celle) → præsenterer ekstracellulært antigen → CD4+ T-celler |

## Nøgleprocesser
- **Inflammation**: vasodilation → rødme, varme, hævelse, smerte
- **Fagocytose**: neutrofile/makrofager spiser og fordøjer patogener
- **Apoptose**: programmeret celledød → fjerner inficerede celler

## Klinisk relevans
- **Allergi**: overreaktion på harmløse stoffer (IgE, mastceller)
- **Autoimmunsygdom**: immunsystemet angriber egne celler (f.eks. Graves', type 1 diabetes)
- **Immundefekt**: HIV → CD4+ T-celler ødelægges → AIDS
- **Vaccination**: inducerer hukommelses-B/T-celler → beskyttelse
