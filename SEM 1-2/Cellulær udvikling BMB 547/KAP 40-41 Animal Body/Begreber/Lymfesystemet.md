## Lymfesystemet

**Lymfesystemet** er et parallelt karsystem, der **dræner overskydende interstitiel væske** tilbage til blodbanen og spiller en central rolle i **immunforsvaret** og **fedtabsorption**.

### Opbygning

```
Interstitiel væske → Lymfekapillærer → Lymfekar → Lymfeknuder → Lymfestammer → Ductus thoracicus/ductus lymphaticus → Vener (v. subclavia)
```

### 1. Lymfekapillærer (initialt)
- **Blindende rør** med **overlappende endotelceller** (one-way valves)
- **Ankerfilamenter** holder kapillærerne åbne ved øget interstitielt tryk
- Større permeabilitet end blodkapillærer → proteiner kan passere

### 2. Dræningsmekanisme
| Drivkraft | Mekanisme |
|-----------|-----------|
| **Interstitielt tryk** | Væske presses ind i lymfekapillærer |
| **Kontraktion af glat muskel** | Lymfangioner (segmenter mellem klapper) kontraheres spontant |
| **Ydre kompression** | Skeletmuskelpumpe, respiration, puls |
| **Envejsklapper** | Forhindrer tilbageløb |

### 3. Funktioner

| Funktion | Mekanisme |
|----------|-----------|
| **Væskebalance** | Returnerer ~2-4 L/dag (ellers ødem) |
| **Immunforsvar** | Lymfeknuder filtrerer og aktiverer immunceller |
| **Fedtabsorption** | **Laktealer** i tarmvilli optager chylomikroner |
| **Protein-retur** | Returnerer interstitielle proteiner til blodet |

### 4. Lymfoide organer
| Organ | Funktion |
|-------|----------|
| **Lymfeknuder** | Filtrering, antigen-præsentation, B/T-celle-aktivering |
| **Milt** | Filtrering af blod, fagocytose af gamle RBC |
| **Tonsiller** | Første forsvar mod indåndede/indtagne patogener |
| **Thymus** | T-celle-modning |

### Klinisk relevans
- **Lymfødem** → blokeret lymfedrænage (post-kirurgi, filariasis)
- **Lymfadenopati** → hævede lymfeknuder (infektion, cancer)
- **Metastasering** → cancer spredes via lymfebaner
