# Væv (animal body)

> [!tip] **For en 5-årig:**  
> Kroppen er bygget af forskellige "byggematerialer" (væv). Der er dækmateriale (epitel), bæremateriale (bindevæv), trækmateriale (muskel) og ledningsmateriale (nerver). Hvert væv har sin egen specialitet!

## Definition
Væv er grupper af celler med **samme funktion og struktur**. Der findes fire grundtyper af væv i dyrekroppen.

## De fire vævstyper

### 1. Epitelvæv
| Egenskab | Detalje |
|----------|---------|
| Funktion | Beskytter, sekreterer, absorberer, filtrerer |
| Celler | Tætpakkede, lidt ekstracellulær matrix |
| Basalmembran | Anker for epitelet |
| Kar | Ikke vaskulariseret (ernæres via diffusion) |
| **Typer** | Enkelt (simple), lagdelt (stratificeret), pseudo-stratificeret |
| **Eksempel** | Hud, tarmvæg, lungealveoler, nyretubuli |

### 2. Bindevæv
| Egenskab | Detalje |
|----------|---------|
| Funktion | Støtte, forbinde, beskytte, transportere |
| Celler | Spredte, **meget ekstracellulær matrix** (fiber + grundsubstans) |
| Fibre | Kollagen (styrke), Elastin (elasticitet) |
| **Typer** | Løst, fast (kollagen), fedt, brusk, knogle, blod |
| **Eksempel** | Dermis, sener, ledbånd, knogler, blod |

### 3. Muskelvæv
| Egenskab | Detalje |
|----------|---------|
| Funktion | Kontraktion (bevægelse) |
| Celler | Muskelfibre = lange, kontraktile celler |
| Proteiner | Aktin + myosin (sliding-filament) |
| **Typer** | Skeletmuskel (frivillig, tværstribet), glat (u.villig, enkeltkernet), hjerte (u.villig, tværstribet) |
| **Eksempel** | Biceps, tarmvæg, hjerte |

### 4. Nervevæv
| Egenskab | Detalje |
|----------|---------|
| Funktion | Kommunikation (elektriske signaler) |
| Celler | Neuroner (signal) + gliaceller (støtte, myelin, immunforsvar) |
| **Neurontyper** | Sensoriske, motoriske, interneuroner |
| **Eksempel** | Hjerne, rygmarv, nerver |

## Oversigtstabel
| Vævstype | Celler | Matrix | Funktion | Regeneration |
|----------|-------|--------|----------|-------------|
| Epitel | Tætpakkede | Lidt | Dække/sekretion | Høj |
| Bindevæv | Spredte | Meget | Støtte/forbinde | Variabel |
| Muskel | Lange fibre | Lidt | Kontraktion | Begrænset |
| Nerve | Neuroner + glia | Meget lidt | Signalering | Meget lav |

## Eksamenstræning
- Spørgsmålstype: "Angiv de fire vævstyper" → epitel, bindevæv, muskel, nerve
- Spørgsmålstype: "Forklar forskel på epitel og bindevæv" → tætpakkede vs spredte celler, lidt vs meget matrix
- Spørgsmålstype: "Hvilke vævstyper regenererer godt?" → epitel (høj), lever (god), hjerte/dårlig), nerve (meget dårlig)
