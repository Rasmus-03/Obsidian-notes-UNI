## Urinens vej

Urinen produceres i nyrerne og transporteres via urinvejene til udskillelse. Hele systemet er trykreguleret og envejs.

### Anatomisk rute
**Nyrekapsel (Bowmans kapsel) → Proksimale tubulus → Henles slynge → Distale tubulus → Samlerør → Nyrebækken → Ureter → Blære → Urethra**

### Mekanisme pr. struktur

| Struktur | Funktion | Mekanisme |
|----------|----------|-----------|
| **Nyrebækken (pelvis renalis)** | Opsamling af urin | Fyldning via peristaltik |
| **Ureter** | Transport → blære | Peristaltik (glat muskel, sympatikus) |
| **Blære** | Opbevaring | Detrusormuskel relaxeres (sympatikus β₃) |
| **Urethra** | Udskillelse | Tømning: detrusor kontraheres (parasympatikus M₃) |

### Peristaltik i ureter
1. Pacemaker-celler i nyrebækken → spontan depolarisering
2. Ca²⁺-indstrømning → kontraktion af glat muskel
3. Bølge af kontraktion (2-6/min) → urin presses mod blæren
4. **Vesicoureteral junction** – klapmekanisme ved ureters indgang i blæren → forhindrer refluks

### Tømningsrefleks (miksjon)
1. Blærefyldning → stræk-receptorer i blærevæggen aktiveres
2. Afferent signal via **n. pelvicus** → rygmarv (S2-S4)
3. Parasympatisk efferent → **detrusor kontraheres** + **indre urethral-sfinkter relaxeres**
4. Ydre urethral-sfinkter (somatisk) → **frivillig kontrol** via n. pudendus
5. Hjernens kontrol: **Pontin miksjonscenter** koordinerer

### Klinisk relevans
- **Vesicoureteral reflux** → urin tilbage i ureter → nyreskade
- **Urinretention** → blæren tømmes ikke → overfyldning
- **Stress-inkontinens** → svækket bækkenbund
