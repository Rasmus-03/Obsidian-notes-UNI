## Leverkapillærer (Sinusoider)

Leverens kapillærer er **sinusoider** – specialiserede, permeable kapillærer med unik struktur tilpasset leverens metaboliske funktion.

### Struktur vs. almindelige kapillærer

| Egenskab | Almindelig kapillær | Lever-sinusoid |
|----------|---------------------|----------------|
| **Basalmembran** | Kontinuert | **Fraværende eller diskontinuert** |
| **Endotel** | Kontinuert | **Fenestreret** (100-200 nm huller) |
| **Pericytter** | Tilstede | **Fraværende** |
| **Størrelse** | 5-10 µm | **10-30 µm** (bredere) |
| **Funktion** | Udveksling kapillær-væv | Udveksling blod-hepatocyt |

### Funktionelle konsekvenser
1. **Fravær af basalmembran** → plasmaproteiner (inkl. albumin) kan passere frit
2. **Store fenestrationer** → chylomikroner og VLDL kan passere direkte til hepatocytter
3. **Langsom blodgennemstrømning** → optimal tid til ekstraktion af næringsstoffer
4. **Tæt kontakt med hepatocytter** → effektiv clearance af affaldsstoffer

### Sinusoidens celletyper
| Celletype | Funktion |
|-----------|----------|
| **Endotelceller** | Fenestreret barriere, filtrering |
| **Kupffer-celler** (makrofager) | Fagocytose af bakterier, gamle RBC |
| **Stellate-celler (Ito-celler)** | Vitamin A-lagring, kollagenproduktion ved skade |
| **Pit-celler** (NK-celler) | Immunovervågning |

### Flow-retning
1. Blod kommer via **a. hepatica** (O₂-rig) + **v. portae** (næringsrig fra tarm)
2. Blandes i **sinusoider** → langsom perkolation omkring hepatocytter
3. Samles i **v. centralis** → **v. hepatica** → v. cava inferior

### Klinisk relevans
- **Portal hypertension** → sinusoid-modstand → ascites, øsofagus-varicer
- **Levercirrhose** → stellate-celler aktiveres → kollagenaflejring → sinusoid-kapillarisering (tab af fenestrationer)
