# Absorption (fordøjelse)

## Definition
**Absorption** er optagelsen af **fordøjede næringsstoffer** (monosakkarider, aminosyrer, fedtsyrer, vitaminer, mineraler og vand) fra tarmlumen gennem **enterocytterne** i tyndtarmens epithel til blod eller lymfe.

## Lokalisation
- **Tyndtarm (duodenum, jejunum, ileum)** – primær absorptionssite
- **Jejunum:** Mest absorption (glukose, aminosyrer, lipider, vitaminer, mineraler)
- **Ileum:** Vitamin B₁₂ (med intrinsic factor), galdesalte (enterohepatisk kredsløb)
- **Colon:** Vand og elektrolytter (Na⁺, Cl⁻, K⁺); kortkædede fedtsyrer (SCFA) fra fermentering

## Absorptionsmekanismer (enterocytten)

### Kulhydrater (→ monosakkarider)
| Mekanisme | Transportør | Eksempel |
|-----------|------------|----------|
| **Sekundær aktiv transport** (SGLT1) | Na⁺-glukose symport (2 Na⁺ : 1 glukose) | Glukose, galactose |
| **Faciliteret diffusion** (GLUT5) | GLUT5 (fructose-transportør) | Fruktose |
| **Faciliteret diffusion** (GLUT2) | GLUT2 på basolateral side | Glukose, galactose → blod |

**Mekanisme SGLT1:**
1. Na⁺/K⁺-ATPase på basolateral side opretholder lav [Na⁺] i cellen
2. Na⁺-gradient → trækker glukose ind via SGLT1 på apikal side
3. Glukose forlader cellen via GLUT2 til blodet

### Proteiner (→ aminosyrer)
- **Aminosyrer (AA):**
  - **Neutrale AA** → Na⁺-symport (B⁰AT1)
  - **Sure AA** → H⁺-symport
  - **Basiske AA** → uafhængig transportør (rBAT/b⁰,⁺AT)
- **Di-/tripeptider** → **PEPT1** (H⁺-symport) → intracellulært spaltet til AA → basolateral transport via specifikke transportører

### Lipider
1. **Miceller** (galdesalte + fedtsyrer + monoglycerider + fosfolipider) diffunderer til enterocyt-membranen
2. **Passiv diffusion** af fedtsyrer og monoglycerider ind i enterocytten
3. **Intracellulær resyntese** → triglycerider + kolesterol + fosfolipider + apolipoprotein → **chylomikroner**
4. **Exocytose** → **lactealer** (lymfekar i villi) → ductus thoracicus → blod (omgår leverens first-pass)

### Vand og elektrolytter
| Ion | Mekanisme | Sted |
|-----|-----------|------|
| Na⁺ | SGLT1, Na⁺/H⁺-antiport (NHE3), ENaC (colon) | Tyndtarm + colon |
| Cl⁻ | CFTR-kanal, Cl⁻/HCO₃⁻-antiport | Tyndtarm + colon |
| Fe²⁺ | DMT1 (H⁺-symport) på apikal side; ferroportin på basolateral | Duodenum |
| Ca²⁺ | TRPV6 (apikal); calbindin + Ca²⁺-ATPase (basolateral) | Duodenum |

**Vand:** Absorption følger **Na⁺-gradienten** (transcellulært via aquaporiner + paracellulært via tight junctions)

## Regulering
- **Aldosteron:** ↑ Na⁺-absorption (ENaC, Na⁺/K⁺-ATPase) i colon
- **Glukokortikoider:** ↑ Na⁺-absorption i tyndtarm
- **Angiotensin II:** ↑ Na⁺/H⁺-antiport (NHE3)
- **Vitamin D:** ↑ Ca²⁺-absorption (↑ TRPV6, calbindin)

## Klinisk relevans
- **Laktoseintolerance:** ↓ laktase → laktose fermenteres i colon → oppustethed, diarré
- **Malabsorption:** Cøliaki (gluten → villi-atrofi), Crohns sygdom, tropisk sprue
- **Ondt kolesterol (LDL):** ↑ absorption af mættet fedt + kolesterol → ↑ plasma-LDL
- **CFTR-mutation (cystisk fibrose):** ↓ Cl⁻ → ↓ vand → tykt, sejt slim → obstruktion

## Relationer
- ← **Fordøjelse** (mave, bugspytkirtel)
- ← **Tyndtarmens anatomi** (villi, mikrovilli, crypts)
- → **Blod / lymfe** (transport til væv)
- ← **Galde** (miceller)
- → **Lever** (portalvenen)
