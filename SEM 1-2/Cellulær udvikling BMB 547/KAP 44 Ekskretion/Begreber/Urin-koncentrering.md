## Urin-koncentrering (modstrømsmekanisme)

Nyrens evne til at **koncentrere urin** (op til 1200 mOsm/kg) afhænger af en **medullær osmotisk gradient**, der skabes via **modstrømsmultiplikation**.

### Gradienten
- Cortex: ~300 mOsm (isotont med plasma)
- Medulla (spids): ~1200 mOsm (4× koncentreret)
- Gradienten er **afgørende** for ADH-afhængig vandreabsorption

### Modstrømsmultiplikation (Henles slynge)

| Segment | Permeabilitet | Transport | Osmolalitetsændring |
|---------|--------------|-----------|---------------------|
| **Nedstigende Henle** | Høj vand-permeabel (AQP1) | **Ingen** aktiv transport | ↑ [300→1200], vand ud |
| **Tynd opstigende** | Ingen vandpermeabilitet | Passiv Na⁺-udstrømning | ↓ [1200→...] |
| **Tykk opstigende** | Ingen vandpermeabilitet | **Aktiv NKCC2** (Na⁺/K⁺/2Cl⁻) | ↓ (fortyndende segment) |

### Vasa recta (modstrømsudveksling)
- Vasa recta bevarer gradienten ved **passiv modstrømsudveksling**
  - Nedstigende: O₂ + næring → medulla, vand ud, NaCl ind
  - Opstigende: Vand ind, NaCl ud
- **Langsomt flow** → mindsker udvaskning af gradienten

### ADH's rolle (samlerør)
1. **ADH** (vasopressin) → AQP2-kanaler indsættes i samlerørets luminale membran
2. AQP2 → **vand-permeabelt** samlerør → vand diffunderer passivt ud langs gradienten
3. Uden ADH → samlerør impermeabelt for vand → **fortyndet urin**

### Kortlægning af osmolalitet

| Sted | Uden ADH | Med ADH |
|------|----------|---------|
| Cortex (proksimal) | 300 | 300 |
| Nedstigende Henle | 300→1200 | 300→1200 |
| Opstigende Henle | 1200→100 | 1200→100 |
| Distale tubulus | 100 | 100 |
| Samlerør (cortex) | 100 | 300 |
| Samlerør (medulla) | 100 | 1200 |
| **Urin** | **50-100** (fortyndet) | **1200** (koncentreret) |

### Modstrømsmultiplikation i detaljer (step-by-step)
1. NKCC2 pumper Na⁺, K⁺, Cl⁻ ud af opstigende Henle → **interstitium bliver hyperosmotisk**
2. Interstitium → trækker vand ud af **nedstigende Henle** (AQP1) → tubulusvæske koncentreres
3. Væsken fortsætter til opstigende Henle → NKCC2 pumper Na⁺ ud → **fortyndet** væske
4. Loop gentages → gradienten **multipliceres** op til 1200 mOsm

### Klinisk relevans
- **Diabetes insipidus** → ↓ ADH eller ↓ AQP2 → kan ikke koncentrere urin → polyuri, polydipsi
- **Loop-diuretika** (furosemid) → blokerer NKCC2 → gradienten forsvinder → ↓ koncentreringsevne
- **Nyresvigt** → tab af medullær gradient → isostenuri (urin = plasma osmolalitet)
