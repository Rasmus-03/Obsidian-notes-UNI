## Nyresten (Nefrolithiasis)

**Nyresten** er **krystallinske konkrementer**, der dannes i nyrebækkenet eller urinvejene, når urinen bliver **overmættet** med bestemte stoffer.

### Stentyper (sammensætning)

| Type | Forekomst | Årsag | Røntgen |
|------|-----------|-------|---------|
| **Calciumoxalat** | ~70% | ↑ Ca²⁺, ↓ citrat | **Radioopak** |
| **Calciumfosfat** | ~10% | ↑ pH (UVI), renal tubulær acidose | **Radioopak** |
| **Urat** (urinsyre) | ~10% | ↑ urinsyre (gigt, cancer), lav pH | **Radiolucent** |
| **Struvit** (Mg-NH₄-PO₄) | ~5% | UVI med urease-bakterier (Proteus) | **Radioopak** (stor) |
| **Cystin** | <1% | Cystinuri (genetisk) | **Svagt opak** |

### Dannelse (mekanisme)
1. **Supersaturation** → urinen indeholder mere af stoffet end kan opløses
2. **Nukleation** → krystaller dannes (homogen/heterogen, f.eks. på celledebris)
3. **Vækst** → krystaller aggregerer → synligt konkrement
4. **Manglende hæmmere:** ↓ citrat, ↓ pyrophosphat, ↓ osteopontin → øger risiko

### Risikofaktorer
| Faktor | Mekanisme |
|--------|-----------|
| **Dehydrering** | ↓ urinvolumen → ↑ koncentration → ↓ opløsning |
| **Hypercalciuri** | Hyperparathyroidisme, sarkoidose, ↑ vitamin D |
| **Hyperurikosuri** | Gigt, kemoterapi (tumorlyse) |
| **Hyperoxaluri** | Oxalatrig kost (rabarber, spinat), tyndtarmssygdom |
| **Hypocitraturi** | Citrat hæmmer krystalvækst (metabolisk acidose ↓ citrat) |
| **UVI** | Urease-bakterier → ↑ pH → struvit-sten |
| **Familiel** | Cystinuri, renal tubulær acidose |

### Symptomer (ureter-sten)
- **Nyremave** (akutte smerter) → kolik, smerter fra flanke → lyske/testikel
- **Hæmaturi** → blod i urinen
- **Kvalme, opkast** → ren-intestinal refleks
- **Stranguri** → smerte ved vandladning
- **Ved obstruktion:** ↓ urinproduktion → hydronefrose

### Behandling

| Størrelse | Behandling |
|-----------|------------|
| <5 mm | Spontan passage (90%), smertestillende, α-blokker |
| 5-10 mm | Medicamentøs uddrivelse (tamsulosin) → 50% |
| >10 mm | ESWL (stødbølge), ureteroskopi, PCNL |
| Urat-sten | Alkalisering (citrat, NaHCO₃) → opløses kemisk |

### Klinisk relevans
- **Hydronefrose** → langvarig obstruktion → nyreskade
- **Obstruktiv pyelonefritis** → sten + infektion → urologisk akut
- **Gentagelsesrisiko:** ~50% på 10 år → forebyggelse: ↑ vandindtag, diæt
