# Osmoregulering

## Definition
Osmoregulering er aktiv opretholdelse af vand- og saltbalancen, så plasma-osmolariteten holdes stabil (280-295 mOsm/L).

## Reguleringsmekanismer

### ADH (antidiuretisk hormon)
- Stimulus: øget plasma-osmolaritet (>290 mOsm) eller lavt blodvolumen
- Effekt: øget vandreabsorption i opsamlingsrøret via aquaporin-2 → koncentreret urin
- Se [[ADH]]

### Tørst
- Stimulus: øget osmolaritet (>290 mOsm) → osmoreceptorer i hypothalamus
- Effekt: øget vandindtag → fortynder blodet

### RAAS (Renin-Angiotensin-Aldosteron System)
- Stimulus: lavt blodtryk, lav Na+, sympatisk stimulering
- Effekt: øget Na+-reabsorption + vasokonstriktion → blodtryk stiger
- Se [[RAAS-systemet]]

### ANP (Atrial Natriuretic Peptide)
- Stimulus: højt blodtryk, atrieudspiling → ANP frigives fra hjertets atrier
- Effekt: øget Na+-udskillelse (natriurese) + vasodilatation → blodtryk falder
- ANP er modspiller til RAAS
