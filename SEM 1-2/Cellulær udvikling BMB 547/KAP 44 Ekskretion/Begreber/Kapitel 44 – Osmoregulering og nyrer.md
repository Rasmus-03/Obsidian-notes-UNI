# Kapitel 44 – Osmoregulering og nyrer

> [!tip] **For en 5-årig:**  
> Nyrerne er kroppens vandrensningsanlæg. De filtrerer blodet, fjerner affald, og sørger for at der er præcis den rigtige mængde vand og salt i kroppen. Hver dag renser de hele blodet ~60 gange!

## Nyrernes funktioner
1. **Fjerner affaldsstoffer** (urinstof, kreatinin)
2. **Regulerer væske- og saltbalance** (osmoregulering)
3. **Regulerer blodtryk** (RAAS-systemet)
4. **Regulerer syre-base-balance** (H⁺/HCO₃⁻)
5. **Producerer hormoner** (erythropoietin, renin, calcitriol)

## Nyrernes opbygning
- **Cortex** (ydre): glomeruli, proximal tubuli
- **Medulla** (indre): Henles slynge, samlerør
- **Nefron**: funktionel enhed (~1 million per nyre)

## Nefronets opbygning
1. **Glomerulus** (kapillærknippe) → filtrering
2. **Bowmans kapsel** → opsamler filtrat
3. **Proximal tubuli** → reabsorption (glukose, aminosyrer, Na⁺, vand)
4. **Henles slynge** → modstrømsmultiplikator (koncentrerer urin)
5. **Distal tubuli** → finjustering (Ca²⁺, Na⁺, pH)
6. **Samlerør** → ADH-reguleret vandreabsorption

## De 3 processer
| Proces | Sted | Hvad sker der? |
|--------|------|----------------|
| **Filtrering** | Glomerulus | Vand + små molekyler filtreres (tryk-drevet) |
| **Reabsorption** | Tubuli | Nyttige stoffer → blodet igen |
| **Sekretion** | Tubuli | Affald/overskud → urinen |

## Modstrømsmultiplikator
- **Henles slynge**: nedadgående = vand ud (permeabel for vand); opadgående = NaCl ud (permeabel for salt)
- Skaber **osmotisk gradient** i medulla → cortex: 300 mOsm; indre medulla: 1200 mOsm
- ADH → aquaporiner → vand reabsorberes → koncentreret urin

## Eksamenstræning
- Spørgsmålstype: "Forklar de 3 processer i nyrerne" → filtrering → reabsorption → sekretion
- Spørgsmålstype: "Hvordan fungerer modstrømsmultiplikator?" → Henles slynge skaber osmotisk gradient
- Spørgsmålstype: "Hvordan påvirker ADH urinproduktion?" → aquaporiner → vandreabsorption → koncentreret urin
