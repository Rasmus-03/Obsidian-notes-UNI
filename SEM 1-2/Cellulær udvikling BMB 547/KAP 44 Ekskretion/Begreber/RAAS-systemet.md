# RAAS-systemet (Renin-Angiotensin-Aldosteron System)

> [!tip] **For en 5-årig:**  
> RAAS er kroppens blodtryksregulering. Forestil dig en vandslange: Hvis trykket bliver for lavt, sender RAAS et signal om at dreje på hanen (indsnavre blodkar) og fylde mere vand på (beholde salt og vand). Det får trykket op igen!

## Definition
RAAS er et **hormonelt kaskadesystem** der regulerer blodtryk, væskebalance og elektrolytbalance. Det aktiveres ved lavt blodtryk, lavt Na⁺ eller høj K⁺.

## Kaskaden

### 1. Renin (fra juxtaglomerulære celler i nyren)
Udløses af:
- **Lavt blodtryk** (renalt perfusionstryk ↓) → baroreceptorer i afferent arteriole
- **Lav Na⁺** i macula densa (DCT) → signal om lav GFR
- **Sympatikus-aktivering** (β₁-receptorer)

### 2. Angiotensinogen → Angiotensin I
- Renin spalter angiotensinogen (fra leveren) → angiotensin I (inaktiv)

### 3. Angiotensin I → Angiotensin II
- ACE (Angiotensin Converting Enzyme) i **lungerne** spalter AI → AII

### 4. Angiotensin II's effekter
| Effekt | Mekanisme |
|--------|-----------|
| Vasokonstriktion | Indsnævrer arterioler → blodtryk ↑ |
| Aldosteron-frigivelse | Binyrebark → Na⁺-reabsorption ↑, K⁺-udskillelse ↑ |
| ADH-frigivelse | Hypofyse → vandreabsorption ↑ |
| Tørst | Hypothalamus → væskeindtag ↑ |
| Øget Na⁺-reabsorption | Direkte effekt på PCT |

### 5. Aldosteron (fra binyrebark)
- Virker på **distale tubulus** og **opsamlingsrør**
- Øger antallet af Na⁺-kanaler (ENaC) og Na⁺/K⁺-pumper
- Na⁺-reabsorption ↑ → vand følger med → blodvolumen ↑ → blodtryk ↑
- K⁺-udskillelse ↑ (byttes mod Na⁺)

## Negative feedback
- Højt blodtryk → renin ↓ → kaskade slukkes
- Høj Na⁺ → ANP (atrial natriuretisk peptid) frigives → modvirker RAAS

## Klinisk relevans
- **ACE-hæmmere** (f.eks. ramipril, enalapril): blokerer ACE → AII ↓ → blodtryk ↓ → anvendes mod hypertension og hjertesvigt
- **ARB'er** (angiotensin II-receptor-blokkere, f.eks. losartan): blokerer AII-receptorer
- **Aldosteron-antagonister** (spironolacton): diuretikum, K⁺-besparende
- **Renal arteriestenose**: nedsat perfusion → RAAS overaktiveres → hypertension

## Eksamenstræning
- Spørgsmålstype: "Redegør for RAAS-systemet" → renin → AI → AII → aldosteron → Na⁺/vand-reabsorption
- Spørgsmålstype: "Hvordan reguleres blodtryk via nyrerne?" → RAAS + ADH + ANP
- Spørgsmålstype: "Hvad er effekten af ACE-hæmmere?" → blokerer AII-dannelse → vasodilatation + nedsat væskevolumen
