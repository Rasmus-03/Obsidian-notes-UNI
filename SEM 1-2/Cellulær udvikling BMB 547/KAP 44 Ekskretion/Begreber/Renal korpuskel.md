## Renal korpuskel

**Renal korpuskel** (Malpighis legeme) = **Glomerulus + Bowmans kapsel**. Det er den **filterende enhed** i nephronet.

### Struktur
- **Bowmans kapsel:** 2 lag (parietalt = fladt epitel, visceralt = **podocytter**)
- **Urinrum:** Mellem de to lag → filtrat opsamles
- **Glomerulus:** Kapillærnet mellem afferent og efferent arteriole
- **Mesangium:** Celler + matrix mellem kapillærerne

### Filtrationsbarrieren (3 lag)

```
Kapillærlumen → Fenestreret endotel (70-100 nm) → Basalmembran (~300 nm) → Podocyt-slidsmembran → Urinrum
```

**Selektivitet:**
| Stof | Molekylestørrelse | Flitrering |
|------|-------------------|------------|
| Vand, ioner, glukose | <1 nm | ~100% |
| Inulin (test) | ~5 kDa | 100% |
| Myoglobin | ~17 kDa | 75% |
| Albumin | ~68 kDa, negativ | <0.5% (spor) |
| Immunoglobuliner | >150 kDa | <0.1% |

### Starling-kræfter (filtrations-drivkraft)
| Kraft | Værdi | Retning |
|-------|-------|---------|
| P_GC (kapillært hydrostatisk) | ~60 mmHg | **Ud** |
| P_BS (Bowmans hydrostatisk) | ~15 mmHg | Ind |
| π_GC (kapillært onkotisk) | ~28 mmHg | Ind |
| π_BS (Bowmans onkotisk) | 0 mmHg | Ud |
| **Netto P** | **+17 mmHg** | **Ud** |

### Autoregulering
- **Myogen respons:** Stræk → afferent arteriole kontraheres → ↓ flow → stabilt GFR
- **Tubuloglomerulær feedback:** Macula densa i distale tubulus → ↑ Na⁺ → vasokonstriktion af afferent
- **Resultat:** GFR holdes stabilt ved BT 80-180 mmHg

### Klinisk relevans
- **Glomerulonefritis** → inflammation → beskadiget barriere → protein/hæmaturi
- **Nefrotisk syndrom** → massiv proteinuri (>3.5 g/d) → ødem, hypoalbuminæmi
- **Diabetisk nefropati** → fortykket basalmembran + mesangial ekspansion
