## Blæren (Vesica urinaria)

**Blæren** er et **muskulært hulorgan**, der **opbevarer urin** (300-500 mL) indtil **miksjon** (tømning).

### Anatomi
| Struktur | Funktion |
|----------|----------|
| **Detrusor-muskel** | Glat muskel (3 lag) → kontraktion ved tømning |
| **Trigonum** | Trekantet område mellem ureter-munding + urethra (følsomt for stræk) |
| **Mucosa** | Urothel (overgangsepitel) – **strækbart** |
| **Indre urethral-sfinkter** | Glat muskel (autonom, sympatikus) – holder urin |
| **Ydre urethral-sfinkter** | Tværstribet muskel (somatisk, frivillig kontrol) |

### Innervation
| Nerve | Effekt |
|-------|--------|
| **N. pelvicus** (parasympatisk, S2-S4) | Detrusor kontraheres → tømning |
| **N. hypogastricus** (sympatisk, L1-L2) | Detrusor relaxeres → fyldning |
| **N. pudendus** (somatisk) | Ydre sfinkter kontraheres → holder |

### Fyldning (opbevaringsfase)
1. Urin fra ureter → blære
2. **Stræk-receptorer** i blærevæggen aktiveres ved ~150 mL
3. **Sympatikus:** Detrusor relaxeres (β₃) + indre sfinkter kontraheres (α₁)
4. **Ydre sfinkter:** Frivillig kontraktion (holder)
5. Fyldning fortsætter → **urgency** ved ~400-500 mL

### Tømning (miksjon)
1. Stræk-receptorer → afferent signal til **pontin miksjonscenter**
2. Frivillig beslutning → **parasympatikus aktiveres** → detrusor kontraheres
3. **Sympatikus + somatisk** hæmmes → sfinktere relaxeres
4. Blæretryk > urethratryk → urin strømmer ud

### Tryk-volumen kurve
- **Lavt tryk** op til ~300 mL (compliance = strækbarhed)
- **Stejl stigning** >400 mL → urgency
- Ved tømning: tryk stiger til ~40-60 cmH₂O

### Klinisk relevans
- **Urinretention** → kan ikke tømme → overfyldning → smerte
- **Overaktiv blære** → ufrivillig detrusor-kontraktion → urge-inkontinens
- **Neurogen blære** → skade på spinale centre (paraplegi: spontan tømning)
- **Cystitis** → inflammation → urgency, dysuri
