# Binyrerne (Glandulae suprarenales)

> [!tip] **For en 5-årig:**  
> Binyrerne er to små hatte oven på nyrerne. De laver stress-hormoner (adrenalin og kortisol) der hjælper dig med at reagere hurtigt i farlige situationer.

## Opbygning
| Zone | Hormoner | Funktion |
|------|----------|----------|
| **Binyrebark** (cortex) | | |
| Zona glomerulosa | **Aldosteron** | Na⁺-balance, blodtryk |
| Zona fasciculata | **Cortisol** | Stress, metabolism, immun |
| Zona reticularis | **Androgener** (DHEA) | Kønshormonforløber |
| **Binyremarv** (medulla) | **Adrenalin, noradrenalin** | Kamp/flugt |

## HPA-aksen
```
Hypothalamus → CRH → Hypofyse → ACTH → Binyrebark → Cortisol
                                        ↕ (negativ feedback)
```

## Klinisk relevant
- **Addison**: binyrebarkinsufficiens → træthed, hypotension, hyperpigmentering
- **Cushing**: overskud af cortisol → måneansigt, fedme, striae
- **Conn**: overskud af aldosteron → hypertension, hypokaliæmi
- **Fæokromocytom**: medullær tumor → episodisk hypertension, hjertebanken
