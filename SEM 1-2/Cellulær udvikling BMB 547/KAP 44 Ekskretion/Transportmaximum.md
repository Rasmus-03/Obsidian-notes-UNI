# Transportmaximum

> [!tip] **Hovedprincip:** Transportmaximum (Tm) er den **maksimale hastighed**, hvormed et stof kan transporteres aktivt gennem tubulusvæggen. Når koncentrationen overstiger Tm, udskilles overskuddet i urinen.

## Definition

- **Tm** = den maksimale mængde af et stof, der kan reabsorberes pr. tidsenhed
- Skyldes **mætning** af transportørproteiner (carrier-mediated transport)
- Følger Michaelis-Menten-kinetik (enzymkinetik)

## Eksempler

| Stof | Tm-værdi | Hvad sker ved overstigelse |
|------|----------|---------------------------|
| **Glukose** | ~375 mg/min (hos voksne) | Glukosuri (sukker i urinen) |
| **Fosfat** | ~0,1 mmol/min | Fosfaturi |
| **Aminosyrer** | Varierer efter type | Aminosyreuri |
| **Askorbinsyre (C-vitamin)** | ~2 mg/min | Udskilles i urinen |

## Glukose – det klassiske eksempel

```
B-glucose (mmol/L)
    0────3,9────5,6────10────15────20────>
    │       │      │      │      │
    │       │      │      │      │
    │   Normal  Nyretærskel     │
    │   (ingen   (~10-11       │
    │   glucosuri)  mmol/L)    │
    │                     │
    │           Glucosuri (↑ Tm)
```

| B-glucose | Filteret glucose | Reabsorption | Urin |
|-----------|-----------------|--------------|------|
| < 10 mmol/L | < Tm | Al reabsorberes | Ingen glucose |
| ~10-11 mmol/L | = Tm | Maksimal | Glucosuri begynder |
| > 11 mmol/L | > Tm | Overskud udskilles | Glucosuri |

> [!warning] **Klinisk:**
> - **Diabetes mellitus:** Forhøjet blod-glucose → overstiger Tm → glucosuri → osmotisk diurese → polyuri
> - **Renal glucosuri:** Sjælden tilstand hvor Tm er nedsat (defekt i SGLT2-transportøren) → glucosuri trods normal B-glucose
> - **SGLT2-hæmmere** (f.eks. dapagliflozin) → sænker Tm bevidst for at behandle type 2-diabetes
