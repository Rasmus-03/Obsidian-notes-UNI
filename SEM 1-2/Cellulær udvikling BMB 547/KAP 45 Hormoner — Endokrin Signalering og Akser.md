# Hormoner — Endokrin Signalering og Akser

> **Kerne-pathway:** Hormoner er kemiske budbringere, der koordinerer fysiologiske processer via hypothalamus-hypofyse-akser.

---

## 📡 Hormon-signaleringstyper

| Type | Afstand | Eksempel |
|------|:-------:|----------|
| **Endokrin** | Lang (blod) | Insulin, thyroxin |
| **Parakrin** | Kort (naboceller) | Histamin, prostaglandiner |
| **Autokrin**| Samme celle | Cytokiner |
| **Juxtakrin** | Celle-celle-kontakt | Notch-signalering |
| **Neuroendokrin** | Neuron → blod | ADH, oxytocin |

## 🧪 Hormon-klasser — lipofile vs. lipofobe

> [!INFO] **Eksamensspørgsmål: "Forklar forskellen på hydrofile og hydrofobe hormoner"**

| Egenskab | Hydrofile (peptid-hormoner) | Hydrofobe (steroid/thyroid-hormoner) |
|----------|:---------------------------:|:-----------------------------------:|
| **Opløselighed** | Vandopløselige | Fedtopløselige |
| **Syntese** | Peptider (pre-pro-hormon) | Kolesterol/tyrosin-afledning |
| **Lagring** | Ja (vesikler) | Nej (syntetiseres ved behov) |
| **Transport i blod** | Frit (opløst) | Bundet til bærerproteiner |
| **Receptor** | Membranbundet (GPCR, RTK) | Intracellulær (cytoplasma/kerne) |
| **Signalvej** | Second messenger (cAMP, Ca²⁺, IP₃) | Gen-ekspression (minutter-timer) |
| **Respons** | Hurtig (sekunder-minutter) | Langsom (minutter-timer) |
| **Eksempel** | Insulin, glucagon, ADH | Cortisol, testosteron, T₃ |

## 🧠 Hypothalamus-Hypofyse-Aksen — "Kommandocentralen"

> [!INFO] **Eksamensspørgsmål: "Redegør for hypothalamus-hypofyse-aksen med eksempler"**

**Adenohypofysen (forlap) — endokrine celler:**
```
Hypothalamus → Hypofysens portåresystem → Adenohypofysen → Hormoner
    (releasing/inhibiting hormoner)            │
                                              ├── ACTH (binyrebark)
                                              ├── TSH (thyroidea)
                                              ├── FSH/LH (gonader)
                                              ├── GH (vækst)
                                              └── Prolaktin
```

**Neurohypofysen (baglap) — neurosekretion:**
```
Hypothalamus → Axoner → Neurohypofysen → ADH, Oxytocin (lagres + frigives)
```

**Feedback-regulering:**
```
Hypothalamus → releasing hormon → Hypofyse → tropt hormon → Endokrin kirtel → Hormon
    ↑                                                          │
    └──────────────────────── Long-loop feedback (─) ──────────┘
```

## 📊 De 3 store akser

### HPA-aksen (stress)
```
Stressor → Hypothalamus (CRH) → Hypofyse (ACTH) → Binyrebark → Cortisol
    ↑                                                           │
    └───────────────── Negativ feedback ────────────────────────┘
```

**Cortisol-effekter:**
- Blodsukker ↑ (glukoneogenese)
- Immunsuppression (anti-inflammatorisk)
- Protein-nedbrydning (muskel)
- Fedt-omfordeling

### HPT-aksen (metabolisme)
```
Hypothalamus (TRH) → Hypofyse (TSH) → Thyroidea → T₃/T₄
    ↑                                              │
    └─────────────── Negativ feedback ──────────────┘
```

**T₃/T₄-effekter:**
- BMR ↑ (varmeproduktion)
- Vækst og udvikling (CNS)
- Protein-, fedt-, kulhydrat-metabolisme

### HPG-aksen (reproduktion)
```
Hypothalamus (GnRH) → Hypofyse (FSH/LH) → Gonader → Østrogen/Testosteron
    ↑                                                       │
    └─────────────── Negativ/positiv feedback ──────────────┘
```

## 🩸 Blodsukkerregulering — Insulins pathway

> [!INFO] **Eksamensspørgsmål: "Forklar hvordan blodsukker reguleres"**

```
Højt blodsukker:
    β-celler: Insulin ↑ → GLUT4-translokation
        → Muskel/fedt: glukoseoptag ↑
        → Lever: glykogensyntese ↑, glukoneogenese ↓
        → Blodsukker ↓

Lavt blodsukker:
    α-celler: Glucagon ↑ → Lever: glykogenolyse + glukoneogenese
        → Blodsukker ↑
```

**Signal-pathway (insulin):**
```
Insulin → RTK → IRS → PI3K → Akt → GLUT4 → glukoseoptag
```
