# Ca²⁺-signalering

> [!INFO] **Definition**
> **Ca²⁺-signalering** er intracellulær signalering via calciumioner (Ca²⁺) som second messenger. Ca²⁺ bindes af calmodulin, der aktiverer downstream-effektorer.

> **Kilde:** Campbell Biology (12. udgave) – Kapitel 5, s. 100-101; Kapitel 11, s. 238-239

---

## Mekanisme
1. Ekstracellulært signal (fx hormon) → receptor
2. PLC aktiveres → IP₃ dannes
3. IP₃ åbner Ca²⁺-kanaler i ER → Ca²⁺ frigives
4. Ca²⁺ binder til calmodulin eller troponin C
5. Calmodulin aktiverer CaMK, phosphataser, ionkanaler

## Funktioner
- **Muskelkontraktion**: Ca²⁺-troponin C → cross-bridge cycling
- **Neurotransmitterfrigivelse**: Ca²⁺-indstrømning → exocytose
- **Genregulering**: Ca²⁺ påvirker transkriptionsfaktorer
- **Apoptose**: Forhøjet Ca²⁺ → mitokondriel permeabilitet
