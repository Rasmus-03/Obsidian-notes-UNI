# Cellebiologi

## Cellelæren (Cell Theory)
1. **Alle levende organismer består af én eller flere celler**
2. **Cellen er den grundlæggende enhed for liv** – den mindste enhed der kan udføre livsprocesser
3. **Alle celler opstår fra eksisterende celler** ved celledeling (omnis cellula e cellula)

## Prokaryote vs eukaryote celler

| Træk | Prokaryote | Eukaryote |
|------|-----------|-----------|
| Kerne | Ingen (nukleoid region) | Sand kerne med kernemembran |
| Organeller | Ingen membranbundne organeller | Flere membranbundne organeller (mitokondrier, ER, Golgi m.fl.) |
| Størrelse | 0,5–5 μm | 10–100 μm |
| Ribosomer | 70S | 80S (i cytosol) |
| DNA | Cirkulært, ét kromosom | Lineært, flere kromosomer i kernen |
| Cellevæg | Peptidoglycan (bakterier) | Cellulose (planter) eller chitin (svampe) |
| Reproduktion | Binær fission | Mitose/meiose |
| Flageller | Opmikrobiell (simplere) | Komplekse med 9+2 mikrotubuli-arrangement |

## Cellemikroskopi – typer

| Mikroskoptype | Opløsning | Anvendelse |
|--------------|-----------|------------|
| **Lysmikroskop (LM)** | ~200 nm | Levende celler, overblik |
| **Konfokalmikroskop** | ~200 nm | 3D-rekonstruktion, fluorescens |
| **Transmissionselektronmikroskop (TEM)** | ~0,2 nm | Indre cellestrukturer |
| **Scanningelektronmikroskop (SEM)** | ~0,2 nm | Overfladestrukturer, 3D-overflade |
| **Fluorescensmikroskop** | ~200 nm | Specifikke proteiner/molekyler (via fluorescerende markører) |

## Overblik over eukaryote cellestrukturer

| Struktur | Funktion |
|---------|----------|
| **Plasmamembran** | Selektiv barriere, transport, signalering |
| **Cellekerne** | Opbevaring af DNA, transkription |
| **Ribosomer** | Proteinsyntese (frie = cytosolprotein; bundet til ER = sekretoriske/membranproteiner) |
| **Endoplasmatisk Retikulum (ER)** | RER: proteinsyntese og foldning; SER: lipidsyntese, calcium-lager, afgiftning |
| **Golgi-apparatet** | Modifikation, sortering og pakning af proteiner |
| **Lysosomer** | Nedbrydning af makromolekyler (autofagi, fagocytose) |
| **Mitokondrier** | ATP-produktion via cellulær respiration |
| **Cytoskelet** | Celleform, støtte, motorisk transport, celledeling |
| **Peroxisomer** | Oxidativ nedbrydning af fedtsyrer, neutralisering af reaktive oxygenforbindelser |
