# CYP450 (Cytochrom P450-systemet)

## Definition
**Cytochrom P450 (CYP450)** er en **superfamilie af enzymer** (hovedsageligt i **leverens hepatocytter** og tarmens epithelceller), der **metaboliserer** både **endogene stoffer** (steroidhormoner, fedtsyrer) og **fremmedstoffer** (lægemidler, toksiner). CYP450 er den primære **fase 1-metabolisme** i lægemiddelomsætningen.

## Lokalisation
- **Endoplasmatisk reticulum (glat ER)** – hepatocytter
- **Mitokondrier** – steroidogenese
- **Højst koncentration:** Lever, derefter tarm, lunger, nyrer

## Reaktionsmekanisme
CYP450 katalyserer en **monooxygenase-reaktion:**

```
RH + O₂ + NADPH + H⁺  →  ROH + H₂O + NADP⁺
```

**(RH = substrat; ROH = hydroxylreret produkt)**

**Trin:**
1. **Substratbinding:** RH binder til CYP450s aktive site → hæm-jernet skifter spin (low-spin → high-spin)
2. **Elektron 1:** NADPH-CYP450-reduktase donerer e⁻ via FAD/FMN til hæm-jernet (Fe³⁺ → Fe²⁺)
3. **O₂-binding:** Molekylært oxygen (O₂) binder til det reducerede hæm-jern
4. **Elektron 2:** En anden e⁻ (fra NADPH-CYP450-reduktase eller cytochrom b5) reducerer Fe²⁺-O₂-komplekset
5. **O₂-spaltning:** Den spaltes → én O-atom inkorporeres i RH (→ ROH), det andet danner H₂O
6. **Produktfrigivelse:** ROH (hydroxyleret, polær) frigives → klar til **fase 2-konjugering**

## Vigtigste CYP450-isoformer

| Isoform | Andel af CYP | Substrater | Kompetitive hæmmere |
|---------|-------------|------------|---------------------|
| **CYP3A4** | ~30% | Statiner, Ca-antagonister, midazolam, makrolider | Ketoconazol, grapefrugtjuice |
| **CYP2D6** | ~20% | β-blokkere, opioider (kodein → morfin), SSRI | Paroxetin, fluoxetin |
| **CYP2C9** | ~15% | Warfarin, NSAID (ibuprofen), glipizid | Amiodaron, fluconazol |
| **CYP2C19** | ~10% | Omeprazol, clopidogrel (prodrug → aktivt) | Omeprazol (selv), fluconazol |
| **CYP2E1** | ~5% | Ethanol, paracetamol → NAPQI (toksiske metabolit) | Disulfiram |

## Polymorfisme (klinisk vigtig)
- **CYP2D6-phenotyper:** Poor (PM) / Intermediate (IM) / Extensive (EM) / Ultrarapid (UM)
  - **PM (7–10% af kaukasiere):** ↓ kodein → morfin → ↓ smertestillende; ↑ bivirkninger af metoprolol
  - **UM:** ↑ metabolisme → subklinisk effekt af normale doser

## Kliniske implikationer
- **Lægemiddelinteraktioner:** En hæmmer af CYP3A4 (fx grapefrugt) → ↑ koncentration af samtidig medicin (fx simvastatin) → risiko for toksicitet
- **Prodrugs:** Omsættes af CYP (fx clopidogrel → aktiv metabolit via CYP2C19)
- **Paracetamolforgiftning:** CYP2E1 omsætter paracetamol til NAPQI → glutation udtømmes → hepatotoksicitet (behandling: N-acetylcystein)
- **Induktion:** Rygning (CYP1A2) / alkohol (CYP2E1) / rifampicin (CYP3A4) → ↑ metabolisme af andre lægemidler

## Relationer
- ← **Fase 1-metabolisme** (lever)
- → **Fase 2-konjugering** (glucuronidering, sulfatering)
- ← **Lægemiddelinteraktioner**
- → **Toksikologi** (NAPQI)
- ← **Genetisk polymorfi** (CYP2D6, CYP2C19, CYP2C9)
