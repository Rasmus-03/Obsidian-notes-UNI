# G-proteiner (Guanin-nukleotid-bindende proteiner)

## Definition
**G-proteiner** er **molekylære omskiftere (molecular switches)** der kobler **ekstracellulære signaler** (fra G-protein-koblede receptorer, GPCR'er) til **intracellulære effektorer**. De er heterotrimere (α, β, γ) og binder GDP/GTP.

## Opbygning
- **Gα-subenhed:** GDP/GTP-bindende; GTPase-aktivitet
- **Gβγ-kompleks:** Tight bundet; fungerer som én enhed
- **GPCR (7-transmembran-receptor):** Aktiverer G-proteinet ved at katalysere GDP→GTP-udveksling

## Aktiveringscyklus (mekanisme)
1. **Hviletilstand:** Gα bundet til **GDP** → Gαβγ-komplekset er **intakt** og inaktivt
2. **Ligandbinding til GPCR:** Hormon/neurotransmitter binder → GPCR skifter konformation → virker som **GEF (guanin-nukleotid exchange factor)** for Gα
3. **GDP → GTP:** Gα frigiver GDP → binder GTP → Gα og Gβγ dissocierer
4. **Effektoraktivering:**
   - **Gα-GTP** ± **Gβγ** aktiverer hver især forskellige **downstream effektorer**
5. **Inaktivering:** Gα's **intrinsiske GTPase-aktivitet** hydrolyserer GTP → GDP → Gα-GDP genfornes med Gβγ → inaktiv

## Vigtigste Gα-familier og signalveje

| Familie | Gα-type | Effektor | Second messenger | Eksempel |
|---------|---------|----------|-----------------|----------|
| **Gs** | Gαs | ↑ Adenylyl cyclase | ↑ cAMP ↑ PKA | β-adrenerge receptorer, glucagon |
| **Gi** | Gαi | ↓ Adenylyl cyclase | ↓ cAMP | α₂-adrenerge, muskarin M₂ |
| **Gq** | Gαq | ↑ Phospholipase C (PLC) | IP₃ + DAG (→ Ca²⁺ + PKC) | α₁-adrenerge, muskarin M₁/M₃ |
| **G12/13** | Gα12/13 | ↑ RhoGEF | Rho → cytoskelet-ombygning | Thrombin-receptorer |

## Signalforstærkning
Én aktiveret GPCR → aktiverer ~10–20 G-proteiner → hver Gαs aktiverer adenylyl cyclase → **hundredvis af cAMP** → hver PKA fosforylerer **mange target-proteiner** → enorm forstærkning

## Klinisk relevans
- **Choleratoksin:** ADP-ribosylerer Gαs → blokerer GTPase → **konstitutiv Gs-aktivitet** → ↑ cAMP → vandtab til tarmen (diarré)
- **Kighostetoksin (pertussis):** ADP-ribosylerer Gαi → **blokerer hæmning** af adenylyl cyclase → ↑ cAMP
- **Mutasjoner:** Gαs-mutationer kan give endokrine tumorer (fx mcCune-Albright)
- **β-blokkere:** Blokerer β-receptorer (Gs-koblede) → ↓ cAMP → ↓ hjertefrekvens og kontraktilitet
- **Lægemidler:** 30–40% af alle markedsførte lægemidler virker via GPCR'er

## Relationer
- ← **GPCR** (7TM-receptor)
- → **Adenylyl cyclase** / **cAMP** / **PKA**
- → **PLC / IP3 / DAG / PKC**
- ← **GTP → GDP** (regulering)
- → **Fysiologisk respons** (kontraktion, sekretion, transkription)
