## Tight Junctions (Zonula Occludens)

**Tight junctions** er **intercellulære forbindelser** mellem epitelceller, der **forsegler** mellemrummet og kontrollerer **paracellulær transport**.

### Struktur
- **Proteiner:**
  - **Claudiner** (24 isoformer) – *primære barriereprotein*
  - **Occludin** – regulatorisk
  - **JAMs** (junctional adhesion molecules) – adhæsion
- **Cytoplasmatiske adaptere:** **ZO-1, ZO-2, ZO-3** → forankrer til actincellecytoskelet

### Funktioner

| Funktion | Mekanisme |
|----------|-----------|
| **Barriere** | Forhindrer ukontrolleret diffusion mellem epitelceller |
| **Paracellulær selektivitet** | Claudiner bestemmer **ladning** + **størrelse** af partikler der kan passere |
| **Apikal-basolateral polaritet** | Forhindrer diffusion af membranproteiner mellem apikal/basolateral domæne |
| **Signalering** | ZO-proteiner forbinder til celleproliferation + differentiering |

### Paracellulær transport-selektivitet

| Type | Ladning | Eksempel claudin |
|------|---------|------------------|
| **Cation-selektiv** | Pos. ioner (Na⁺) → passere | Claudin-2, -10b, -15 |
| **Anion-selektiv** | Neg. ioner (Cl⁻) → passere | Claudin-10a, -17 |
| **Tæt** (vand/uioniseret) | Kun vand + små neutrale molekyler | Claudin-1, -4, -5 |

### Localisering
```
Apikal (lumen)
    │
├── Tight junction ──┤  ← Zonula Occludens (zona = bælte rundt om cellen)
├── Adherens junction ─┤
├── Desmosom ───────┤
    │
Basolateral (blod/interstitium)
```

### Klinisk relevans
- **Inflammatorisk tarmsygdom (IBD):** ↓ claudin-1 + ↑ claudin-2 → ↓ barriere → ↑ paracellulær permeabilitet → inflammation
- **Hepatitis C-virus:** bruger claudin-1 + occludin som receptorer til at inficere hepatocytter
- **Hæmoragisk feber** (Ebola, SARS-CoV-2): ↓ tight junction-integritet → vaskulær lækage
- **Cøliaki:** Gliadin (gluten) → ↑ zonulin → tight junctions åbnes → ↑ permeabilitet
