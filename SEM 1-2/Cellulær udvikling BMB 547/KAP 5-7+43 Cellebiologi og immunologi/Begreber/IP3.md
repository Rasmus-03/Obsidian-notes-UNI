# IP3 (Inositoltrifosfat)

## Definition
IP3 er en intracellulær andenbudbringer (second messenger) dannet ved hydrolyse af PIP2 (fosfatidylinositol-4,5-bisfosfat) via phospholipase C (PLC). IP3 mobiliserer Ca2+ fra intracellulære depoter (endoplasmatisk reticulum).

## Signalvej
1. Ekstracellulært signal (hormon/neurotransmitter) binder til Gq-koblet receptor
2. Gq aktiverer phospholipase C (PLC)
3. PLC spalter PIP2 → IP3 + DAG (diacylglycerol)
4. IP3 diffunderer til cytosol og binder IP3-receptorer på ER
5. Ca2+-kanaler åbnes → Ca2+ strømmer ud i cytosol
6. Ca2+ fungerer som tredje budbringer (muskelkontraktion, sekretion, genregulering)

## IP3 vs DAG

| Molekyle | Lokalisation | Funktion |
|----------|-------------|----------|
| **IP3** | Vandopløselig, cytosol | Frigiver Ca2+ fra ER |
| **DAG** | Membranbundet | Aktiverer PKC (protein kinase C) |

## Relation til G-proteiner
- Gq-proteiner → PLC → IP3 + DAG → Ca2+-signal
- Gs-proteiner → adenylatcyclase → cAMP → PKA
- Gi-proteiner → hammer adenylatcyclase → nedsat cAMP
