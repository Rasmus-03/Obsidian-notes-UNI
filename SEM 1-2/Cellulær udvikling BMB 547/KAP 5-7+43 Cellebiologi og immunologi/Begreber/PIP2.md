# PIP₂ (Phosphatidylinositol-4,5-bisphosphat)

## Definition
**PIP₂** er et **membranfosfolipid** der fungerer som **forløber** for de to vigtige **second messengers**: **IP₃ (inositol-1,4,5-trisphosphat)** og **DAG (diacylglycerol)**. PIP₂ spiller en central rolle i **Gq-protein**-signalering og findes i den **cytoplasmatiske side af plasmamembranen**.

## Opbygning
- **Phosphatidylinositol (PI)** – en phospholipid med **inositol** som hovedgruppe
- **Fosforyleres** i position 4 og 5 → **PIP₂** (Phosphatidylinositol-4,5-bisphosphat)
- Andelen i membranen: ~1% af alle fosfolipider

## Mekanisme – IP₃/DAG-vejen

```
Ligand → GPCR (Gq) → Gαq-GTP → Phospholipase C (PLC-β)
                                                 ↓
                                          PIP₂ spaltes
                                         /             \
                                        /               \
                                   IP₃ (vandopløselig)   DAG (membranbundet)
                                        ↓                    ↓
                              IP₃-receptor på SR/ER     Aktiverer PKC
                              → Ca²⁺-kanal åbner        → fosforylerer target-proteiner
                              → Ca²⁺ frigives til cytosol
```

### Trin for trin
1. **Ligandbinding:** Hormon/neurotransmitter (fx noradrenalin, ACh, angiotensin II) binder til **Gq-koblet receptor**
2. **Gαq aktivering:** GDP → GTP → Gαq-GTP dissocierer
3. **PLC-β aktivering:** Gαq-GTP aktiverer **phospholipase C (PLC-β)** som spalter PIP₂
4. **Produkter:**
   - **IP₃** diffunderer til cytosol → binder **IP₃-receptor (IP₃R)** på SR/ER → Ca²⁺-kanal åbner → Ca²⁺ strømmer ud i cytosol → Ca²⁺ aktiverer calmodulin, CaMKII, kontraktion, eksocytose
   - **DAG** bliver i membranen → rekrutterer **PKC (proteinkinase C)** → PKC aktiveres af Ca²⁺ + DAG → fosforylerer target-proteiner

## Andre funktioner for PIP₂
- **Forankring af cytoskelet:** PIP₂ binder actin-bindende proteiner (fx profilin, cofilin, gelsolin) → regulerer actin-dynamik
- **Regulering af ionkanaler:** PIP₂ aktiverer K⁺-kanaler (fx KCNQ/Kv7) og hæmmer TRPV1
- **Forløber for PI3K-vejen:** PIP₂ → PIP₃ (via PI3-kinase) → Akt/PKB-signalering (overlevelse/vækst)
- **Membranidentitet:** PIP₂ er markør for plasmamembranen (genkendes af PH-domæne-proteiner)

## Regulering
- **PLC-β** spalter PIP₂ → nedregulering
- **PI3K** fosforylerer PIP₂ til PIP₃ → aktiverer Akt
- **PI5K (PI4P 5-kinase)** syntetiserer PIP₂ fra PI4P
- **PTEN** defosforylerer PIP₃ tilbage til PIP₂ → hæmmer PI3K/Akt-vejen (tumorsuppressor)

## Klinisk relevans
- **Lithium (Li⁺):** Hæmmer IPP (inositol monophosphatase) → ↓ IP₃-genanvendelse → ↓ PIP₂ → mod stabilisering af humør ved bipolar lidelse
- **PTEN-mutationer:** ↑ PIP₃ → ↑ Akt → cancer (prostata, bryst, glioblastom)
- **PLC-mutationer:** X-linked immunodefekt (PLCγ2-mangel)
- **Ca²⁺-signalering:** IP₃-medieret Ca²⁺-frigivelse er central i hjertet, glat muskel, immunceller og neuroner

## Relationer
- ← **Gq** (G-protein)
- ← **GPCR** (receptor)
- → **IP₃** → Ca²⁺ → kontraktion, sekretion, genregulering
- → **DAG** → PKC → fosforylering
- ← **PLC-β** (spaltning)
- ← **PI3K / PTEN** (signalregulering)
