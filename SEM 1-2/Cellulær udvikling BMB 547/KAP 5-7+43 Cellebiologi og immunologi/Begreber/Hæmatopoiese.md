# Hæmatopoiese (bloddannelse)

**Hæmatopoiese** er dannelsen af blodceller i knoglemarven. Starter fra hæmatopoietiske stamceller (HSC).

## Nøglepunkter
| Linje | Celler | Funktion |
|-------|--------|----------|
| **Myeloid** | Erytrocytter | O₂-transport |
| | Trombocytter | Koagulation |
| | Neutrofiler, monocytter | Fagocytose |
| **Lymfoid** | B-celler, T-celler, NK-celler | Immunforsvar |

- **HSC's egenskaber**: selvfornyelse + differentiering
- **Erythropoietin (EPO)**: stimulerer erytrocyt-produktion (nyre)
- **Cytokiner**: CSF, interleukiner → regulerer hæmatopoiese
