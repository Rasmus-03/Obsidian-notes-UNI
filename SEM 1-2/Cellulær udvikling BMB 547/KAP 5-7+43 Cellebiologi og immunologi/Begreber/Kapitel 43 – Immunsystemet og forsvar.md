## Immunsystemet og forsvar (oversigt)

Immunsystemet består af **medfødte** (uspecifikke) og **adaptive** (specifikke) forsvarsmekanismer.

### Medfødt immunitet (hurtig, ikke-specifik)

| Barriere/celle | Funktion |
|----------------|----------|
| **Hud, slimhinder** | Fysisk barriere |
| **Neutrofile granulocytter** | Fagocytose, toksiske molekyler |
| **Makrofager** | Fagocytose, antigen-præsentation |
| **NK-celler** | Dræber virus-inficerede celler |
| **Dendritiske celler** | Antigen-præsentation → aktiverer T-celler |
| **Mastceller** | Allergi, parasitter (histamin, heparin) |
| **Komplementsystemet** | Opsonisering, lysis, inflammation |
| **DAMPs/PAMPs/PRRs** | Genkender farlige molekyler (TLR'er) |

### Adaptiv immunitet (langsom, specifik, hukommelse)

| Komponent | Funktion |
|-----------|----------|
| **B-celler** | Antistofproduktion (humoral) |
| **CD4⁺ T-celler** | Hjælperceller (aktiverer makrofager, B-celler) |
| **CD8⁺ T-celler** | Cytotoksiske (dræber inficerede celler) |
| **Memory-celler** | Hurtigere og stærkere ved geninfektion |

### Immunresponsets faser

1. **Genkendelse:** PRRs (TLR, NOD) genkender PAMPs (f.eks. LPS, flagellin)
2. **Aktivering:** Inflammation → cytokin-frigivelse → rekruttering af immunceller
3. **Adaptiv respons:** Dendritiske celler migrerer til lymfeknuder → præsenterer antigen på MHC → T-celle-aktivering
4. **Effektorrespons:** Antistoffer, cytotoksiske T-celler, makrofager
5. **Resolution:** Inflammation dæmpes → homeostase

### Inflammationskaskade (5 tegn)
- **Rubor** (rødme) – vasodilatation
- **Calor** (varme) – øget blodgennemstrømning
- **Tumor** (hævelse) – øget permeabilitet → væske + celler ud
- **Dolor** (smerte) – prostaglandiner, bradykinin
- **Functio laesa** (nedsat funktion) – resultat af ovenstående

### Vigtige cytokiner
| Cytokin | Kilde | Effekt |
|---------|-------|--------|
| **IL-1** | Makrofager | Feber, inflammation |
| **IL-6** | Makrofager, T-celler | Aktivering, feber |
| **TNF-α** | Makrofager | Inflammation, feber, shock |
| **IL-10** | Treg, makrofager | Anti-inflammatorisk |
| **IFN-γ** | Th1, NK | Aktiverer makrofager |
| **IL-4** | Th2 | B-celle-isotype-switch → IgE |

### Klinisk relevans
- **Autoimmunitet:** Tab af tolerance → immunsystem angriber selv (SLE, MS, type 1 DM)
- **Immunsuppression:** HIV/AIDS, kemoterapi, transplantation
- **Hypersensitivitet:** Allergi (type I), cytotoksisk (type II), immunkompleks (type III), forsinket (type IV)
