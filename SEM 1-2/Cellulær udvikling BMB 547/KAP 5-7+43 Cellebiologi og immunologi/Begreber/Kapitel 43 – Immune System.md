## Key Points
- **Innate immunity**: fast, non-specific (skin, phagocytes, complement, inflammation)
- **Adaptive immunity**: slow, specific, memory (B cells, T cells)
- **B cells**: produce antibodies → neutralize extracellular pathogens
- **T cells**: helper (CD4+) activate others; cytotoxic (CD8+) kill infected cells
- **MHC class I**: all cells present intracellular antigens → CD8+
- **MHC class II**: APCs present extracellular antigens → CD4+

## Exam Training
- Q: "Compare innate vs adaptive immunity" → specificity, speed, memory
- Q: "Explain the role of MHC" → antigen presentation to T cells
