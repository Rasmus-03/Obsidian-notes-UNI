# Temporallappen

## Definition
**Temporallappen (lobus temporalis)** er en af hjernens fire store lapper, beliggende under **sylvius-furen** (fissura lateralis). Den er centrum for **auditiv bearbejdning, sprogforståelse, hukommelse, følelser og genkendelse**.

## Anatomi
- **Superior temporale gyrus (STG)** – primær auditiv cortex (BA 41/42)
- **Mediale temporallap (MTL)** – hippocampus, amygdala, entorhinal cortex
- **Inferior temporale gyrus** – visuel genkendelse (hvad-banen)

## Funktioner

| Funktion | Område | Mekanisme |
|----------|--------|-----------|
| **Hørelse** | BA 41/42 (Heschls tværgyri) | Tonotopisk kort; bearbejder frekvens, styrke, lydlokalisering via ITD/ILD |
| **Sprogforståelse** | Wernickes område (BA 22, posterior) | Fonologisk → semantisk kortlægning; forbindes til Brocas område via fasciculus arcuatus |
| **Hukommelse** | Hippocampus (CA1-3, dentate gyrus) | Langtidspotentiering (LTP) via NMDA-receptorer → konsolidering af deklarativ hukommelse |
| **Følelser** | Amygdala | Vurderer trusler (frygt)/belønning; modulerer hippocampus-konsolidering via emotionel arousal |
| **Visuel genkendelse** | Inferior temporale cortex (IT) | "Hvad-banen" – genkender objekter, ansigter (fusiforme face area) |

## Mekanisme – hukommelseskonsolidering (hippocampus)
1. **Encoding:** Sensorisk input → entorhinal cortex → dentate gyrus → CA3 (via mossy fibers) → CA1 (via Schaffer collaterals)
2. **Lagring:** CA1 sender signaler til cortex (langtidslagring)
3. **LTP:** Højfrekvent stimulation → NMDA-receptorer åbner → Ca²⁺-influx → aktivering af CaMKII → ↑ AMPA-receptorer i synapsen → **styrket synaptisk transmission** (→ hukommelse)
4. **Konsolidering under søvn:** Replay af neurale mønstre (hippocampus → cortex)

## Klinisk relevans
- **Wernickes afasi:** Skade i posterior STG → flydende tale (meningsløs) med nedsat forståelse
- **Alzheimers:** Først hippocampus → medial temporal atrofi → hukommelsestab (AP42-β plaques, tau-tangles)
- **Temporallaps-epilepsi:** Fokale anfald (aura, déjà vu, bevidsthedspåvirkning)
- **Prosopagnosi:** Skade i fusiforme ansigtsområde → manglende ansigtsgenkendelse

## Relationer
- ← **Auditive cortex**
- ← **Hippocampus** (hukommelse)
- ← **Amygdala** (følelser)
- → **Frontallappen** (via fasciculus arcuatus)
- → **Broca** (sprogproduktion)
