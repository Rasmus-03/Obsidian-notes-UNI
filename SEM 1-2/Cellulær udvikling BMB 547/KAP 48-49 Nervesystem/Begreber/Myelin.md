# Myelin

## Definition
**Myelin** er en **fedtholdig isolerende skede** omkring axoner i både centralnervesystemet (CNS) og perifere nervesystem (PNS). Myelinet dannes af **oligodendrocytter** (CNS) og **Schwann-celler** (PNS) og muliggør **hurtig saltatorisk ledning** af aktionspotentialer.

## Opbygning
- **Lipider (70%)** – hovedsageligt galaktocerebroside, sfingomyelin, kolesterol
- **Proteiner (30%)** – myelin basic protein (MBP), proteolipidprotein (PLP), myelin-associated glycoprotein (MAG)
- **Spiralformet membran** – cellen vikler sig flere gange om axonet → **kompakt myelin**

## Mekanisme – saltatorisk ledning
1. Myelinet isolerer axonet elektrisk → **kapacitans ↓** og **modstand ↑** → membranpotentialet kan ikke ændres under myelin
2. **Spændingsstyrede Na⁺-kanaler** findes kun i **Ranvierske indsnøringer**
3. Aktionspotentialet "depolariserer" næste indsnøring via **elektrotonisk (passiv) strømspredning** gennem axoplasmat
4. Na⁺-kanalerne i næste indsnøring åbner → nyt aktionspotentiale
5. **Hastighed:** op til 120 m/s (umyeliniseret: 0,5–2 m/s)
6. **Energibesparelse:** ↓ Na⁺/K⁺-pumpeaktivitet (kun ved indsnøringerne)

## Forskel CNS vs PNS

| Egenskab | CNS (oligodendrocyt) | PNS (Schwann-celle) |
|---------|----------------------|---------------------|
| Antal axoner pr. glia | Én celle myelinerer **flere axoner** | Én celle myelinerer **ét** axon |
| Basallamina | Nej | Ja |
| Regeneration | Dårlig (inhibitoriske faktorer som Nogo) | God (Schwann-celler guider vækst) |
| Skader | MS → faste plaques | Guillain-Barré → segmental demyelinisering |

## Klinisk relevans
- **Multipel sklerose:** Autoimmun reaktion mod MBP/PLP → demyelinisering → blokeret ledning → sensoriske/motoriske symptomer
- **Leukodystrofier:** Genetiske defekter i myelinmetabolisme (fx adrenoleukodystrofi)
- **Guillain-Barré:** Autoimmun reaktion efter infektion → demyelinisering af PNS → ascenderende paralyse
- **Demyelinisering** → ledningsblok, men også **hyperexcitabilitet** (ektopiske aktionspotentialer) → paræstesier

## Relationer
- ← **Oligodendrocytter** / **Schwann-celler**
- → **Saltatorisk ledning**
- ← **Axoner** (det der myelineres)
- → **Nervesignalets hastighed**
