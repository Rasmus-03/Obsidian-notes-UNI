# Kapitel 48 – Nervesystemet

> [!tip] **For en 5-årig:**  
> Nervesystemet er kroppens lynhurtige kommunikationsnetværk. Hjernen er chefkontoret, rygmarven er hovedkablet, og nerverne er ledningerne der sender beskeder som elektriske signaler til alle kropsdele.

## Opbygning

### Centralnervesystemet (CNS)
- **Hjerne**: cerebrum (tænkning, sprog), cerebellum (balance, koordination), hjernestamme (basale funktioner)
- **Rygmarv**: forbinder hjerne → krop, reflekscentre

### Perifere nervesystem (PNS)
- **Sensoriske nerver**: signaler → CNS
- **Motoriske nerver**: signaler → muskler/kirtler
- **Autonome nervesystem**: sympatisk (kamp/flugt), parasympatisk (hvil/fordøj)

## Nervecellen (neuron)
1. **Dendritter**: modtager signaler
2. **Soma**: cellekrop, integrerer signaler
3. **Axon**: leder signal (AP) væk
4. **Synapse**: overfører signal til næste celle

## Hvilemembranpotentiale (-70 mV)
- Høj K⁺ inde, høj Na⁺ ude (Na⁺/K⁺-ATPase)
- K⁺-kanaler åbne → K⁺ strømmer ud → negativ inde
- Se [[Nernst-ligningen]] og [[Goldman-ligningen]]

## Aktionspotentialet
1. **Hvile**: -70 mV
2. **Depolarisering**: Na⁺-kanaler åbner → Na⁺ ind → +30 mV
3. **Repolarisering**: Na⁺-kanaler lukker, K⁺-kanaler åbner → K⁺ ud
4. **Hyperpolarisering**: K⁺-kanaler stadig åbne → under hvile
5. **Refraktærperiode**: absolut (ny AP umulig) + relativ (sværere)

## Synaptisk transmission
- **Kemisk synapse**: AP → Ca²⁺ ind → neurotransmitter frigives → postsynaptisk respons
- **EPSP**: depolariserer (Na⁺ ind) → lettere AP
- **IPSP**: hyperpolariserer (Cl⁻ ind / K⁺ ud) → sværere AP

## Eksamenstræning
- Spørgsmålstype: "Forklar aktionspotentialets faser" → depolarisering → repolarisering → hyperpolarisering
- Spørgsmålstype: "Hvad er hvilemembranpotentiale og hvorfor -70 mV?" → Na⁺/K⁺-pumpe + K⁺ leak-kanaler
- Spørgsmålstype: "Forskel på EPSP og IPSP" → EPSP: depolariserer; IPSP: hyperpolariserer
