# Perifert Nervesystem (PNS)

> [!INFO] **Definition**
> **Det perifere nervesystem (PNS)** består af alle **nerver og ganglier** uden for hjernen og rygmarven. Det forbinder centralnervesystemet (CNS) med resten af kroppen og opdeles i somatisk og autonomt nervesystem.

> **Kilde:** Campbell Biology (12. udgave) – Kapitel 48, s. 1130-1131

---

## Opdeling

```
PNS
├── Somatisk nervesystem (bevidst kontrol)
│   ├── Afferent (sensorisk) → CNS
│   └── Efferent (motorisk) → skeletmuskulatur
└── Autonome nervesystem (uvilkårlig kontrol)
    ├── Sympatikus (kamp/flugt)
    └── Parasympatikus (rest/digest)
```

## Nerveopbygning
| Komponent | Beskrivelse |
|-----------|-------------|
| **Aksonbundt** | Flere aksoner samlet |
| **Endoneurium** | Bindevæv omkring enkelt akson |
| **Perineurium** | Bindevæv omkring aksonbundt |
| **Epineurium** | Yderste bindevævslag |

## Regeneration i PNS
- PNS kan **regenerere** (Schwann-celler hjælper) – CNS kan ikke
- Wallersk degeneration distalt for skade → Schwann-celler ← → ny vækst
