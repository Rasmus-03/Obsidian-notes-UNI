# Nervesystemets farmakologi

> [!tip] **For en 5-årig:**  
> Medicin kan ændre, hvordan nerver sender beskeder. Nogle stoffer gør beskederne stærkere, nogle svagere, og nogle blokerer dem helt – ligesom at skrue op eller ned for lyden på en højttaler.

## Principper for synaptisk påvirkning
| Mekanisme | Eksempel |
|-----------|----------|
| **Agonist** = aktiverer receptoren | Nicotin aktiverer ACh-receptorer |
| **Antagonist** = blokerer receptoren | Curare blokerer ACh-receptorer |
| **Reuptake-hæmmer** = øger transmitter-niveau | SSRI (fluoxetin) → øget serotonin |
| **Enzymhæmmer** = forhindrer nedbrydning | Donepezil hæmmer AChE |

## Neurotransmittersystemer

### Kolinergt system (ACh)
| Lægemiddel | Virkning |
|------------|----------|
| Atropin | Antagonist → pupiludvidelse, mundtørhed |
| Botulinumtoksin | Hæmmer ACh-frigivelse → lammelse |
| Donepezil | AChE-hæmmer → Alzheimers behandling |

### Monoaminerge systemer
| Transmitter | Lægemiddel | Funktion |
|-------------|------------|----------|
| **Dopamin** | L-DOPA (Parkinson), antipsykotika | Bevægelse, belønning |
| **Noradrenalin** | Betablokkere, antidepressiva | Kamp/flugt, opmærksomhed |
| **Serotonin** | SSRI, LSD | Humør, appetit, hallucinationer |

### GABA-systemet
- **Benzodiazepiner** (diazepam): GABA-agonister → angstløsende
- **Barbiturater** (phenobarbital): GABA-agonister → sedation
- **Alkohol**: GABA-agonist + glutamat-antagonist

### Glutamat-systemet
- **NMDA-antagonister**: ketamin (anæstesi, depression)
- **AMPA-antagonister**: perampanel (epilepsi)

## Klinisk relevans
- **Narkose**: kombination af GABA-agonist + NMDA-antagonist
- **Smertebehandling**: opioider (μ-receptor-agonister)
- **Depression**: SSRI, SNRI → øget monoaminerg transmission
