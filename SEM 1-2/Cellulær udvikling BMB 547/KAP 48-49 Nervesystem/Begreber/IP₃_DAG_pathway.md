# IP₃/DAG-signalvejen

> [!INFO] **Definition**
> **IP₃/DAG-vejen** er en **G-proteinkoblet signalvej**, hvor aktivering af **phospholipase C (PLC)** nedbryder **PIP₂** til **IP₃** (inositoltrisphosphat) og **DAG** (diacylglycerol). Disse second messengers frigiver Ca²⁺ hhv. aktiverer PKC.

> **Kilde:** Campbell Biology (12. udgave) – Kapitel 48, s. 1130-1131

---

## Signalvej-trinnene

1. **Ligand** → **GPCR** → aktiverer **Gq-protein**
2. **Gq** → aktiverer **Phospholipase C (PLC)**
3. **PLC** → spalter **PIP₂** (phosphatidylinositol-4,5-bisphosphat) til:
   - **IP₃** (vandopløseligt) → diffunderer til cytosol
   - **DAG** (membranbundet) → bliver i membranen

## IP₃'s rolle
- Binder til **IP₃-receptorer** på endoplasmatisk reticulum (ER)
- → Åbner Ca²⁺-kanaler → **Ca²⁺ frigives** fra ER til cytosol
- Ca²⁺ → aktiverer calmodulin, CaMKII, andre Ca²⁺-afhængige proteiner

## DAG's rolle
- Rekrutterer **PKC** (Proteinkinase C) til membranen
- PKC aktiveres af **DAG + Ca²⁺** → phosphorylerer målproteiner

## Fysiologiske funktioner

| Funktion | Eksempel |
|----------|----------|
| **Muskelkontraktion** | Glat muskel (acetylcholin → M3 → IP₃) |
| **Neurotransmitterfrigivelse** | Synaptisk transmission |
| **Immunrespons** | T-celle-aktivering |
| **Vækst/deling** | Mitogen signalering |
| **Synaptisk plasticitet** | Metabotrop glutamatreceptor → LTP |
