# Fordøjelse — Fra Mund til Celle

> **Kerne-pathway:** Maden nedbrydes mekanisk og kemisk → næringsstoffer absorberes → affald elimineres. Hele processen er hormonelt og neuralt reguleret.

---

## 📍 Oversigt — Fordøjelseskanalen

```
Mund → Spiserør → Mave → Tyndtarm (duodenum → jejunum → ileum)
                          ↓
                       Tyktarm (colon) → Endetarm → Anus
                          ↓
                      (vandabsorption)
```

## 🔬 Makronæringsstoffernes fordøjelse

> [!INFO] **Eksamensspørgsmål: "Redegør for fordøjelsen af kulhydrater, proteiner og fedt"**

### 🥖 Kulhydrater
| Lokation | Enzym(er) | Substrat → Produkt |
|----------|-----------|-------------------|
| Mund | Spyt-amylase | Stivelse → maltose (kortvarig) |
| Tyndtarm | Pancreas-amylase | Stivelse → maltose |
| Børstesøm | Maltase, sucrase, laktase | Disakkarider → monosakkarider |

**Absorption:** SGLT1 (glukose/galaktose, Na⁺-cotransport), GLUT5 (fruktose) → portalvene → lever

### 🥩 Proteiner
| Lokation | Enzym(er) | Substrat → Produkt |
|----------|-----------|-------------------|
| Mave | Pepsin (pH 2) | Proteiner → peptider |
| Tyndtarm | Trypsin, chymotrypsin, carboxypeptidase | Peptider → korte peptider + aminosyrer |
| Børstesøm | Aminopeptidaser | Korte peptider → aminosyrer |

**Absorption:** Na⁺-afhængige cotransportere (aminosyrer), PepT1 (di-/tripeptider) → portalvene

### 🧈 Fedt
| Lokation | Komponent | Funktion |
|----------|-----------|----------|
| Mave | Gastrisk lipase | Fedt-emulsificering (minimal) |
| Tyndtarm | Pancreas-lipase + colipase | Triglycerider → monoglycerider + frie fedtsyrer |
| Galde | Galdesalte | Emulsificering (øger overfladeareal) |

**Absorption:**
```
Miceller (galdesalte + lipider) → enterocyt
    → Resyntese til triglycerider
    → Pakkes i chylomikroner (apolipoprotein B-48)
    → Lymfen (lactealer) → ductus thoracicus → blodet
```

> [!question] Eksamensspørgsmål
> **"Hvorfor transporteres fedt via lymfen, mens kulhydrater og proteiner går via portalvenen?"**
> *Svar: Fedtsyrer og monoglycerider resyntetiseres til triglycerider i enterocytter → for store til at gå direkte i blodet → pakkes i chylomikroner → lymfen. Kulhydrat- og protein-spaltningsprodukter er vandopløselige og går direkte til leveren via portalvenen.*

## 🧪 Hormonel regulering af fordøjelsen

> [!INFO] **Eksamensspørgsmål: "Forklar de tre faser af fordøjelsesregulering"**

### 1. Cephalisk fase (hjernen)
```
Syn/lugt/smag → CNS → Vagus (parasympatikus)
    → Mave: gastrin ↑, syresekretion ↑
    → Pancreas: enzymer sekreres
```

### 2. Gastrisk fase (maven)
```
Maden ankommer → stræk + kemiske stimuli
    → G-celler: gastrin ↑ → syresekretion ↑
    → Pepsinogen → pepsin (aktiveres af pH 2)
```

### 3. Intestinal fase (tyndtarmen)
```
Chymus ankommer → pH ↓, fedt ↑, peptider ↑
    → Sekretin (S-celler): pancreas-bicarbonat ↑
    → CCK (I-celler): pancreas-enzymer ↑, galdeblære-kontraktion ↑
    → GIP: insulin-sekretion, mavetømning ↓
```

**Hormon-oversigt:**

| Hormon | Stimuleres af | Effekt |
|--------|--------------|--------|
| **Gastrin** | Stræk, protein, vagus | Syresekretion ↑, mave-tømning ↓ |
| **Sekretin** | pH ↓ i duodenum | Pancreas HCO₃⁻ ↑, galde ↑, mave-syre ↓ |
| **CCK** | Fedt, protein i duodenum | Pancreas-enzymer ↑, galdeblære-kontraktion |
| **GIP** | Glukose, fedt | Insulin ↑, mave-tømning ↓ |
| **Ghrelin** | Tom mave | Sultfølelse |
| **PYY** | Føde (colon) | Mæthed, appetit ↓ |

## 🩺 Kliniske perspektiver

| Sygdom | Årsag | Konsekvens |
|--------|-------|-----------|
| **Laktoseintolerance** | Laktasemangel | Uabsorberet laktose → osmotisk diarré, oppustethed |
| **Cøliaki** | Autoimmun → villi-atrofi | Malabsorption |
| **Crohns** | Kronisk inflammation i tyndtarm | Smerter, diarré, malabsorption |
| **Cystisk fibrose** | CFTR-mutation → tykt sekret | Pancreas-insufficiens → malabsorption |
| **Galdesten** | Kolesterol-krystaller | Fedt-malabsorption (steatorré) |
