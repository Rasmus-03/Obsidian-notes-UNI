# Leveren — Kroppens Metaboliske Hub

> **Kerne-pathway:** Leveren (hepatocytter) er central for metabolisme, lagring, detoxifikation og galde-produktion. Den modtager alt fra tarmen via portalvenen.

---

## 📋 Leverens 7 hovedfunktioner

| Funktion | Detaljer |
|----------|----------|
| **1. Metabolisk regulering** | Glukoneogenese, glykogenolyse, glykogensyntese |
| **2. Fedt-metabolisme** | Lipogenese, ketonproduktion, lipoprotein-syntese |
| **3. Protein-metabolisme** | Proteinsyntese (albumin, koagulationsfaktorer), deaminering, urinstof-cyklus |
| **4. Galde-produktion** | Galdesalte (fedt-emulsificering), bilirubin-ekskretion |
| **5. Detoxifikation** | CYP450-system (fase I + II), ammoniak → urinstof |
| **6. Lagring** | Glykogen, vitaminer (A, D, B₁₂), jern |
| **7. Immun** | Kupffer-celler (fagocytose), akutfase-proteiner |

## 💚 Galde — sammensætning og funktion

| Komponent | Kilde | Funktion |
|-----------|-------|----------|
| **Galdesalte** | Hepatocytter (fra kolesterol) | Emulsificering → micelle-dannelse |
| **Bilirubin** | Nedbrydning af hæm | Affaldsprodukt (gulfarve) |
| **Phospholipider** | Hepatocytter | Micelle-stabilitet |
| **HCO₃⁻** | Cholangiocytter | Neutraliserer mavesyre |
| **Vand** | Hepatocytter + galdeblære | Transportmedium |

**Enterohepatiske kredsløb:**
```
Lever → galde → tyndtarm → 95% af galdesalte reabsorberes i ileum
    → portalvenen → lever (genbruges) → galde igen
```

> [!question] Eksamensspørgsmål
> **"Forklar det enterohepatiske kredsløb og dets betydning"**
> *Svar: Galdesalte udskilles fra lever til tyndtarm → emulsificerer fedt → reabsorberes i ileum → transporteres via portalvenen tilbage til leveren → genudskilles. Dette gør at en pool på ~3-5 g galdesalte kan genbruges 6-10 gange per måltid (~20-30 g/dag).*

## 🧪 CYP450 — detoxifikations-systemet

> [!INFO] **Fase I + Fase II detoxifikation i hepatocytter**

**Fase I (CYP450-enzymer):** Oxidation, reduktion, hydrolyse
- Gør molekylet mere vandopløseligt (+ reaktivt!)
- CYP3A4 metaboliserer ~50% af alle lægemidler

**Fase II (Konjugation):** Glucuronidering, sulfatering, glutathion-konjugation
- Kæder molekylet med en polær gruppe → vandopløseligt → udskilles

> **Første-passage-metabolisme:** Lægemidler optaget fra tarmen går direkte til leveren via portalvenen → en del metaboliseres før de når det systemiske kredsløb.
