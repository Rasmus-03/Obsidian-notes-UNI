# Nyrerne — Filtrering, Reabsorption og Osmoregulering

> **Kerne-pathway:** Nyrerne opretholder homeostase for vand, ioner, pH og affaldsstoffer via nefronets 4 processer: **Filtrering → Reabsorption → Sekretion → Ekskretion**.

---

## 📋 Nefronet — nyrens funktionelle enhed

> [!INFO] Hver nyre har ~1 million nefroner — et nefron = glomerulus + tubulussystem

```
Glomerulus (Bowmans kapsel)
    ↓ Filtrering (180 L/dag!)
Proximal tubulus
    ↓ Reabsorption (65% Na⁺, vand, glukose, aminosyrer)
Henles sløjfe (nedstigende/opstigende)
    ↓ Modstrøms-multiplikator → urin-koncentrering
Distal tubulus
    ↓ Regulering (Ca²⁺, Na⁺, pH)
Samlerør (medulla)
    ↓ ADH-reguleret vand-reabsorption (sidste koncentrering)
Urin → Bækken → Ureter → Blære
```

## 🔄 Filtrering og GFR

> [!INFO] **Eksamensspørgsmål: "Forklar glomerulær filtration og regulering af GFR"**

**Filtrations-barrieren:**
```
Blod → Fenestreret endotel → Basalmembran → Podocytters fodprocesser
    (70 nm porer)      (negativ ladning)    (slidsmembran → filtreringsslids)
```

**GFR (Glomerulær FiltrationsRate):**
- Normal: ~125 mL/min (~180 L/dag — kun 1,5 L bliver til urin!)
- **Autoregulering:** Myogen respons + tubuloglomerulær feedback
- **RAAS:** Angiotensin II → vasokonstriktion → GFR ↓
- **ANP:** Dilaterer afferent arteriole → GFR ↑

**Filtreres:** Vand, små molekyler, glukose, aminosyrer, ioner, affald
**Filtreres IKKE:** Blodceller, store proteiner (>70 kDa), negativt ladede molekyler

> [!question] Eksamensspørgsmål
> **"Hvorfor er der glukose i urinen ved diabetes?"**
> *Svar: Ved højt blodsukker (>10 mM) overskrides transport-maximum for SGLT2 i proximal tubulus → glukose kan ikke reabsorberes → glukosuri (sukker i urinen).*

## 💧 Modstrøms-multiplikator — urin-koncentrering

> [!INFO] **Eksamensspørgsmål: "Forklar modstrøms-multiplikatoren i nyrerne"**

**Interstitielt osmolaritets-gradient (cortex → medulla):**
```
Cortex: 300 mOsm
    ↓
Ydre medulla: 600 mOsm
    ↓
Indre medulla: 1200 mOsm
```

**Mekanisme:**
```
1. Opstigende Henle (tyk del): Na⁺/K⁺/2Cl⁻-cotransport → salt ud, vand bliver
   → fortyndet tubular væske + salt-ophobning i interstitiet
2. Nedstigende Henle: vand ud (aquaporiner), salt bliver → koncentreret
3. Modstrøm → gradient forstærkes (multiplikator-effekt)
4. Vasa recta (kapillærer): modstrøm bevarer gradienten
5. Samlerør: ADH → aquaporin-2 → vand ud → koncentreret urin
```

> [!question] Eksamensspørgsmål
> **"Hvordan producerer nyrerne koncentreret urin?"**
> *Svar: Modstrøms-multiplikatoren (opstigende Henle pumper salt ud, nedstigende taber vand) skaber en osmolaritets-gradient fra 300→1200 mOsm. Når ADH er til stede, sættes aquaporin-2 ind i samlerøret → vand diffunderer ud af gradienten → koncentreret urin (op til 1200 mOsm). Uden ADH → fortyndet urin (50 mOsm).*

## 🧪 Syre-base-regulering i nyrerne

> [!INFO] Nyrerne regulerer pH ved at udskille H⁺ og reabsorbere HCO₃⁻

| pH-afvigelse | Nyrens respons |
|:------------:|---------------|
| **Acidose (pH ↓)** | H⁺ udskilles (via H⁺-ATPase, Na⁺/H⁺-antiport), NH₃ → NH₄⁺, HCO₃⁻ reabsorberes |
| **Alkalose (pH ↑)** | HCO₃⁻ udskilles, H⁺ reabsorberes |

## 🧬 Hormonel regulering

| Hormon | Stimulus | Effekt på nyren | Netto-resultat |
|--------|:--------:|-----------------|:--------------:|
| **ADH** | Osmolaritet ↑ / volumen ↓ | Aquaporin-2 ↑ → vand-reabsorption ↑ | Urin-koncentrering |
| **Aldosteron** | Angiotensin II / K⁺ ↑ | Na⁺-reabsorption ↑, K⁺-sekretion ↑ | Volumen ↑, K⁺ ↓ |
| **ANP** | Atriel stræk ↑ | Na⁺-reabsorption ↓ | Volumen ↓, Na⁺ ↓ |
| **PTH** | Ca²⁺ ↓ | Ca²⁺-reabsorption ↑, PO₄³⁻ ↓ | Ca²⁺ ↑ |

**RAAS-pathway (renin-angiotensin-aldosteron-system):**
```
Blodtryk ↓ → Renin (JG-celler) → Angiotensinogen → Angiotensin I
    → ACE (lunger) → Angiotensin II
        → Vasokonstriktion (blodtryk ↑)
        → Aldosteron ↑ (Na⁺-retention, volumen ↑)
        → ADH ↑ (vand-retention)
        → Tørst ↑
```
