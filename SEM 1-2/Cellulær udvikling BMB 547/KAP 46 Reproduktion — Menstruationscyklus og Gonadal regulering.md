# Reproduktion — Menstruationscyklus og Gonadal Regulering

> **Kerne-pathway:** HPG-aksen (hypothalamus-hypofyse-gonader) styrer gonade-funktion, gametogenese og kønscyklus via negativ og positiv feedback.

---

## 🧠 HPG-aksen — overblik

```
Hypothalamus (GnRH) — pulsatile frigivelse
    │
    ├── GnRH → Hypofyse → FSH + LH
    │         (forlap/adenohypofyse)
    │
    ├── FSH → Gonader:
    │   ├── Kvinde: follikel-vækst + østrogen-produktion
    │   └── Mand: spermatogenese (Sertoli-celler)
    │
    ├── LH → Gonader:
    │   ├── Kvinde: ovulation + corpus luteum (progesteron)
    │   └── Mand: testosteron-produktion (Leydig-celler)
    │
    └── Kønshormoner → negativ/positiv feedback på hypothalamus + hypofyse
```

## 👩 Kvindens menstruationscyklus — 28 dage

> [!INFO] **Eksamensspørgsmål: "Redegør for menstruationscyklussen og dens hormonelle regulering"**

### Ovariecyklus — hvad sker der i æggestokken?

| Fase | Dage | Hændelse | Hormon-niveau |
|------|:----:|----------|:-------------:|
| **Follikulær fase** | 1-14 | FSH → follikel-vækst, østrogen ↑ | Østrogen ↑, Inhibin ↑ |
| **Ovulation** (dag 14) | ~1 dag | LH-spike → follikel brister → æg frigives | LH-spike!, FSH-spike |
| **Luteal fase** | 15-28 | Corpus luteum → progesteron + østrogen | Progesteron ↑↑, Østrogen |

### Endometriecyklus — hvad sker der i livmoderen?

| Fase | Dage | Hændelse | Hormonel kontrol |
|------|:----:|----------|:----------------:|
| **Menstruation** | 1-5 | Endometriet afstødes | Østrogen + progesteron ↓ |
| **Proliferativ fase** | 6-14 | Endometriet genopbygges | Østrogen ↑ (fra follikel) |
| **Sekretorisk fase** | 15-28 | Kirtler udvikles, sekretion | Progesteron ↑ (corpus luteum) |

### Feedback-mekanismer

| Fase | Feedback | Mekanisme |
|:----:|:--------:|-----------|
| **Follikulær (tidlig)** | Negativ | Lavt østrogen → hæmmer FSH/LH |
| **Follikulær (sen)** | **Positiv!** | Højt østrogen (12-24t) → LH-spike! |
| **Luteal** | Negativ | Progesteron + østrogen → FSH/LH ↓ |

> [!question] Eksamensspørgsmål
> **"Forklar LH-spike og dens betydning"**
> *Svar: Når østrogen når en tærskelværdi i >12 timer, skifter det fra negativ til positiv feedback på hypothalamus/hypofyse → massiv GnRH-frigivelse → LH-spike (10× normal). LH-spike → follikel brister → ægget frigives ~36 timer efter. Uden LH-spike → ingen ovulation!*

## 🧬 Spermatogenese vs. Oogenese

> [!INFO] **Eksamensspørgsmål: "Sammenlign spermatogenese og oogenese (meiose)"**

| Egenskab | Spermatogenese | Oogenese |
|----------|:--------------:|:--------:|
| **Lokation** | Testis (tubuli seminiferi) | Ovarium |
| **Start** | Pubertet | Fostertilværelse (meiose I starter) |
| **Hastighed** | Kontinuerlig | Cyklisk (1 æg/måned) |
| **Produkt** | 4 spermier/meiose | 1 æg + 3 pollegemer/meiose |
| **Meiose I** | 22 dage | Blokeres i profase I → færdiggøres ved ovulation |
| **Meiose II** | 1 dag | Blokeres i metafase II → færdig ved fertilization |
| **Antal** | ~1.000/sekund | ~1/måned × 35 år |
| **Hormon-regulering** | FSH (Sertoli), LH (Leydig → testosteron) | FSH (follikel-vækst), LH (ovulation) |

## 👶 Fertilization og tidlig udvikling

```
1. Sperm møder æg i ampulla tubae (æggeleder)
2. Acrosom-reaktion → enzymer frigives → zona pellucida gennemtrænges
3. Sperm-æg-fusion → Ca²⁺-bølge → cortical reaktion → blokering af polyspermi
4. Meiose II færdiggøres → han- + hun-forkerne → diploid zygote
5. Zygote → embryo → blastocyst → implantation (dag 5-7)
```

## 🤱 Graviditet og fødsel

| Hormon | Rolle i graviditet |
|--------|-------------------|
| **hCG** | Produceres af trophoblast → corpus luteum reddes → progesteron fortsætter |
| **Progesteron** | Vedligeholder endometriet, hæmmer kontraktioner |
| **Østrogen** | Uterus-vækst, oxytocin-receptor ↑ |
| **Relaxin** | Udvider symfyse, blødgør cervix |
| **Oxytocin** | Uterus-kontraktioner → fødsel + mælkeejektion |
| **Prolaktin** | Mælkeproduktion |

**Fødsels-pathway:**
```
Fosterets hoved → stræk af cervix → oxytocin ↑ (positiv feedback)
    → Uterus-kontraktioner ↑ → mere stræk → mere oxytocin
    → Barn født → placenta stødes ud → oxytocin ↓
```
