# Motorik — Muskelkontraktion og Bevægelse

> **Kerne-pathway:** Motor cortex → motorneuron → neuromuskulær synapse → excitation-kontraktions-kobling → krydsbro-cyklus → kraftudvikling.

---

## 🧠 Motorisk kontroll-pathway

> [!INFO] **Eksamensspørgsmål: "Forklar vejen fra motorisk planlægning til muskelkontraktion"**

```
Motor cortex (planlægning + initiering)
    │
    ├── Cortex-spinal-bane (corticospinal = pyramidale bane)
    │       → Krydser i medulla oblongata (decussatio pyramidum)
    │       → Rygmarv → α-motorneuron
    │
    ├── Cerebellum (koordination, timing, finjustering)
    │
    ├── Basalganglier (initiering, selektion af bevægelser)
    │
    └── Hjernestam → ekstrapyramidal (postur, tonus)
```

**α-motorneuron → neuromuskulær junction:**
```
AP i α-motorneuron → Ca²⁺ ind → ACh frigives → ACh binder til 
nikotinisk ACh-receptor på muskel → Na⁺ ind → EPP (end-plate potential) 
→ AP i muskelfiber → excitation-kontraktions-kobling
```

## ⚡ Excitation-Kontraktions-Kobling

> [!INFO] **Eksamensspørgsmål: "Redegør for excitation-kontraktions-kobling i skeletmuskel"**

```
AP i muskelfiber → T-tubuli (transversale tubuli)
    → Spændingsfølsomme receptorer (dihydropyridin = DHPR)
    → Mekanisk kobling til ryanodin-receptor (RyR) på SR
    → Ca²⁺ frigives fra sarcoplasmatisk reticulum (SR)
    → Ca²⁺ binder til troponin C → tropomyosin skyder sig væk
    → Aktin-myosins bindings-site blotlægges → krydsbro-cyklus
```

| Struktur | Funktion |
|----------|----------|
| **T-tubuli** | Fører AP dybt ind i fiberen |
| **Sarcoplasmatisk reticulum** | Ca²⁺-lager |
| **DHPR** | Spændingssensor |
| **RyR** | Ca²⁺-frigivelseskanal |
| **Troponin C** | Ca²⁺-buffer → aktiverer kontraktion |

**Relaxation:** Ca²⁺ pumpes tilbage i SR af SERCA → tropomyosin dækker aktin igen

## 🔄 Krydsbro-cyklus (Sliding Filament Theory)

```
1. ATP binder til myosinhoved → myosin dissocierer fra aktin
2. ATP → ADP + Pᵢ (myosin-ATPase) → myosin "cocks" (45° → 90°)
3. Myosin binder til aktin (Pᵢ frigives) → "cross-bridge formation"
4. ADP frigives → **Power stroke** → myosin trækker aktin (90° → 45°)
5. Nyt ATP binder → cyklus gentages
```

> [!INFO] Rigor mortis: Efter døden → ATP opbruges → myosin kan ikke dissociere fra aktin → stive muskler!

**Kraftens afhængighed af sarkomerlængde (Frank-Starling-lignende):**
| Overlap | Kraft |
|:-------:|:-----:|
| For langt (sarkomer > 3,5 μm) | Ingen overlapping → 0 kraft |
| Optimal (2,0-2,2 μm) | Maksimalt overlap → max kraft |
| For kort (< 1,5 μm) | Overlap + kompression → kraft ↓ |

## 💪 Muskeltyper — Skelet, Hjerte, Glat

> [!INFO] **Eksamensspørgsmål: "Sammenlign de tre muskeltyper"**

| Egenskab | Skeletmuskel | Hjertemuskel | Glat muskelulatur |
|:--------:|:------------:|:------------:|:-----------------:|
| **Anatomisk** | Lang, cylindrisk, tværstribet | Kort, forgrenet, tværstribet | Spoleformet, ikke tværstribet |
| **Kerner** | Flere perifere | Én central | Én central |
| **Kontraktionskraft** | Meget stærk (tetani mulig) | Stærk (ingen tetani) | Svag, tonisk |
| **Automatisk?** | Nej (kun nerveaktivitet) | Ja (SA-knude pacemaker) | Ja (slow waves) |
| **Ca²⁺-kilde** | SR (hurtig frigivelse) | SR + ekstracellulær | Primært ekstracellulær |
| **T-tubuli** | Ja (ved A-I-grænse) | Ja (ved Z-disken) | Nej (caveolae) |
| **Trettes** | Ja | Nej | Nej |

**Skeletmuskel-subtyper:**
| Type | Fiber | Kontraktion | Træthed | Anvendelse |
|:----:|:-----:|:-----------:|:-------:|:----------:|
| **Type I** | Rød (oxidativ) | Langsom | Modstandsdygtig | Holdning, maraton |
| **Type IIa** | Rød (oxidativ-glykolytisk) | Hurtig | Moderat | Gang, cykling |
| **Type IIx** | Hvid (glykolytisk) | Meget hurtig | Let trættelig | Sprint, styrkeløft |

> [!question] Eksamensspørgsmål
> **"Hvorfor kan du stå oprejst i timevis uden at dine benmuskler trættes, men du kan kun løbe hurtigt i kort tid?"**
> *Svar: Stående = Type I-fibre (oxidativ, langsom trætning). Sprint = Type IIx (glykolytisk, pH-fald → træthed). Kroppen rekrutterer i rækkefølgen I → IIa → IIx efter behov (Hennemans størrelsesprincip).*
