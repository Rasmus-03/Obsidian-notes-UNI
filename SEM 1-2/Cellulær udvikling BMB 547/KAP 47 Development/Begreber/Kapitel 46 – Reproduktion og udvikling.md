# Kapitel 46 – Reproduktion og udvikling

> [!INFO] **Formål**
> Dette kapitel dækker **reproduktionsbiologi** og **embryonal udvikling** — fra kønscelledannelse til fosterudvikling. Kapitlet integrerer celedeling, differentiering og morfogenese.

> **Kilde:** Campbell Biology (12. udgave) – Kapitel 45-47

---

## Kapiteloversigt

### Del 1: Reproduktion (Kap 45)
| Emne | Nøglebegreber |
|------|---------------|
| **Kønscelledannelse** | Meiose, oogenese, spermatogenese |
| **Kønsbestemmelse** | Genetisk (XX/XY), miljøbestemt (temperatur hos krybdyr) |
| **Hormonregulering** | GnRH, FSH, LH, testosteron, østrogen, progesteron |
| **Kønscyklus (menneske)** | Follikelfase, ægløsning, lutealfase, menstruation |
| **Befrugtning** | Akrosomreaktion, kortikalk reaktion, polyspermi-blokering |

### Del 2: Udvikling (Kap 46-47)
| Emne | Nøglebegreber |
|------|---------------|
| **Cleavage** | Hurtig celledeling, morula, blastula |
| **Gastrulering** | Primitive streak, tre kimlag, notochord |
| **Neurulation** | Neuralrør, neuralkam, CNS-dannelse |
| **Organogenese** | Hjerte, nyrer, lemmer, sanser |
| **Stamceller** | Totipotent, pluripotent, multipotent |
| **Differentiering** | Transkriptionsfaktorer, epigenetik, induktion |
| **Morfogener** | Gradienter, tærskelværdier, positionel information |

### Del 3: Evolutionært perspektiv
- **Protostomer vs deuterostomer**: Forskelle i blastoporskæbne, celledeling, coelom-dannelse
- **Regulativ vs. determinativ udvikling**: Deuterostomer kan kompensere — protostomer har fastlåst skæbne tidligt

## Centrale signalveje

| Signalvej | Rolle i udvikling |
|-----------|-------------------|
| **Wnt** | Anterior-posterior aksedannelse, celledeling |
| **Shh** | Neuralrørsmønster, lemmerakser |
| **BMP** | Dorsal-ventral mønster, knogledannelse |
| **FGF** | Celleproliferation, lemmerudvækst |
| **Notch** | Lateral inhibering — celler får forskellige skæbner |
| **Nodal** | Venstre-højre asymmetri, mesoderm-induktion |

## Eksamensrelevans
- Kønscelledannelsens faser (meiose I → meiose II)
- Gastruleringens betydning
- Forskelle mellem protostomer og deuterostomer
- Stamcellers plasticitet og terapeutisk potentiale
- Hormonregulering af reproduktion
