# Morfogener

> [!INFO] **Definition**
> **Morfogener** er signalmolekyler der **diffunderer** gennem væv og danner **koncentrationsgradienter**, som giver **positionel information** til celler. Forskellige tærskelværdier af morfogenkoncentration inducerer forskellige celleskæbner — cellerne "læser" deres position via koncentrationen af morfogen.

> **Kilde:** Campbell Biology (12. udgave) – Kapitel 47, s. 1076-1080

---

## Morfogen-konceptet

| Princip | Forklaring |
|---------|-----------|
| **Kilde** | Morfogen produceres i en lokaliseret region (signaleringscenter) |
| **Diffusion** | Morfogen spredes passivt gennem vævet |
| **Gradient** | Koncentrationen aftager med afstand fra kilden |
| **Tærskelværdier** | Celler reagerer forskelligt afhængigt af koncentration |
| **Respons** | Forskellige gener aktiveres ved forskellige koncentrationer |

> **Lewis Wolpert's model**: "Celler opfører sig som om de har en lineal — de måler afstanden fra morfogenkilden"

## Klassiske morfogener

| Morfogen | Funktion | Modelorganisme |
|----------|----------|----------------|
| **Bicoid** | Anterior mønster (hoveddannelse) | *Drosophila* |
| **Nanos** | Posterior mønster (abdominaldannelse) | *Drosophila* |
| **Sonic Hedgehog (Shh)** | Neuralrør-mønster, lemmer-akse | Hvirveldyr |
| **BMP** | Dorsal-ventral mønster, knogledannelse | Hvirveldyr, *Drosophila* |
| **Wnt** | Anterior-posterior mønster | Hvirveldyr |
| **Retinsyre** | Anterior-posterior mønster (i lemmer) | Hvirveldyr |
| **Nodal** | Venstre-højre asymmetri | Hvirveldyr |
| **TGF-β** | Mesoderm-induktion | Hvirveldyr |

## Morfogen-gradienter i *Drosophila*-embryonet

1. **Bicoid** (anterior) → hoved- og thoraxdannelse
2. **Nanos** (posterior) → abdominaldannelse
3. **Hunchback** → anterior-posterior segmentering
4. **Gap-gener** → grov opdeling
5. **Pair-rule-gener** → segmentgrænser
6. **Segment-polaritetsgener** → anterior-posterior orientering af segmenter

> Dette er et **genetisk hierarki** — morfogener på øverste niveau styrer ekspression af downstream gener

## Morfogen-gradienter hos hvirveldyr

| System | Morfogen | Gradientfunktion |
|--------|----------|-----------------|
| **Neuralrør** | Shh (ventral) + BMP (dorsal) | Inducerer forskellige neuron-typer |
| **Lemmer** | Shh (posterior) + Wnt (dorsal) + BMP (ventral) | Anterior-posterior + dorsal-ventral akse |
| **Somitter** | FGF (posterior) + retinsyre (anterior) | Segmenteringsur |

## Tærskelværdi-model

```
Høj [morfogen] ───→ Gen A aktiveres → Skæbne 1
Mellem [morfogen] ──→ Gen B aktiveres → Skæbne 2
Lav [morfogen] ────→ Gen C aktiveres → Skæbne 3
```

> **French flag model** (Wolpert): Tre koncentrationsniveauer → tre forskellige "farver" (skæbner)

## Eksamensspørgsmål
1. *Hvad kendetegner et morfogen?*
   - Det danner en koncentrationsgradient, og celler reagerer forskelligt afhængigt af koncentrationen
2. *Hvordan kan én morfogen give flere celletyper?*
   - Via tærskelværdier — forskellige gener aktiveres ved forskellige koncentrationer
3. *Hvad er French flag-modellen?*
   - En model der forklarer hvordan morfogen-gradienter skaber mønstre med definerede grænser
