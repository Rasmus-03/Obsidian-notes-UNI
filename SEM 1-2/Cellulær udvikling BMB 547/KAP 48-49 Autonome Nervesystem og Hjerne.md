# Autonome Nervesystem (ANS) og Hjerne

> **Kerne-pathway:** ANS styrer ubevidste funktioner (hjerte, fordøjelse, respiration) via sympatikus og parasympatikus. Hjernen integrerer sensorisk input og motorisk output.

---

## ⚖️ Sympatikus vs. Parasympatikus

| Egenskab | Sympatikus (fight-or-flight) | Parasympatikus (rest-and-digest) |
|:--------:|:----------------------------:|:--------------------------------:|
| **Nervespring** | Thorakolumbal (T1-L2) | Kraniosakral (CN III, VII, IX, X + S2-S4) |
| **Ganglieplacering** | Nær rygmarven (truncus sympaticus) | Nær/i organet |
| **Præganglionær NT** | Acetylcholin (nikotinisk) | Acetylcholin (nikotinisk) |
| **Postganglionær NT** | **Noradrenalin** (de fleste) | **Acetylcholin** (muskarinisk) |
| **Binyremarv** | ACh → Adrenalin (direkte i blod) | - |

**Effekter:**
| Organ | Sympatikus | Parasympatikus |
|:-----:|:----------:|:--------------:|
| Hjerte | ↑ frekvens + kraft | ↓ frekvens |
| Lunger | Bronkodilatation | Bronkokonstriktion |
| Tarm | ↓ peristaltik | ↑ peristaltik |
| Pupiller | Dilatation | Konstriktion |
| Sved | ↑ (ingen parasymp.) | - |
| Blære | Relaxation (fyldning) | Kontraktion (tømning) |

> [!QUESTION] Eksamensspørgsmål
> **"Sammenlign sympatikus og parasympatikus med hensyn til anatomi, neurotransmittere og effekter"**
> *Svar: Se tabellerne ovenfor. Fokusér på: symp = thorakolumbal, noradrenalin, fight-or-flight. Parasymp = kraniosakral, ACh, rest-and-digest. Binyremarv = undtagelse (symp, ACh → adrenalin).*

## 🧠 Hjernens struktur — kort overblik

> [!INFO] **Eksamensspørgsmål: "Redegør for hjernens hovedregioner og deres funktioner"**

| Region | Funktion |
|--------|----------|
| **Cerebral cortex** | Sansning, motorik, sprog, kognition |
| **Frontallap** | Planlægning, eksekutiv funktion, personlighed |
| **Parietallap** | Somatosensorik (berøring, tryk, smerte) |
| **Temporallap** | Hørelse, hukommelse (hippocampus), sprogforståelse (Wernicke) |
| **Occipitallap** | Syn |
| **Cerebellum** | Koordination, balance, motorisk indlæring |
| **Basalganglier** | Motorisk initiering, vaner |
| **Hippocampus** | Langtidshukommelse (declarativ) |
| **Amygdala** | Følelser (frygt, aggression) |
| **Hypothalamus** | Homeostase, hormoner |
| **Thalamus** | Sensorisk relæstation |
| **Hjernestamme** | Basis funktioner (vejrtrækning, hjerterytme) |

### Hjerneblodforsyning & Blod-hjerne-barriere

| Struktur | Funktion |
|----------|----------|
| **Blod-hjerne-barrieren (BBB)** | Tight junctions i kapillærer → beskyttelse mod toksiner |
| **Cirkel van Willis** | Kollateral blodforsyning ved okklusion |

> [!WARNING] Stroke (apopleksi): Cirkel van Willis kan omgå okklusion. Uden collateral → infarkt.
