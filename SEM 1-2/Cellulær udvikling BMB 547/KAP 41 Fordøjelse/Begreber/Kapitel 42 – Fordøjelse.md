# Kapitel 42 – Fordøjelse

> [!tip] **For en 5-årig:**  
> Fordøjelse er som en tivolitur for maden: den bliver mast i munden, syrebadet i maven, blandet med enzymer i tolvfingertarmen, og suget tør for næring i tyndtarmen. Til sidst kommer resterne ud.

## Fordøjelsessystemets dele
| Organ | Funktion |
|-------|----------|
| **Mund** | Mekanisk nedbrydning (tænder), amylase (stivelse) |
| **Spiserør** | Peristaltik → maven |
| **Mave** | Pepsin (protein), HCl (syrer, dræber bakterier) |
| **Tyndtarm** | Enzymatisk nedbrydning + absorption (villi, mikrovilli) |
| – Duodenum | Galde (fedt), pancreas-enzymer (alt) |
| **Tyktarm** | Vandabsorption, afføring |
| **Lever** | Galde, metabolisme, afgiftning |
| **Pancreas** | Fordøjelsesenzymer + bicarbonat |

## Fordøjelsesenzymer
| Enzym | Substrat | Produkt |
|-------|----------|---------|
| Amylase | Stivelse | Maltose |
| Pepsin | Protein | Peptider |
| Lipase | Fedt | FEDTSYRER + glycerol |
| Trypsin | Protein | Peptider |
| Nuklease | DNA/RNA | Nukleotider |

## Overfladeforstørrelse
- **Villi** (finger-lignende udbulninger)
- **Mikrovilli** (børsteformet rand på epitelceller)
- Øger absorptionsarealet ~600×

## Eksamenstræning
- Spørgsmålstype: "Forklar fordøjelsens vej" → mund → mave → tyndtarm → tyktarm
- Spørgsmålstype: "Hvilke enzymer er involveret?" → amylase, pepsin, lipase, trypsin
