# Tyndtarmens sekret

> [!tip] **Hovedprincippet:** Tyndtarmens egen sekretion + sekret fra lever (galde) og pancreas (enzymer + bicarbonat) sikrer fuldstændig fordøjelse.

## Pankreas-sekret
| Komponent | Funktion |
|-----------|----------|
| **Bicarbonat (HCO₃⁻)** | Neutraliserer mavesyre (pH 2 → pH 7-8) |
| **Trypsin** | Spalter proteiner (frigives som trypsinogen → aktiveres af enteropeptidase) |
| **Chymotrypsin** | Spalter proteiner |
| **Pancreas-amylase** | Spalter stivelse |
| **Lipase** | Spalter fedt (med colipase) |
| **Nukleaser** | Spalter nukleinsyrer |

## Tarmens eget sekret
- **Enteropeptidase** (i tolvfingertarmen) → aktiverer trypsinogen til trypsin
- **Disaccharidaser** (laktase, maltase, sucrase) → spalter disakkarider til monosakkarider
- **Peptidaser** → spalter peptider til aminosyrer
