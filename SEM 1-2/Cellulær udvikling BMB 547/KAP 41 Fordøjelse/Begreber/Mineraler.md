# Mineraler (fordøjelse og fysiologi)

> [!INFO] **Definition**
> Mineraler er essentielle uorganiske næringsstoffer der indtages via kosten og optages i fordøjelsessystemet. De er kofaktorer for enzymer, byggesten for knogler og nødvendige for nervefunktion, muskelsammentrækning og væskebalance.

**Makromineraler** (>100 mg/dag):
| Mineral | Funktion | Kilde |
|---|---|---|
| **Calcium** | Knogler, koagulation, signalering | Mælk, grønne grøntsager |
| **Fosfor** | ATP, DNA, knogler | Kød, mælk, fuldkorn |
| **Kalium** | Hvilemembranpotentiale, muskler | Kartofler, bananer |
| **Natrium** | Væskebalance, nerveimpulser | Salt |
| **Klorid** | Mavesyre (HCl), væskebalance | Salt |
| **Magnesium** | Enzymkofaktor, muskelafspænding | Grønt, nødder |

**Spormineraler** (<100 mg/dag):
| Mineral | Funktion | Mangel |
|---|---|---|
| **Jern** | O₂-transport (hæmoglobin) | Anæmi |
| **Zink** | Immunforsvar, enzymer | Væksthæmning |
| **Kobber** | Bindevæv, jernmetabolisme | Anæmi, neurologi |
| **Selen** | Antioxidant (glutathionperoxidase) | Kardiomyopati |
| **Jod** | Thyroideahormoner (T₃/T₄) | Struma |
| **Fluor** | Tandemalje | Caries |

**Absorption i tarmen:**
- **Ca²⁺** → aktiv transport (TRPV6) reguleret af vitamin D og PTH
- **Fe²⁺** → DMT1 i duodenum, reguleret af hepcidin
- **Zn²⁺** → ZIP4 i jejunum, opreguleret ved mangel
- **Na⁺** → cotransport med glukose (SGLT1) og aminosyrer

**Interaktioner:**
- Vitamin D ↑ Ca²⁺ optag
- C-vitamin ↑ Fe²⁺ optag
- Fytat ↓ Zn²⁺, Fe²⁺, Ca²⁺ optag
- Tanniner ↓ Fe²⁺ optag
