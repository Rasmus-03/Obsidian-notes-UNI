# Fordøjelsessystemet

> [!tip] **Hovedprincippet:** Fordøjelsessystemet nedbryder føde til optagelige næringsstoffer via mekanisk og kemisk bearbejdning.

## Anatomisk oversigt
```
Mund → Pharynx → Øsofagus → Mave → Tyndtarm (duodenum, jejunum, ileum)
                                         ↓
                                      Tyktarm (colon ascendens, transversum, descendens, sigmoideum)
                                         ↓
                                      Rectum → Anus
```

## Fordøjelsens faser
| Fase | Hvad sker der | Styring |
|------|--------------|---------|
| **1. Mund** | Tygning, amylase → stivelse nedbrydes | Viljestyret |
| **2. Mave** | Pepsin → proteiner, HCl → aktivering, blandning | Parasympatikus |
| **3. Tyndtarm** | Enzymer + galde → alle makromolekyler → monomerer | Enterisk + hormonel |
| **4. Tyktarm** | Vand-reabsorption, gæring (bakterier) | Autonomt |
