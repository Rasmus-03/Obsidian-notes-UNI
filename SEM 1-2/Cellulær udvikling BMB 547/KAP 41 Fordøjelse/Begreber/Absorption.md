# Absorption (Fordøjelse)

## Definition
Absorption er optagelsen af næringsstoffer (monosakkarider, aminosyrer, fede syrer, glycerol, vitaminer, mineraler og vand) fra tarmlumen til blodbanen eller lymfen.

## Mekanisme
- **Kulhydrater**: monosakkarider (glukose, galaktose, fruktose) optages via SGLT1/GLUT-transportere i tyndtarmen → portalvenen → lever
- **Proteiner**: aminosyrer/dipeptider/tripeptider optages via Na+-afhængige cotransportere og PepT1 → portalvenen
- **Fedt**: miceller (fede syrer + monoglycerider + galdesalte) → enterocytter → resyntese til triglycider → chylomikroner → lymfen (via lactealer)
- **Vand og elektrolytter**: passiv (osmotisk gradient) + aktiv (Na+/K+-ATPase) transport

## Klinisk relevans
- Uden pankreasenzymer → malabsorption af alle næringsstoffer
- Uden galde → fedtmalabsorption (steatorré)
- Sygdomme: cøliaki, Crohns sygdom, laktoseintolerance, cystisk fibrose

## Eksamenstraening
- Spørgsmålstype: "Redegør for absorption af fedt/kulhydrat/protein i tyndtarmen"
- Fokus: forskellige transportveje for forskellige næringsstoffer
