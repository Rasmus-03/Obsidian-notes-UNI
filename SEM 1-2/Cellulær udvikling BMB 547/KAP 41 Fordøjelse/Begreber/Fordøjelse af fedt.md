# Fordøjelse af fedt

> [!tip] **For en 5-årig:**  
> Fedt er som små vandballoner der ikke vil blandes med vand. Kroppen bruger galde (sæbe) til at gøre dem mindre, og enzymer (lipaser) til at klippe dem i stykker.

## Trin i fedtfordøjelsen
| Trin | Sted | Hvad sker? |
|------|------|------------|
| 1. **Emulgering** | Duodenum | Galdesalte → fedtkugler → små dråber |
| 2. **Hydrolyse** | Duodenum | Pankreaslipase → triglycerider → 2 FFA + monoglycerid |
| 3. **Micelledannelse** | Duodenum | Galdesalte + fedtsyrer → miceller |
| 4. **Absorption** | Jejunum | Fedtsyrer + monoglycerider → enterocyt |
| 5. **Resyntese** | Enterocyt | → nye triglycerider |
| 6. **Chylomikroner** | Enterocyt | → lymfe via lactealer |

## Nøglemolekyler
- **Pankreaslipase**: hovedenzymet (virker ved pH 7-8)
- **Colipase**: binder lipase til fedtdråberne (aktiveres af trypsin)
- **Galdesalte**: emulgering, micelledannelse (recirkuleres via enterohepatisk kredsløb)
- **Bikarbonat**: neutraliserer pH → optimal lipase-aktivitet

## Klinisk relevans
- **Steatorrhea**: fedt i afføring (pankreasinsufficiens, galdeobstruktion)
- **CFTR-mutation** (cystisk fibrose): → manglende bikarbonat → dårlig fedtfordøjelse
