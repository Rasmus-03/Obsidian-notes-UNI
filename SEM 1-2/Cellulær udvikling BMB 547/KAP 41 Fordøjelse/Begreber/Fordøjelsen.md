# Fordøjelsen (overblik)

> [!tip] **For en 5-årig:**  
> Fordøjelse er som et samlebånd der kører baglæns: Maden bliver brudt ned i mindre og mindre stykker, så kroppen kan optage næringsstofferne. Det starter i munden, fortsætter i maven og tarmen, og det der ikke kan bruges, ryger ud i toilettet!

## Definition
Fordøjelsen er den proces hvor **mad nedbrydes** til små molekyler (glukose, aminosyrer, fedtsyrer) der kan absorberes af tarmen og optages i blodet.

## Fordøjelseskanalen
| Organ | Funktion |
|-------|----------|
| **Mund** | Mekanisk nedbrydning (tænder), amylase (stivelse → maltose) |
| **Svelg** | Synkning, epiglottis lukker luftrøret |
| **Spiserør** | Peristaltik → maven |
| **Mave** | Protein-nedbrydning (pepsin), syre (HCl), blanding (krøser) |
| **Tyndtarm** | Hoved-nedbrydning + absorption (villi, mikrovilli) |
| **Tyktarm** | Vand-absorption, elektrolytoptag, fæces-dannelse |
| **Rektum/Anus** | Fæces-lagring og -udskillelse |

## Fordøjelsesenzyner
| Enzym | Kilde | Substrat | Produkt |
|-------|-------|----------|---------|
| α-Amylase | Spyt, bugspytkirtel | Stivelse | Maltose |
| Pepsin | Mave (chief cells) | Proteiner | Peptider |
| Trypsin | Bugspytkirtel | Proteiner | Peptider |
| Lipase | Bugspytkirtel | Fedt (triglycerider) | Fedtsyrer + monoglycerider |
| Nuklease | Bugspytkirtel | DNA/RNA | Nukleotider |
| Maltase/Sukrase/Laktase | Tyndtarms-epitel | Disakkarider | Monosakkarider |
| Peptidaser | Tyndtarms-epitel | Peptider | Aminosyrer |

## Hormonel regulering
| Hormon | Kilde | Effekt |
|--------|-------|--------|
| **Gastrin** | Maven (G-celler) | ↑ mavesyre, ↑ mave-tømning |
| **CCK** | Tyndtarm | ↑ galdeblærekontraktion, ↑ pankreas-enzyner |
| **Sekretin** | Tyndtarm | ↑ HCO₃⁻ (pankreas), ↓ mavesyre |
| **GIP** | Tyndtarm | ↑ insulin-frigivelse |
| **Ghrelin** | Maven | ↑ appetit |
| **PYY** | Tyndtarm/kolon | ↓ appetit |

## Absorption (tyndtarm)
- **Villi**: fingerformede udposninger → øger overfladeareal
- **Mikrovilli** (brush border): forstørrer overflade yderligere
- **Transport**: Na⁺/glukose co-transport (SGLT1), Na⁺/aminosyre co-transport
- **Fedt**: miceller (galdesalte) → absorption → chylomikroner → lymfe
