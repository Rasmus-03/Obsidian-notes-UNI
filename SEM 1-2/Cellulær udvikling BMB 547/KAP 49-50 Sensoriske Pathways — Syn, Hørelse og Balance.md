# Sensoriske Pathways — Syn, Hørelse og Balance

> **Kerne-pathway:** Sanseceller omdanner fysiske stimuli (lys, lyd, tryk) til elektriske signaler via **transduktion** → signalet behandles i thalamus → fortolkes i cortex.

---

## 👁️ Syn — Fototransduktion

> [!INFO] **Eksamensspørgsmål: "Forklar fototransduktion i stænger"**

**Opbygning — retina:**
```
Lys → Cornea → Pupil → Linse → Glaslegeme → Retina:
    ┌── Stænger (scotopisk, sort-hvid, svagt lys)
    └── Tappe (fotopisk, farve, tre typer: S/M/L-bølgelængder)
```

**Fototransduktions-pathway (stænger):**
```
Mørke: cGMP ↑ → Na⁺-kanaler åbne → Na⁺ ind → membran depolariseret (-40 mV)
    → Glutamat frigives til bipolærceller → hæmmer signalering

Lys: Rhodopsin → opsin + retinal (11-cis → all-trans)
    → Transducin (G-protein) → phosphodiesterase (PDE)
    → cGMP ↓ → Na⁺-kanaler lukker → hyperpolarisering
    → Glutamat ↓ → bipolærcelle aktiveres → AP til ganglioncelle → synsnerve
```

> [!question] Eksamensspørgsmål
> **"Hvorfor ser man dårligere i mørket efter at have set på stærkt lys?"**
> *Svar: Stærkt lys bleger rhodopsin (11-cis retinal → all-trans retinal → dissocierer). Det tager tid (~20 min) at regenerere 11-cis retinal → rhodopsin-niveau genopbygges → mørkeadaptation.*

**Farvesyn:** Tappe med 3 fotopsiner → S (blå, 420 nm), M (grøn, 530 nm), L (rød, 560 nm). Farveblindhed = mangel på én tap-type (oftest L/tap → rød-grøn).

## 👂 Hørelse — Mekanotransduktion i cochlea

> [!INFO] **Eksamensspørgsmål: "Forklar hvordan lydbølger omdannes til nervesignaler"**

```
Lydbølger → Trommehinde → Hamre → Ambolt → Stigbøjle (forstærkning 20×)
    → Ovalt vindue → perilymfe i cochlea → basilarmembranen vibrerer
    → Cortis organ → hårceller bøjes
    → Stereocilia bøjes → K⁺-kanaler åbner (endolymfe, K⁺ 150 mM!)
    → K⁺ ind → depolarisering → Ca²⁺ ind → glutamat → AP i hørenerve
```

**Frekvenskodetopografi:** Basen af basilarmembranen = høje frekvenser. Spidsen = lave frekvenser.

**Hårcelle-mekanotransduktion:**
```
Stereocilia bøjes mod kinocilium → "tip links" strækkes → K⁺-kanaler åbner
    → Depolarisering
Stereocilia bøjes væk → kanaler lukker → hyperpolarisering
```

## 🧠 Somatosensorik — Berøring, smerte, proprioception

| Sensorisk modalitet | Receptor | Fibertype | Bane |
|:-------------------:|:--------:|:---------:|:----:|
| **Fin berøring** | Meissner, Merkel | Aβ | Dorsal colum (medial lemniscal) |
| **Tryk** | Pacini, Ruffini | Aβ | Dorsal colum |
| **Smerte/temperatur** | Frie nerveender | Aδ (skarp) + C (brændende) | Spinothalamisk |
| **Proprioception** | Muskelspindel, Golgi-seneorgan | Aα, Aβ | Dorsal colum → cerebellum |

**Smerte-pathway (spinothalamisk):**
```
Smertereceptor (nociceptor) → Aδ/C-fiber → rygmarv (dorsal horn)
    → Krydser → spinothalamisk bane → thalamus → somatosensorisk cortex
```
