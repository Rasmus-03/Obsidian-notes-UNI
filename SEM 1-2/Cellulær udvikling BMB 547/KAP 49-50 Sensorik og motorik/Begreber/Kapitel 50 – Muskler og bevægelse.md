# Kapitel 50 – Muskler og bevægelse

> [!tip] **For en 5-årig:**  
> Muskler er kroppens motorer. De trækker sig sammen (kontraktion) ved at små kroge (myosinhoveder) trækker i tynde tråde (aktin) – som når du hiver et reb ind mod dig. Det giver bevægelse!

## Muskeltyper
| Type | Tværstribet? | Frivillig? | Sted |
|------|-------------|-----------|------|
| **Skeletmuskulatur** | Ja | Ja | Knogler, bevægelse |
| **Hjertemuskulatur** | Ja | Nej (automatisk) | Hjerte |
| **Glat muskulatur** | Nej | Nej (automatisk) | Tarme, blodkar, blære |

## Skeletmuskel – struktur
1. **Muskel** → fascikler → muskelfibre → myofibriller → **sarcomerer**
2. **Sarcomeren** (mellem Z-skiver): grundenhed for kontraktion
3. **Tynde filamenter**: aktin + troponin + tropomyosin
4. **Tykkefilamenter**: myosin (med hoveder)

## Sliding-filament modellen
1. Myosinhoveder binder til aktin (krydsbro)
2. Hovederne trækker aktinfilamenterne indad (power stroke)
3. ATP binder → myosin frigør aktin
4. ATP → ADP + P (myosin ATPase) → myosin "cocks" igen
5. Cyklus gentages → forkorter sarcomeren

## Krydsbro-cyklussen
| Trin | Hvad sker? | Energi |
|------|------------|--------|
| 1. **Rigor** | Myosin bundet til aktin (stiv) | Ingen ATP |
| 2. **ATP-binding** | ATP binder → myosin frigør aktin | ATP bruges |
| 3. **Hydrolyse** | ATP → ADP + P → myosin rejser sig | ATP → ADP + P |
| 4. **Power stroke** | Myosin trækker aktin → sarcomeren forkortes | ADP + P frigøres |
| 5. **Tilbage til 1** | Ny ATP kræves for at frigøre | - |

## Kontraktionsregulering
- **Hvile**: tropomyosin blokerer myosin-bindingssted på aktin
- **Ca²⁺** frigives fra sarcoplasmatisk reticulum (SR)
- Ca²⁺ binder til troponin → tropomyosin flytter sig → myosin kan binde
- **Aktionspotentiale** → SR → Ca²⁺ ↑ → kontraktion

## Excitabilitet – kobling
1. Motorisk neuron → ACh → muskelcelle depolariserer (AP)
2. AP → T-tubuli → SR → Ca²⁺ frigives
3. Ca²⁺ → troponin → tropomyosin flytter → krydsbro-cyklus starter

## Eksamenstræning
- Spørgsmålstype: "Forklar sliding-filament modellen" → myosin trækker aktin → sarcomeren forkortes
- Spørgsmålstype: "Gennemgå krydsbro-cyklussen" → rigor → ATP → hydrolyse → power stroke → ny ATP
- Spørgsmålstype: "Hvad er Ca²⁺'s rolle?" → troponin → tropomyosin flytter → myosin binder aktin
- Spørgsmålstype: "Hvad er forskellen på de 3 muskeltyper?" → skelet (tværstribet, frivillig), hjerte (tværstribet, ufrivillig), glat (ikke-tværstribet, ufrivillig)
