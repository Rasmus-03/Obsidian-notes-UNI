# Glat vs skelet vs hjerte-muskel

## Definition
Menneskets **tre muskeltyper** har hver især forskellig opbygning, kontraktionsmekanisme, regulering og funktion. Oversigten her sammenligner dem på tværs af centrale parametre.

## Sammenligningstabel

| Egenskab | Skeletmuskel | Hjertemuskel | Glat muskel |
|----------|-------------|--------------|-------------|
| **Lokalisation** | Fæstnet til knogler (via sener) | Hjertets vægge | Indre organer: kar, tarm, blære, bronkier, uterus |
| **Tværstribet** | Ja (sarcomerer) | Ja (sarcomerer) | Nej |
| **Antal kerner** | Flere (perifere) | Én (central) | Én (central, spolformet) |
| **Viljestyret** | Ja (somatisk) | Nej (autonom) | Nej (autonom) |
| **Pacemaker-aktivitet** | Nej (motorisk neuron) | Ja (SA-node) | Ja (ICC-celler) |
| **T-tubuli** | Ja (ved A-I-grænsen) | Ja (ved Z-skiven) | Nej (caveolae) |
| **Sarcoplasmatisk reticulum** | Veludviklet | Moderat | Dårligt udviklet |
| **Ca²⁺-kilde** | SR | SR (+ ekstracellulær) | SR + ekstracellulær |
| **Kontraktionshastighed** | Hurtig (10–100 ms) | Moderat (200–300 ms) | Langsom (0,5–2 s) |
| **Træthed** | Hurtig | Moderat (kontinuerlig) | Træthedsresistent |
| **Regulering** | Troponin/tropomyosin | Troponin/tropomyosin | Calmodulin + MLCK |

## Kontraktionsmekanisme

### Skeletmuskel
1. AP fra motorisk neuron → ACh → motorisk endeplade → AP i muskelcelle
2. AP → T-tubuli → DHPR → RyR → Ca²⁺ fra SR → Ca²⁺ binder til **troponin C** → tropomyosin flyttes → myosin-hoved binder actin
3. **Cross-bridge cycling** → filamentglidning
4. ATP-krav: myosin-ATPase, Ca²⁺-pumpe (SERCA), Na⁺/K⁺-pumpe

### Hjertemuskel
- Samme basis som skelet, men **Ca²⁺-induced Ca²⁺ release (CICR):** Ca²⁺-influx via L-type Ca²⁺-kanaler → RyR → yderligere Ca²⁺ fra SR
- **AP varer længere** (~300 ms) pga. Ca²⁺-plateau → forhindrer tetanus

### Glat muskel
- **Elektromekanisk kobling:** AP → Ca²⁺-influx via spændingsstyrede Ca²⁺-kanaler
- **Farmakomekanisk kobling:** Hormon/neurotransmitter → G-protein → IP₃ → Ca²⁺ fra SR
- Ca²⁺ binder **calmodulin** → aktiverer **MLCK** → myosin let-kæde fosforyleres → myosin binder actin → kontraktion
- Afslapning: MLCP defosforylerer myosin

## Klinisk relevans
- **Skelet:** Muskeldystrofi (Duchenne → manglende dystrophin)
- **Hjerte:** Hjerteinsufficiens (↑ intracellulær Ca²⁺ dysregulering)
- **Glat:** Astma (bronkokonstriktion), hypertension (vasokonstriktion), antikolinergika (↓ tarmmotilitet)

## Relationer
- ← **Muskelfysiologi** (tværstribet vs glat)
- ← **Aktionspotentialet** (excitation-kontraktionskobling)
- → **Kliniske sygdomme** (dystrofi, insufficiens, astma)
