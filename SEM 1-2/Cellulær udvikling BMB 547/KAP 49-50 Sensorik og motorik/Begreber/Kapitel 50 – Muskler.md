# Kapitel 50 – Muskler

> [!tip] **For en 5-årig:**  
> Se [[Kapitel 50 – Muskler og bevægelse]] for den fulde note. Kort version: muskler trækker sig sammen via sliding-filament-modellen.

## Nøglepunkter
- **3 typer**: skelet (frivillig), hjerte (ufrivillig), glat (ufrivillig)
- **Sarcomeren**: grundenhed, mellem Z-skiver
- **Sliding-filament**: myosin trækker aktin → forkortelse
- **Krydsbro-cyklus**: myosin → aktin → ATP → power stroke
- **Ca²⁺**: udløser kontraktion via troponin/tropomyosin
- **Excitabilitets-kobling**: AP → SR → Ca²⁺ → kontraktion
