# Eksitotoksicitet

> [!tip] **For en 5-årig:**  
> Eksitotoksicitet er når nerveceller bliver overstimuleret så meget at de dør. Det er som at give en motor for meget gas – den brænder sammen.

## Mekanisme
1. **Overskud af glutamat** (eller glutamaterg agonister)
2. → Overdreven aktivering af **AMPA- og Kainat-receptorer**
3. → Massiv indstrømning af **Na⁺** → celleødem
4. → **Depolarisering** → aktivering af **NMDA-receptorer** → massiv **Ca²⁺-indstrømning**
5. → **Calcium-overload**: aktiverer fosfolipaser, endonukleaser, proteaser (calpain)
6. → Mitokondriel permeabilitet → **cytochrome c** → apoptose
7. → Nekrose eller apoptose → celledød

## Kaskade
```
Glutamatoverskud → AMPA/Kainat-aktivering → Na⁺-indstrømning → Depol.
→ Mg²⁺-blokade af NMDA fjernes → Ca²⁺-indstrømning → Celledød
```

## Sygdomme forbundet med eksitotoksicitet
| Sygdom | Mekanisme |
|--------|-----------|
| **Iskaemisk stroke** | Glutamat-frigivelse fra døende celler |
| **Traumatisk hjerneskade** | Mekanisk → glutamat-frigivelse |
| **ALS** | Mutant SOD1 → glutamattransportør-svigt |
| **Alzheimer** | β-amyloid → glutamatsignalering ↑ |
| **Huntington** | Mitochondriel dysfunktion → Ca²⁺-sårbarhed |
