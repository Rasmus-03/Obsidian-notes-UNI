# Myokardium (hjertemuskulatur)

## Definition
**Myokardium** er hjertets muskelvæg, opbygget af **tværstribet hjertemuskulatur**. Det udgør selve **pumpecellen** og er ansvarlig for hjertets kontraktion og relaxation (systole/diastole). Myokardiet er **unikt** ved at være kontraheret **hele livet igennem uden at trættes**.

## Opbygning
- **Kardiomyocytter:** ~100 µm lange, forgrenede celler med **én central kerne**
- **Interkalarskiver (discus intercalatus):** Cellernes samlingspunkter indeholder:
  - **Desmosomer** → mekanisk kobling (overfører trækkraft)
  - **Gap junctions (connexin 43)** → elektrisk kobling (AP spredes via ionstrøm)
  - **Fasciae adherentes** → forankrer actinfilamenter
- **Sarcomerer** (tværstribet) med A-, I-, H-, M-bånd og Z-skiver

## Elektrofysiologi
- **Hvilemembranpotentiale:** ~ -90 mV
- **Aktionspotentiale (ventrikel):**
  1. **Fase 0 (depolarisering):** Spændingsstyrede Na⁺-kanaler åbner → Na⁺-influx → +20 mV
  2. **Fase 1 (tidlig repolarisering):** Kortvarig K⁺-efflux (transient outward current, Iₜₒ)
  3. **Fase 2 (plateau):** L-type Ca²⁺-kanaler åbner → Ca²⁺-influx → modvirker K⁺-efflux → **300 ms varighed** (forhindrer tetanus)
  4. **Fase 3 (repolarisering):** Ca²⁺-kanaler lukker → K⁺-efflux (IKr, IKs) dominerer
  5. **Fase 4 (hvile):** Na⁺/K⁺-ATPase, Ca²⁺-ATPase, NCX genopretter iongradienter

## Excitation-kontraktionskobling (EC-coupling)
1. AP → L-type Ca²⁺-kanaler (DHPR) åbner → Ca²⁺-influx
2. Ca²⁺ binder til **ryanodin-receptor (RyR2)** på SR → **CICR (Ca²⁺-induced Ca²⁺ release)**
3. Ca²⁺ binder til **troponin C** → tropomyosin flyttes → cross-bridge cycling
4. Relaxation: Ca²⁺ pumpes tilbage til SR (SERCA2a) og ekstracellulært (NCX)

## Mekaniske egenskaber
- **Frank-Starling-mekanismen:** ↑ preload → ↑ sarkomerlængde → ↑ Ca²⁺-sensitivitet → ↑ kraft (homøometrisk regulering)
- **Inotropi:** ↑ sympatikus (β₁-adrenerge receptorer) → ↑ cAMP → ↑ Ca²⁺-influx → ↑ kontraktilitet (heterometrisk)
- **Kronotropi:** ↑ AP-frekvens (SA-node) → hjertefrekvens
- **Dromotropi:** ↓ ledningshastighed (AV-node)

## Metabolisme
- **Hovedsubstrat:** Frie fedtsyrer (40–60%), glukose (20–30%), laktat (10–20%)
- **Aerobt:** Rigeligt med mitokondrier (~30% af cellevolumen)
- **O₂-ekstraktion:** ~70% (højeste i kroppen) → øget O₂-behov dækkes via ↑ koronarflow

## Klinisk relevans
- **Hjerteinsufficiens:** ↓ kontraktilitet, ↑ intracellulær Ca²⁺, ↓ SERCA2a-ekspression
- **Ischemi (infarkt):** ATP-svigt → Ca²⁺-overload → irreversibel skade efter ~20 min
- **Hjertestop:** Asystoli → defibrillator genstarter elektrisk aktivitet
- **Digitalis:** Hæmmer Na⁺/K⁺-ATPase → ↑ intracellulær Na⁺ → NCX vender → ↑ Ca²⁺ → ↑ inotropi

## Relationer
- ← **Hjertets anatomi** (endokard, epikard)
- ← **SA-node / AV-node** (rytme)
- ← **Autonome nervesystem** (symp./parasymp.)
- → **Kontraktion → blodtryk**
- ← **Koronarkar** (blodforsyning)
