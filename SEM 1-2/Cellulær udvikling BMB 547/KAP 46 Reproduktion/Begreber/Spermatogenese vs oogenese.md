## Spermatogenese vs. Oogenese

**Spermatogenese** (sædceller) og **oogenese** (ægceller) er de to processer for **kønscelledannelse** (gametogenese). De følger samme grundmønster (meiose) men med markante tidsmæssige og kvantitative forskelle.

### Sammenligning

| Egenskab | Spermatogenese | Oogenese |
|----------|---------------|----------|
| **Sted** | Testikler (tubuli seminiferi) | Ovarier |
| **Start** | Pubertet (fra stamceller) | Føtalt (oogonier → oocytter) + pubertet |
| **Varighed** | ~64 dage (kontinuerlig) | Årtier (pause ved profase I indtil ovulation) |
| **Produkt pr. meiose** | **4** funktionelle sædceller | **1** modent æg + **3** pollegemer (polar bodies) |
| **Størrelse** | Lille (~5 µm hoved) | Stor (~120 µm incl. zona pellucida) |
| **Antal** | ~100 mio/dag | ~400 i livstid (resten atresieres) |
| **Cytoplasmefordeling** | Symmetrisk (ligelig) | **Asymmetrisk** (alt cytoplasma til ægget) |
| **Motilitet** | Ja (flagel) | Nej (transporteres) |

### Spermatogenese i detaljer
```
Spermatogonium (2n) → Mitose → Primær spermatocyt → Meiose I → 2 sekundære spermatocytter → Meiose II → 4 spermatider → Spermiogenese → 4 modne spermatozoer
```

**Spermiogenese:** 
1. **Kernens kondensering** – DNA pakkes tæt (protaminer i stedet for histoner)
2. **Akrosom-dannelse** – Golgi → enzym-filled vesikel (til at penetrere ægget)
3. **Flagel-dannelse** – centriol → microtubuli (9+2 arrangement)
4. **Mitochondriel** spiring – energiproduktion til motilitet
5. **Cytoplasmatisk** rest fjernes → Sertoli-celler fagocyterer

### Oogenese i detaljer
**Prænatal fase:**
```
Oogonium (2n) → Mitose (op til uge 20) → Primær oocyt → Meiose I (starter, pauser ved profase I (diploten)) → Hvile i årtier
```

**Pubertet (cyklisk):**
```
Hver måned: 1 primær oocyt → fuldfører Meiose I → Sekundær oocyt (haploid) + 1. pollegeme → Meiose II (pauser ved metafase II)
```

**Ovulation:** Sekundær oocyt (metafase II) frigives
**Fertilization:** Trigger → Meiose II fuldføres → modent æg + 2. pollegeme

### Cytoplasmefordeling (asymmetrisk)
- **Målet:** Alt cytoplasma + næringsressourcer til ét stort æg (zygotens overlevelse)
- **Polar bodies** degenereres (ingen funktion)
- I spermatogenese er fordelingen symmetrisk (4 lige store sædceller)

### Regulering

| Hormon | Spermatogenese | Oogenese |
|--------|---------------|----------|
| **FSH** | Stimulerer Sertoli-celler → næring til spermatocytter | Stimulerer follikelvækst + østradiol |
| **LH** | Stimulerer Leydig-celler → testosteron | Trigger ovulation + corpus luteum |
| **Testosteron** | Nødvendig for spermatogenese | - |
| **Østradiol** | - | Follikelvækst, feedback |
| **Inhibin** | Negativ feedback (Sertoli → ↓ FSH) | Negativ feedback (granulosaceller → ↓ FSH) |

### Klinisk relevans
- **Azoospermi** → ingen sæd i ejakulat (obstruktion, hormonel, genetisk)
- **PCOS** → anovulation (forstyrret oogenese) → infertilitet
- **Alder (kvinde)** → ↓ kvalitet + ↑ aneuploidi (lang profase I-hvile)
- **Kemoterapi** → påvirker spermatogenese (hurtigt delende celler) > oogenese (langsom)
