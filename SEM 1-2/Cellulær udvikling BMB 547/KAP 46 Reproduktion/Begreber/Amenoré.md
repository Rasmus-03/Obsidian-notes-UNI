# Amenoré

> [!INFO] **Definition**
> **Amenoré** er fravær af menstruation. Opdeles i **primær** (menstruation er aldrig indtrådt ved 16-års alderen) og **sekundær** (menstruation ophører i ≥3 måneder hos en kvinde, der tidligere har haft regelmæssig menstruation).

> **Kilde:** Campbell Biology (12. udgave) – Kapitel 45, s. 1063-1065

---

## Primær amenoré

| Årsag | Forklaring |
|-------|-----------|
| **Turner syndrom (45,XO)** | Gonadedysgenese → ingen østrogenproduktion → manglende pubertet |
| **Hypothalamus-hypofyse-svigt** | Nedsat GnRH → nedsat FSH/LH → manglende ovarieaktivering |
| **Anatomiske defekter** | Imperforat hymen, vaginal atresi, Müllerian agenesi (MRKH-syndrom) |
| **Forsinket pubertet** | Normal variant (konstitutionel forsinkelse) |
| **Kryptomenoré** | Menstruationsblod kan ikke forlade livmoderen → smerter |

## Sekundær amenoré

| Årsag | Forekomst |
|-------|-----------|
| **Graviditet** | Hyppigste årsag → altid udelukkes først! |
| **Amning (laktationsamenoré)** | Prolaktin → hæmmer GnRH |
| **Stress** | CRH → hæmmer GnRH |
| **Lav kropsvægt/spiseforstyrrelser** | Leptin-nedsættelse → hæmmet GnRH |
| **PCOS** | Hyppigste endokrine årsag (~30%) |
| **Hypothyroidisme** | TRH → prolaktinstigning → hæmmet GnRH |
| **Hyperprolaktinæmi** | Prolaktin hæmmer GnRH direkte |
| **Hypofysetumor** | Prolaktinom → hyperprolaktinæmi |
| **Tidlig menopause (POI)** | Ovariesvigt før 40 år |
| **Ashermans syndrom** | Arvæv i uterus efter abrasio |

---

## Diagnostisk algoritme

1. **Udeluk graviditet** (hCG-test)
2. **FSH + LH**: Højt FSH/LH → ovariesvigt; lavt FSH/LH → hypofyse/hypothalamus-problem
3. **Prolaktin**: Højt → hyperprolaktinæmi
4. **TSH**: Højt → hypothyroidisme
5. **Progesteron-challenge test**: Gives progesteron → hvis blødning → østrogen-tilstedeværelse

## Behandling
- Afhænger af **underliggende årsag**
- Hormonel substitution (østrogen + progesteron) ved ovariesvigt
- Dopamin-agonister ved hyperprolaktinæmi
- Vægtøgning ved spiseforstyrrelser
