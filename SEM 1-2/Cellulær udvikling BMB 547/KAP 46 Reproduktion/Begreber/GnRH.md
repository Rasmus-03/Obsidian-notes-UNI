# GnRH (Gonadotropin-Releasing Hormone)

> [!INFO] **Definition**
> **GnRH (Gonadotropin-Releasing Hormone)** er et **decapeptid** (10 aminosyrer) produceret i **hypothalamus**, der stimulerer den forreste hypofyse (adenohypofysen) til at frigive **FSH** og **LH**.

> **Kilde:** Campbell Biology (12. udgave) – Kapitel 45, s. 1042-1045; [[Menstruationscyklus]] • [[Kønshormoner]]

---

## Produktion og transport
- **Producert af**: Neuroner i **arcuatus-kernen** i hypothalamus
- **Transport**: Via **hypofyse-portal-systemet** (portalvene) direkte til adenohypofysen
- **Halveringstid**: ~2-4 minutter — konstant nedbrydning → pulsatil sekretion afgørende

## Pulsatil sekretion
- **Kræves**: GnRH skal frigives **pulserende** — ikke konstant!
- **Frekvens**:
  - **Høj frekvens** (~1 puls/time) → favoriserer **LH** sekretion
  - **Lav frekvens** (~1 puls/2-3 timer) → favoriserer **FSH** sekretion
- **Kontinuerlig GnRH** → nedregulering af GnRH-receptorer → **hæmning** af FSH/LH
- **Klinisk anvendelse**: GnRH-agonister (f.eks. leuprolid) → kontinuerlig stimulering → nedregulering → kemisk kastration (prostatacancer, endometriose)

## Regulering

| Stimulerer GnRH | Hæmmer GnRH |
|:----------------|:------------|
| Lavt østrogen (negativ feedback) | Højt østrogen + progesteron |
| Kisspeptin (KISS1) | **Kritisk**: Højt østrogen sent i follikulær fase *stimulerer* GnRH (positiv feedback → LH-surge) |
| Norepinefrin | Dopamin (hos nogle arter) |
| Leptin (fedtvæv → signal om energitilstand) | Stress (kortisol hæmmer GnRH) |
| Lavt inhibin | Højt inhibin → mindre FSH via hypofyse |

## GnRH → FSH/LH → gonader (HPG-aksen)

```
Hypothalamus:   [GnRH] ──(portalvene)──→
                     ↓
Adenohypofyse:  [FSH + LH] ──(blod)──→
                     ↓
Gonader:        [Østrogen, Progesteron, Testosteron, Inhibin]
                     ↓
              Negativ/positiv feedback til hypothalamus + hypofyse
```

## Eksamenstræning
- **Spørgsmål**: Hvorfor kan kontinuerlig GnRH-behandling hæmme fertiliteten?
- **Svar**: Konstant GnHR nedregulerer GnRH-receptorer i hypofysen → FSH og LH falder → gonaderne stoppes (kemisk kastration)
- **Spørgsmål**: Hvordan giver lav frekvens GnRH mere FSH end LH?
- **Svar**: FSH-β-genet kræver mindre stærkt signal end LH-β-genet → lavere pulsintensitet favoriserer FSH-transkription
