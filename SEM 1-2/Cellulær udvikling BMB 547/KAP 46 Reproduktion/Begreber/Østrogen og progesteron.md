# Østrogen og progesteron

> [!tip] **For en 5-årig:**  
> Østrogen og progesteron er som dirigenter for kvindens hormonorkester. Østrogen siger "lad os gøre klar til fest" (opbygning af livmoderslimhinde), og progesteron siger "lad os holde festen i gang" (vedligeholder slimhinden til graviditet).

## Definition
Østrogen og progesteron er de primære **kvindelige kønshormoner** (steroidhormoner). De regulerer menstruationscyklussen, graviditet og sekundære kønskarakteristika.

## Produktion og regulering

### HPG-aksen
1. **GnRH** (hypothalamus) → **FSH + LH** (hypofyse forlap) → østrogen/progesteron (ovarier)
2. **Negativ feedback**: højt østrogen + progesteron → hæmmer GnRH/FSH/LH
3. **Positiv feedback**: meget højt østrogen (før ovulation) → LH-surge → ovulation

### Østrogen
| Aspekt | Detalje |
|--------|---------|
| Hovedtyper | 17β-østradiol (E2), østron (E1), østriol (E3) |
| Kilde | Granulosaceller i ovariet (Follikel-fasen), placenta (graviditet) |
| Mål | Livmoder, bryst, knogle, hjerne, lever |

### Progesteron
| Aspekt | Detalje |
|--------|---------|
| Kilde | Corpus luteum (Luteal-fasen), placenta (graviditet) |
| Mål | Livmoder, bryst, hjerne |
| Funktion | Vedligeholder endometriet, hæmmer uterus-kontraktioner |

## Funktioner

### Østrogen
- **Reproduktion**: endometrievækst (proliferativ fase), follikelmodning, cervikal slim (tyndt)
- **Sekundære kønskarakteristika**: brystudvikling, fedtfordeling, bækkenform
- **Knogle**: øger knogletæthed (hæmmer osteoklaster)
- **Metabolisk**: øger HDL, nedsætter LDL

### Progesteron
- **Reproduktion**: modner endometriet (sekretorisk fase), fortykker cervikalslim, vedligeholder graviditet
- **Bryst**: udvikler mælkekirtler
- **Termoregulering**: hæver basal kropstemperatur (0.3-0.5°C) → bruges til ovulationstest
- **Hæmmer uterus-kontraktioner**: forhindrer for tidlig fødsel

## Cyklus → Graviditet
| Fase | Dag | Dominant hormon | Hændelse |
|------|-----|----------------|----------|
| Follikulær | 1-13 | FSH → Østrogen | Follikelmodning, endometrieopbygning |
| Ovulation | 14 | LH | Æggeløsning |
| Luteal | 15-28 | Progesteron | Endometrie-modning, evt. implantation |
| Menstruation | 1-5 | Begge lave | Slimhinde afstødes (hvis ej gravid) |

## Klinisk relevans
- **P-piller**: syntetisk østrogen + progesteron → negativ feedback → hæmmer FSH/LH → anovulation
- **Hormonbehandling (HRT)**: efter menopause → reducerer osteoporose, hedeture
- **Østrogen-afhængig kræft**: brystkræft (ER-positive) → anti-østrogen-behandling (Tamoxifen)
- **Progesteron-mangel**: tidlig abort (manglende vedligehold af endometriet)

## Eksamenstræning
- Spørgsmålstype: "Redegør for østrogen og progesterons funktioner" → opbygning vs vedligehold
- Spørgsmålstype: "Forklar HPG-aksens regulering" → GnRH → FSH/LH → østrogen/progesteron → feedback
- Spørgsmålstype: "Hvad sker ved manglende progesteron?" → endometriet kan ikke vedligeholdes → abort
