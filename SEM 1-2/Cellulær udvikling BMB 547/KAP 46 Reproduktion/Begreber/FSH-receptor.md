# FSH-receptor

> [!INFO] **Definition**
> **FSH-receptoren (FSHR)** er en G-proteinkoblet receptor (GPCR) på overfladen af **Sertoli-celler** (mand) og **granulosaceller** (kvinde). Den binder **FSH** (follikelstimulerende hormon) og aktiverer **cAMP-signalvejen**.

> **Kilde:** Campbell Biology (12. udgave) – Kapitel 45, s. 1044; [[Sertoli-celler]] • [[GnRH]] • [[Inhibin]]

---

## Struktur
- **GPCR type**: Klasse A (rhodopsin-lignende)
- **Struktur**: 7 transmembrane domæner, stor ekstracellulær N-terminal (binder FSH)
- **Gen**: FSHR på kromosom 2p21
- **Tilhører**: Glykoproteinhormon-receptor familien (sammen med LH-R, TSH-R)

## Signalvej

```
FSH → FSHR → Gαₛ → Adenylylcyclase → ATP → cAMP → PKA → → → Transkription
```

1. FSH binder til ekstracellulært domæne
2. Konformationsændring → Gαₛ aktiveres
3. Adenylylcyclase → cAMP stiger
4. PKA (protein kinase A) phosphorylerer målproteiner
5. **CREB** (transkriptionsfaktor) aktiveres → genekspression

## Effekter

| Væv | Effekt |
|:----|:-------|
| **Granulosaceller** (kvinde) | Stimulerer follikelvækst, østrogenproduktion (aromatase), inhibin B |
| **Sertoli-celler** (mand) | ABP-produktion, inhibin B, næring til sædceller |
| **Begge** | Celledeling, differentiering, overlevelse |

## Rolle i menstruationscyklus
- **Follikulær fase**: FSH binder FSHR på granulosaceller → folliklen vokser → østrogen stiger
- **Dominant follikel**: FSH-receptorer udtrykkes stærkere → folliklen bliver mere følsom → "vinderen"
- **Luteal fase**: FSHR udtrykkes fortsat → men lav FSH (pga. inhibin + progesteron) → ingen ny vækst

## Rolle i spermatogenese
- FSHR på Sertoli-celler → ABP + næring til sædceller
- Nødvendig for **start** af spermatogenese (pubertet)
- Mutationer i FSHR → **infertilitet** (ovarieresistent syndrom)

## Genetiske variationer
- **FSHR-polymorfier** (f.eks. Asn680Ser): påvirker respons på FSH → vigtigt ved IVF-behandling (bestemmer FSH-dosis)
- **Inaktiverende mutationer**: Hypergonadotrop hypogonadisme (højt FSH, men ingen effekt)

## Eksamenstræning
- **Spørgsmål**: Hvorfor er cAMP-signalvejen vigtig for FSH-receptoren?
- **Svar**: FSH → FSHR → Gαₛ → adenylylcyclase → cAMP → PKA → CREB → genaktivering. Uden cAMP-kaskaden ville signalet ikke forstærkes nok til at påvirke transkription
- **Spørgsmål**: Hvad sker der ved inaktiverende FSHR-mutation hos kvinder?
- **Svar**: Ovarierne reagerer ikke på FSH → follikler vokser ikke → amenoré + infertilitet → højt FSH i blodet (feedback)
