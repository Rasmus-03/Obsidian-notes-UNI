# Kapitel 41 – Hormoner og endokrine system

> [!tip] **For en 5-årig:**  
> Kroppens endokrine system er som et netværk af chefer (kirtler) der sender beskeder (hormoner) gennem blodbanen til medarbejdere (målceller). Beskederne siger f.eks. "vokse", "forbrænd mere", "lav et æg" eller "rolig nu".

## Hormonklassifikation
| Type | Opløselighed | Transport | Receptor | Respons |
|------|-------------|-----------|----------|---------|
| **Peptid** | Vand | Fri i blod | Membran | Hurtig (sek-min) |
| **Steroid** | Fedt | Bindes til protein | Intracellulær | Langsom (timer-dage) |
| **Amin** | Varierer | Varierer | Varierer | Varierer |

## Vigtigste endokrine akser

### HPA-aksen (Hypothalamus-Hypofyse-Binyre)
Hypothalamus → **CRH** → Hypofyse → **ACTH** → Binyrebark → **Cortisol**
- Stress-respons, anti-inflammatorisk, blodsukker ↑
- Negativ feedback: cortisol → hæmmer CRH og ACTH

### HPT-aksen (Hypothalamus-Hypofyse-Thyroidea)
Hypothalamus → **TRH** → Hypofyse → **TSH** → Thyroidea → **T₃/T₄**
- Basalstofskifte, vækst, udvikling
- Negativ feedback: T₃/T₄ → hæmmer TRH og TSH

### HPG-aksen (Hypothalamus-Hypofyse-Gonader)
Hypothalamus → **GnRH** → Hypofyse → **FSH/LH** → Gonader → **Testosteron/Østrogen/Progesteron**
- Reproduktion, gametogenese, menstruationscyklus

## Endokrine kirtler i overblik
| Kirtel | Hormoner | Hovedfunktion |
|--------|----------|--------------|
| Hypothalamus | TRH, CRH, GnRH, GHIH, GHRH | Regulerer hypofysen |
| Hypofyse (forlap) | TSH, ACTH, FSH, LH, GH, PRL | Central endokrin chef |
| Hypofyse (baglap) | ADH, oxytocin | Vandbalance, fødsel |
| Thyroidea | T₃, T₄, calcitonin | Stofskifte, Ca²⁺ |
| Parathyroidea | PTH | Ca²⁺-balance |
| Binyrebark | Cortisol, aldosteron, androgener | Stress, salt, kønshormoner |
| Binyremarv | Adrenalin, noradrenalin | Kamp/flugt |
| Bugspytkirtel | Insulin, glukagon | Blodsukker |
| Gonader testis | Testosteron | Sæd, maskulinisering |
| Gonader ovarier | Østrogen, progesteron | Cyklus, graviditet |
