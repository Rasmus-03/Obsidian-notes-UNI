# Cortisol

> [!INFO] **Definition**
> **Cortisol** er et steroidhormon (glukokortikoid) produceret i **binyrebarken** (zona fasciculata). Det er det primære stresshormon og spiller en central rolle i metabolismeregulering, anti-inflammatorisk respons og stress-tilpasning.

> **Kilde:** Campbell Biology (12. udgave) – Kapitel 41, s. 966-967; [[HPA-aksen]]

---

## Produktion og regulering

| Aspekt | Beskrivelse |
|--------|-------------|
| **Produktion** | Binyrebarken (zona fasciculata) |
| **Stimuleres af** | ACTH fra adenohypofysen |
| **Hæmmes af** | Negativ feedback: cortisol → hæmmer CRH og ACTH |
| **Type** | Steroidhormon, fedtopløselig |
| **Transport** | Binder til CBG (cortisol-bindende globulin) i blodet |
| **Receptor** | Intracellulær receptor (glukokortikoid-receptor, GR) |

## Fysiologiske effekter

| Effekt | Beskrivelse |
|--------|-------------|
| **Blodsukker** | ↑ Glukoneogenese (lever), ↑ blodsukker |
| **Proteinstofskifte** | ↑ Proteinnedbrydning (muskel, hud, knogle) |
| **Fedtstofskifte** | ↑ Lipolyse, omfordeling af fedt (central fedtlagring) |
| **Immunforsvar** | ↓ Inflammation, ↓ immunceller (anti-inflammatorisk) |
| **Knogler** | ↓ Knogledannelse, ↑ knogleresorption (osteoporose) |
| **Blodtryk** | ↑ Blodtryk (øger respons af adrenalin og angiotensin II) |
| **Hjerne** | ↑ Årvågenhed, påvirker humør |

## HPA-aksen

```
Hypothalamus → CRH → Adenohypofyse → ACTH → Binyrebark → Cortisol
```

- **Stress:** Fysisk/psykisk stress aktiverer hypothalamus → CRH → ACTH → cortisol
- **Negativ feedback:** Cortisol hæmmer både CRH (hypothalamus) og ACTH (hypofyse)

## Klinisk relevans

| Tilstand | Mekanisme |
|----------|-----------|
| **Cushings syndrom** | For meget cortisol (tumor i hypofyse/binyre eller steroidbehandling) |
| **Addisons sygdom** | For lidt cortisol (binyrebark-insufficiens) |
| **Steroidbehandling** | Langvarig brug → binyrebark-suppression → risiko ved seponering |
