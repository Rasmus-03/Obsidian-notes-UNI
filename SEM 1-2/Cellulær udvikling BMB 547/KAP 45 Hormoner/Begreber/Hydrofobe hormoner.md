# Hydrofobe Hormoner (Lipofile Hormoner)

> [!INFO] **Definition**
> **Hydrofobe (fedtopløselige) hormoner** kan passere cellemembranen og binder til **intracellulære receptorer**. De inkluderer steroidhormoner og thyroideahormoner (T₃/T₄) og giver langsom, langvarig respons via genregulering.

> **Kilde:** Campbell Biology (12. udgave) – Kapitel 41, s. 955-956; [[Lipofile vs lipofobe hormoner]]

---

## Karakteristika
| Egenskab | Beskrivelse |
|----------|-------------|
| **Opløselighed** | Fedtopløselige (lipofile) |
| **Transport** | Kræver bærerprotein (SHBG, CBG, TBG) |
| **Receptor** | Intracellulær (cytoplasmatisk eller nukleær) |
| **Signalering** | Genregulering (transkriptionsfaktor) |
| **Respons** | Langsom (timer-dage) |
| **Halveringstid** | Lang (timer-dage) |

## Eksempler
- **Cortisol** → CBG
- **Testosteron/Østradiol** → SHBG
- **T₃/T₄** → TBG
