# HPA-aksen (Hypothalamus-Hypofyse-Binyre-aksen)

> [!INFO] **Definition**
> **HPA-aksen** (hypothalamus-pituitary-adrenal axis) er et neuroendokrint feedback-system, der regulerer stress-respons, metabolisme, immunfunktion og inflammation. Den består af hypothalamus → CRH → adenohypofyse → ACTH → binyrebark → cortisol.

> **Kilde:** Campbell Biology (12. udgave) – Kapitel 41, s. 966-967; [[Kapitel 41 – Chemical Signals in Animals]]

---

## Kaskaden

```
Stress (fysisk/psykisk)
       ↓
  ┌─── Hypothalamus ────┐
  │   (paraventrikulær)  │
  │       CRH ↓         │
  │   Adenohypofyse      │
  │       ACTH ↓         │
  │   Binyrebark         │
  │  (zona fasciculata)  │
  │       Cortisol       │
  └──────────────────────┘
       ↓
   Effekter: ↑ Blodsukker, ↓ Immunforsvar, ↑ Protein-nedbrydning
```

## Feedback-regulering

- **Negativ feedback:** Cortisol hæmmer frigivelse af CRH (hypothalamus) og ACTH (hypofyse)
- **Ultrakort feedback:** ACTH kan hæmme CRH direkte
- **Døgnrytme:** HPA-aksen er mest aktiv om morgenen (cortisol-stigning ved opvågning)

## Funktioner

| Funktion | Beskrivelse |
|----------|-------------|
| **Stress-respons** | Forbereder kroppen på trusler (fysiske/psykiske) |
| **Metabolisme** | Øger blodsukker (glukoneogenese) |
| **Immunsystem** | Anti-inflammatorisk, hæmmer immunceller |
| **Kredsløb** | Øger blodtryk og kardiovaskulær tonus |

## Klinisk relevans

| Tilstand | Mekanisme |
|----------|-----------|
| **Cushings syndrom** | For meget cortisol (tumor eller steroidbehandling) |
| **Addisons sygdom** | For lidt cortisol (binyrebark-insufficiens) |
| **Depression** | Øget HPA-akse aktivitet → højt cortisol |
| **Posttraumatisk stress** | Forstyrret HPA-akse regulering |
