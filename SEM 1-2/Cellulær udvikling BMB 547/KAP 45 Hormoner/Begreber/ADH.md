# ADH (Antidiuretisk Hormon / Vasopressin)

> [!INFO] **Definition**
> **ADH** (antidiuretisk hormon, også kaldet vasopressin) er et peptidhormon (9 aminosyrer) produceret i **hypothalamus** og frigivet fra **neurohypofysen**. Det regulerer kroppens væskebalance ved at øge vandreabsorptionen i nyrerne.

> **Kilde:** Campbell Biology (12. udgave) – Kapitel 44, s. 1046-1048; [[Neurohypofysen]]

---

## Produktion og regulering

| Aspekt | Beskrivelse |
|--------|-------------|
| **Produktion** | Hypothalamus (supraoptisk kerne) |
| **Frigivelse** | Neurohypofysen (baglap) |
| **Stimuleres af** | Høj plasma-osmolaritet (dehydrering), lavt blodvolumen, stress |
| **Hæmmes af** | Lav plasma-osmolaritet, alkohol |
| **Type** | Peptidhormon (9 aminosyrer) |
| **Receptor** | V₁ (GPCR, blodkar) og V₂ (GPCR, nyrer) |

## Funktioner

| Funktion | Beskrivelse |
|----------|-------------|
| **Nyrer (V₂)** | Øger indsættelse af aquaporin-2 i samlekanaler → ↑ vandreabsorption |
| **Blodkar (V₁)** | Vasokonstriktion → ↑ blodtryk |
| **Hjerne** | Involveret i social adfærd, parbinding (hos nogle arter) |

## Signalering (nyrer)

ADH → V₂-receptor → G-protein → Adenylylcyclase → cAMP ↑ → PKA → fosforylering → aquaporin-2 vesikler fusionerer med membranen → vand kan reabsorberes

## Klinisk relevans

| Tilstand | Mekanisme |
|----------|-----------|
| **Diabetes insipidus** | Mangel på ADH (central) eller manglende respons (nefrogen) → store mængder fortyndet urin |
| **SIADH** (Syndrome of Inappropriate ADH) | For meget ADH → vandretention → hyponatriæmi |
| **Desmopressin** | Syntetisk ADH-analog bruges mod sengevædning og diabetes insipidus |
