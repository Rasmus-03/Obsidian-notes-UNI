# ACTH (Adrenokortikotropt hormon)

> [!INFO] **Definition**
> **ACTH** (adrenokortikotropt hormon, corticotropin) er et peptidhormon produceret i **adenohypofysen**, der stimulerer binyrebarken (zona fasciculata) til at producere og frigive **cortisol**. Det spiller en central rolle i **HPA-aksen** (stress-respons).

> **Kilde:** Campbell Biology (12. udgave) – Kapitel 41, s. 958, 966; [[HPA-aksen]]

---

## Produktion og regulering

| Aspekt | Beskrivelse |
|--------|-------------|
| **Produktion** | Adenohypofyse (corticotrope celler) |
| **Stimuleres af** | CRH fra hypothalamus |
| **Hæmmes af** | Cortisol (negativ feedback), somatostatin |
| **Type** | Peptidhormon (39 aminosyrer) |
| **Receptor** | MC2R (GPCR) på binyrebarken |
| **Døgnrytme** | Højst om morgenen, lavest om aftenen |

## Funktion

- **ACTH** → binyrebark → **zoner:**
  - Zona fasciculata: **Cortisol** (glukokortikoid)
  - Zona reticularis: **DHEA** (androgen)
  - Zona glomerulosa: **Aldosteron** (påvirkes primært af RAAS, ikke ACTH)

## Signalering

- ACTH → MC2R (GPCR) → G-protein → Adenylylcyclase → cAMP ↑ → PKA → aktivering af steroidogene enzymer (CYP11A1, CYP17A1, CYP21A2)

## Klinisk relevans

- **Cushings sygdom:** Hypofysetumor → for meget ACTH → for meget cortisol
- **Sekundær binyrebark-insufficiens:** Hypofysesygdom → for lidt ACTH → for lidt cortisol
- **ACTH-stimulationstest (Synacthen-test):** Bruges til at teste binyrebarkens funktion
