# Hypothalamus-hypofyse-aksen

> [!tip] **Hovedprincippet:** Hypothalamus styrer hypofysen, som styrer de fleste endokrine kirtler – en hierarkisk regulering med **negativ feedback**.

## Anatomisk opsætning
```
Hypothalamus (releasing/inhibiting hormoner)
    │
    ▼
Hypofysen
    ├── Adenohypofysen (forlap) → TSH, ACTH, FSH, LH, GH, prolactin
    └── Neurohypofysen (baglap) → ADH, oxytocin (frigives fra hypothalamus)
            │
            ▼
    Målorganer (thyroidea, binyrer, gonader, lever, mælkekirtler)
```

## Hypothalamiske hormoner

| Hormon | Effekt på adenohypofysen |
|--------|--------------------------|
| **TRH** (thyrotropin-releasing) | Stimulerer TSH |
| **CRH** (corticotropin-releasing) | Stimulerer ACTH |
| **GnRH** (gonadotropin-releasing) | Stimulerer FSH + LH |
| **GHRH** (growth hormone-releasing) | Stimulerer GH |
| **Somatostatin** (SS) | Hæmmer GH + TSH |
| **Dopamin** (PIF) | Hæmmer Prolactin |

> [!example]+ **Eksempel: HPT-aksen**
> TRH (hypothalamus) → TSH (hypofyse) → T₃/T₄ (thyroidea)
> → T₃/T₄ hæmmer TRH og TSH via negativ feedback
>
> *Princippet: Output fra den sidste kirtel hæmmer de øvre led*
