# HPG-aksen (Hypothalamus-Hypofyse-Gonade-aksen)

## Definition
HPG-aksen er det hormonelle feedback-system, der regulerer konshormonproduktion og konscelleudvikling hos begge kon.

## Komponenter
- **Hypothalamus**: udskiller GnRH (gonadotropin releasing hormone) pulserende
- **Adenohypofyse**: udskiller LH (luteiniserende hormon) og FSH (follikelstimulerende hormon) stimuleret af GnRH
- **Gonader (testikler/ovarier)**: producerer konshormoner (testosteron, ostrogen, progesteron) og inhibin

## Regulering
- GnRH stimulerer LH- og FSH-frigivelse (pulsfrekvens bestemmer LH/FSH-ratio)
- LH stimulerer: Leydig-celler (testosteron hos maend), ovulationsudlosning + corpus luteum (kvinder)
- FSH stimulerer: Sertoli-celler (spermatogenese hos maend), follikelvaekst (kvinder)
- Negativ feedback: testosteron/ostrogen hammer GnRH og LH/FSH
- Inhibin hammer specifikt FSH (uden at pavirke LH)

## Hypofysetumor (svarer til Opgave 2c)
En tumor i hypofysen kan pavirke baade TRH- og GnRH-producerende celler. For at teste for dette hos en biologisk mand males:
1. **GnRH**: forventes **oget** eller **normalt** (hvis tumor komprimerer GnRH-celler, kan det vaere lavt)
2. **Inhibin**: forventes **lavere** (da FSH er pavirket → nedsat spermatogenese → mindre Sertoli-celle-aktivering)
3. **Testosteron**: forventes **lavere** (da LH er pavirket → nedsat Leydig-celle-stimulering)

Diagnostisk monster: lavt testosteron + lavt LH/FSH = hypogonadotrop hypogonadisme (hypofyseproblem, ikke gonadeproblem)

## Eksamenstraening
- Sporgsmaalstype (Opgave 2c): "Redegor for hvordan man ud fra test af GnRH, inhibin og testosteron kan teste for hypofysetumor"
- Rationale: Hypofysetumor pavirker LH/FSH-produktion → testosteron falder (LH pavirket), inhibin falder (FSH pavirket), GnRH kan vaere normal/oget/lavere afhaengig af tumorens type
