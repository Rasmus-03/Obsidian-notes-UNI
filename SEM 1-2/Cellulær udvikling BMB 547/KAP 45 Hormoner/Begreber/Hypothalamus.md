# Hypothalamus

> [!INFO] **Definition**
> **Hypothalamus** er en region i mellemhjernen (diencephalon), der fungerer som det overordnede kontrolcenter for det endokrine system. Den modtager input fra nervesystemet og omdanner det til hormonelle signaler, der styrer hypofysen.

> **Kilde:** Campbell Biology (12. udgave) – Kapitel 41, s. 957-960; [[Kapitel 41 – Chemical Signals in Animals]]

---

## Funktioner

| Funktion | Beskrivelse |
|----------|-------------|
| **Endokrin kontrol** | Producerer releasing/inhibiting hormoner → adenohypofyse |
| **Neuroendokrin kontrol** | Producerer ADH og oxytocin → neurohypofyse |
| **Autonom regulering** | Styrer sympaticus/parasympaticus (blodtryk, puls, fordøjelse) |
| **Homeostase** | Kropstemperatur, tørst, sult, døgnrytme |
| **Følelser** | Aggression, frygt, seksuel adfærd |

## Hypothalamus' hormoner

| Hormon | Mål | Effekt |
|--------|-----|--------|
| **TRH** (Thyrotropin-Releasing Hormone) | Adenohypofyse → TSH | Stimulerer skjoldbruskkirtlen |
| **CRH** (Corticotropin-Releasing Hormone) | Adenohypofyse → ACTH | Stimulerer binyrebarken |
| **GnRH** (Gonadotropin-Releasing Hormone) | Adenohypofyse → FSH/LH | Stimulerer gonaderne |
| **GHRH** (Growth Hormone-Releasing Hormone) | Adenohypofyse → GH | Stimulerer vækst |
| **Somatostatin** | Adenohypofyse → GH (hæmmer) | Hæmmer væksthormon |
| **Dopamin (PIH)** | Adenohypofyse → Prolactin (hæmmer) | Hæmmer mælkeproduktion |
| **ADH** (Vasopressin) | Neurohypofyse → nyrer | Vandreabsorption |
| **Oxytocin** | Neurohypofyse → livmoder/mælk | Veer, mælke-nedløb |
