# Development — Fra Fertilization til Organogenese

> **Kerne-pathway:** Den embryonale udvikling følger en konserveret sekvens: **Fertilization → Cleavage → Blastula → Gastrulation → Neurulation → Organogenese**.

---

## 📋 Overblik — Udviklingens stadier

| Stadium | Tid (menneske) | Nøglehændelse |
|---------|:--------------:|---------------|
| **Fertilization** | 0 timer | Sperm + æg → zygote |
| **Cleavage** | 0-4 dage | Celledelinger uden vækst → morula → blastocyst |
| **Implantation** | Dag 5-7 | Blastocyst implanterer i endometriet |
| **Gastrulation** | Uge 3 | Tre kimlag dannes (ekto-, meso-, endoderm) |
| **Neurulation** | Uge 3-4 | Neuralrøret dannes → CNS |
| **Organogenese** | Uge 4-8 | Organer dannes (kritisk periode!) |

---

## 🥚 Fra zygote til blastocyst

**Cleavage — hurtige celledelinger:**
```
Zygote (1 celle) → 2 → 4 → 8 → 16 → Morula (solid kugle)
    → Blastocyst (hul kugle):
        ┌── Trophoblast (→ placenta)
        └── Indre cellemasse (→ embryonet)
```

**Implantation:**
```
Blastocyst → zona pellucida opløses → trophoblast fæstner til endometriet
    → Syncytiotrophoblast invaderer → hCG produceres → corpus luteum reddes
```

## 🔬 Gastrulation — dannelse af kimlag

> [!INFO] **Eksamensspørgsmål: "Forklar gastrulation og hvad de tre kimlag giver ophav til"**

**Processen:**
```
Epiblast (fra indre cellemasse) → celler migrerer gennem primitivstriben
    ↓
    ├── Ektoderm (ydre lag): CNS, PNS, epidermis, sanseorganer
    ├── Mesoderm (midterlag): muskler, knogler, hjerte, nyrer, blod
    └── Endoderm (indre lag): tarmepitel, lunger, lever, pancreas
```

**Notochord — mesoderm struktur:**
- Dannet fra mesoderm (processus chordae)
- Inducerer neurulation → danner rygsøjlens forløber
- [[Notochord]] er en evolutiv nøglestruktur (alle chordater har den)

> [!question] Eksamensspørgsmål
> **"Redegør for gastrulation og betydningen af de tre kimlag"**
> *Svar: Gastrulation = massiv cellemigration der danner 3 kimlag via primitivstriben. Ektoderm → nervesystem + hud. Mesoderm → muskler, skelet, hjerte, nyrer. Endoderm → indre organer (tarm, lunger, lever). Kimlagene er fundamentet for al organogenese.*

## 🧠 Neurulation — dannelse af nervesystemet

```
Notochord → inducerer ektoderm → neuralplade → neuralrør
    │
    ├── Neuralrør → CNS (hjerne + rygmarv)
    │
    └── Neuralrørskammen → PNS (ganglier, Schwann-celler, melanocytter)
      ─ Forklaring: neurale folder hæves → mødes → fusioneres → neuralrør
```

**Fremre neuralrør:** lukkes dag 24 → hjerneblærer → prosencephalon, mesencephalon, rhombencephalon
**Nederste neuralrør:** → rygmarv

> [!WARNING] Neuralrørsdefekter (NTD): Spina bifida (manglende lukning) — folinsyre forebygger!

## 🧬 Morfogener og Hox-gener

> [!INFO] **Eksamensspørgsmål: "Forklar Hox-genernes rolle i udvikling"**

**Morfogener — koncentrationsgradienter styrer skæbne:**
```
Høj konc. → Skæbne A
Mellem → Skæbne B
Lav → Skæbne C
```
Eksempel: Sonic hedgehog (Shh) → gradient → forskellige neurale identiteter

**Hox-gener — kropsplanen bestemmes:**
```
Hox-gener → transkriptionsfaktorer → segment-identitet
    ─ Eksempel: Hoxa9 = bryst, Hoxa10 = lænd, Hoxa11 = sakral
```

**Konservering:** Hox-gruppen er stærkt konserveret fra bananflue til menneske! (se [[Homeodomain]])

## 🔄 Celledifferentiering og stamceller

| Celletype | Potentiale | Eksempel |
|-----------|:----------:|----------|
| **Totipotent** | Hele organismen + placenta | Zygote, tidlige blastomerer |
| **Pluripotent** | Alle væv (men ikke placenta) | Indre cellemasse, ES-celler |
| **Multipotent** | Flere celletyper i væv | Hæmatopoietiske stamceller |
| **Unipotent** | Én celletype | Hudstamceller |

**Differentierings-signalering:**
```
Celle → signal (morfogen) → transkriptionsfaktorer → specifik gen-ekspression
    → celle-skæbne (f.eks. neuron vs. muskelcelle)
```
