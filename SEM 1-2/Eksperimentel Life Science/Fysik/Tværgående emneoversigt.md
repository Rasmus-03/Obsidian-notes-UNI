## Sådan bruger du denne note

## Acceleration

| Hvor? | Hvordan? | Note |
|:---|:---|:---|
| **Mekanik** | $v_f = v_i + at$ — konstant acceleration lineær bevægelse | [[01 Mekanik – Kinematik og Newton]] |
| **Mekanik** | $x_f = x_i + v_i t + \frac12 at^2$ — position ved konstant acc. | [[01 Mekanik – Kinematik og Newton]] |
| **Mekanik** | $g = 9.81\,\text{m s}^{-2}$ — tyngdeacceleration (frit fald, kast) | [[01 Mekanik – Kinematik og Newton]] |
| **Cirkelbevægelse** | $a_c = \frac{v^2}{r} = r\omega^2$ — centripetalacceleration mod centrum | [[02 Cirkelbevægelse]] |

**MCQ-mønster:** Acceleration kan være *lineær* (konstant a, kun mekanik) eller *centripetal* (skifter retning, alle emner med cirkelbevægelse). $g$ bruges kun i mekanik.

## Cirkelbevægelse

| Hvor? | Hvordan? | Note |
|:---|:---|:---|
| **Cirkelbevægelse** | $\omega = \frac{v}{r}$ — vinkelhastighed | [[02 Cirkelbevægelse]] |
| **Cirkelbevægelse** | $T = \frac{2\pi}{\omega}$, $f = \frac{1}{T}$ — periode og frekvens | [[02 Cirkelbevægelse]] |
| **Cirkelbevægelse** | $v = \frac{2\pi r}{T}$ — banehastighed fra periode | [[02 Cirkelbevægelse]] |
| **Centrifugering** | $F_g = m\omega^2 r$ — centrifugalkraft, $v_T$ afhænger af $\omega^2 r$ | [[03 Centrifugering]] |
| **Centrifugering** | $v_T \propto \omega^2 r$ — sedimentationshastighed | [[03 Centrifugering]] |
| **Massespektrometri** | $R = \frac{mv}{qB}$ — cirkelbevægelse i magnetfelt | [[06 Massespektrometri]] |
| **Harmoniske svingninger** | $\omega = 2\pi f$ — vinkelfrekvens i svingninger | [[07 Harmoniske svingninger og Orbitrap]] |

**MCQ-mønster:** Cirkelbevægelse er **fundamentet** for centrifugering og massespektrometri. Hvis du ser $\omega$, $r$, $T$, $f$ — tjek om det er mekanisk rotation (02/03) eller magnetisk bøjning (06).

## Periode og frekvens

| Hvor? | Hvordan? | Note |
|:---|:---|:---|
| **Cirkelbevægelse** | $T = \frac{2\pi}{\omega}$, $f = \frac{1}{T}$ | [[02 Cirkelbevægelse]] |
| **Cirkelbevægelse** | $F_c = 4\pi^2 m r f^2$ — centripetalkraft udtrykt ved $f$ | [[02 Cirkelbevægelse]] |
| **Bølger** | $T = \frac{1}{f}$, $v = \frac{\lambda}{T}$ | [[05 Bølger og Optik]] |
| **Harmoniske svingninger** | $T = 2\pi\sqrt{\frac{m}{k}}$, $f = \frac{1}{2\pi}\sqrt{\frac{k}{m}}$ | [[07 Harmoniske svingninger og Orbitrap]] |
| **Harmoniske svingninger** | $f_{OT} = \frac{1}{2\pi}\sqrt{\frac{k_{OT}q}{m}}$ — Orbitrap | [[07 Harmoniske svingninger og Orbitrap]] |

**MCQ-mønster:** $T = 1/f$ er **universel** — gælder både bølger, cirkelbevægelse og svingninger. Forskellen er *hvad* der svinger (mekanisk fjeder vs. elektrostatisk Orbitrap).

## Elektricitet

| Hvor? | Hvordan? | Note |
|:---|:---|:---|
| **Elektriske kræfter** | $F = k\frac{q_1 q_2}{r^2}$ — Coulomb-kraft | [[04 Elektriske kræfter og felter]] |
| **Elektriske kræfter** | $E = \frac{k|q|}{r^2}$ — elektrisk felt fra punktladning | [[04 Elektriske kræfter og felter]] |
| **Elektriske kræfter** | $F = qE$ — kraft på ladning i felt | [[04 Elektriske kræfter og felter]] |
| **Massespektrometri** | $v = \frac{E}{B}$ — hastighedsselektor (E- og B-felt krydses) | [[06 Massespektrometri]] |
| **Massespektrometri** | $\frac{m}{q} = \frac{B' B R}{E}$ — Bainbridge kombinerer E og B | [[06 Massespektrometri]] |

**MCQ-mønster:** Elektriske felter giver kraft $F = qE$; magnetiske felter giver kraft $F = qvB$. I hastighedsselektoren **balancerer** de to: $qE = qvB \Rightarrow v = E/B$.

## Massespektrometri

| Hvor? | Hvordan? | Note |
|:---|:---|:---|
| **Massespektrometri** | $F_B = qvB$ — magnetisk kraft | [[06 Massespektrometri]] |
| **Massespektrometri** | $R = \frac{mv}{qB}$ — radius i magnetfelt | [[06 Massespektrometri]] |
| **Massespektrometri** | $v = \frac{E}{B}$ — hastighedsselektor | [[06 Massespektrometri]] |
| **Massespektrometri** | $\frac{m}{q} = \frac{B' B R}{E}$ — Bainbridge massespektrometer | [[06 Massespektrometri]] |
| **Cirkelbevægelse** | $qvB = \frac{mv^2}{R}$ — magnetkraft = centripetalkraft | [[02 Cirkelbevægelse]] |
| **Elektriske kræfter** | $qE = qvB$ — balance i hastighedsselektor | [[04 Elektriske kræfter og felter]] |

**MCQ-mønster:** Massespektrometri **kombinerer** elektriske kræfter (E-felt) og cirkelbevægelse (B-felt). $R = mv/(qB)$ er nøgleformlen — tungere partikler = større radius.

## Centrifugering

| Hvor? | Hvordan? | Note |
|:---|:---|:---|
| **Centrifugering** | $F_g = \rho V \omega^2 r$ — centrifugalkraft | [[03 Centrifugering]] |
| **Centrifugering** | $B = -\rho_0 V \omega^2 r$ — opdrift | [[03 Centrifugering]] |
| **Centrifugering** | $F_D = -6\pi\eta R v$ — Stokes drag | [[03 Centrifugering]] |
| **Centrifugering** | $v_T = \frac{2}{9}\frac{R^2 \omega^2 r}{\eta}(\rho-\rho_0)$ — terminal sedimentationshastighed | [[03 Centrifugering]] |
| **Cirkelbevægelse** | $F_g = m\omega^2 r$ — centrifugalkraft fra cirkelbevægelse | [[02 Cirkelbevægelse]] |

**MCQ-mønster:** Centrifugering bygger på **cirkelbevægelsens** centrifugalkraft + **væskefriktion** (Stokes drag). Ligevægtsbetingelsen $F_{\text{net}} + F_D = 0$ giver $v_T$.

## Harmoniske svingninger

| Hvor? | Hvordan? | Note |
|:---|:---|:---|
| **Harmoniske svingninger** | $T = 2\pi\sqrt{\frac{m}{k}}$ — periode for fjeder | [[07 Harmoniske svingninger og Orbitrap]] |
| **Harmoniske svingninger** | $f = \frac{1}{2\pi}\sqrt{\frac{k}{m}}$ — frekvens for fjeder | [[07 Harmoniske svingninger og Orbitrap]] |
| **Harmoniske svingninger** | $f_{OT} = \frac{1}{2\pi}\sqrt{\frac{k_{OT} q}{m}}$ — Orbitrap-frekvens | [[07 Harmoniske svingninger og Orbitrap]] |
| **Bølger** | $y = A\cos(kx - \omega t)$ — harmonisk bølge (samme matematik) | [[05 Bølger og Optik]] |
| **Cirkelbevægelse** | $\omega = 2\pi f$, $T = 2\pi/\omega$ — samme $\omega$-$f$-$T$ relation | [[02 Cirkelbevægelse]] |
| **Massespektrometri** | $f_{OT}$ bruges til at bestemme $m/q$ | [[06 Massespektrometri]] |

**MCQ-mønster:** Fjeder: $f \propto 1/\sqrt{m}$. Orbitrap: $f \propto \sqrt{q/m}$. Begge er på formen $f = \frac{1}{2\pi}\sqrt{\text{"konstant"/m}}$. Orbitrap har ekstra $q$ i tælleren.
