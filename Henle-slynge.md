# Henle-slynge

> [!tip] **Hovedprincip:** Henle-slyngen (loop of Henle) er den **U-formede** del af nefronet, der skaber den **osmotiske gradient** i nyremarven. Den er afgørende for evnen til at producere **koncentreret urin**.

## Anatomi

```
Proximal tubulus
    │
    ├── Nedadgående ben (descending limb)
    │   - Tyndt epitel
    │   - Høj vand-permeabilitet (aquaporin-1)
    │   - Ingen salt-permeabilitet
    │
    ├── Hårnål (svinget)
    │
    ├── Opadgående ben (ascending limb)
    │   - Tyndt: permeabel for salt, ikke vand
    │   - Tykt: aktiv salt-transport (Na⁺/K⁺/Cl⁻-symport)
    │
    └── Distal tubulus
```

## Segmenternes egenskaber

| Egenskab | Nedadgående (tyndt) | Opadgående (tyndt) | Opadgående (tykt) |
|----------|--------------------|--------------------|--------------------|
| **Epiteltype** | Fladt (pladeepitel) | Fladt | Kubisk |
| **Vand-permeabilitet** | ✅ Høj | ❌ Ingen | ❌ Ingen |
| **Na⁺-permeabilitet** | ❌ Ingen | ✅ Passiv | ✅ Aktiv transport |
| **Urea-permeabilitet** | ❌ | ✅ (moderat) | ❌ |
| **Transportør** | Aquaporin-1 (vand) | — | NKCC2 (Na⁺/K⁺/Cl⁻-symport) |
| **Mitokondrier** | Få | Få | Mange (kræver ATP) |

## Funktion

| Trin | Beskrivelse |
|------|-------------|
| 1. Filtratet løber **nedad** → vand diffunderer ud → filtratet bliver mere koncentreret (fra 300 → 1200 mOsm) |
| 2. Filtratet løber **opad** → salt diffunderer/pumpes ud → filtratet bliver mere fortyndet (fra 1200 → 100 mOsm) |
| 3. **Modstrømsmultiplikator:** Saltet der pumpes ud i marven opretholder gradienten |

> [!info] **Længden af Henle-slyngen:**
> - **Kortikale nefroner:** Kort Henle-slynge (når til ydre medulla) → mindre koncentreret urin
> - **Juxtamedullære nefroner:** Lang Henle-slynge → dyb gradient → meget koncentreret urin
> - Kænguru-rotte har ekstra lange Henle-slynger → kan overleve uden at drikke vand!
