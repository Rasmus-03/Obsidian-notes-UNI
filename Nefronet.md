# Nefronet

> [!tip] **Hovedprincip:** Nefronet er nyrens **funktionelle enhed**. Hver nyre har ~1 million nefroner, og hvert nefron består af et **nyrelegeme** (filtrering) og en **tubulus** (reabsorption og sekretion).

## Anatomi

```
Nyrelegeme:
  Glomerulus (kapillærnet) + Bowmans kapsel
        │
        ▼ (filtrat)
  Proximal tubulus (PCT)
        │
  Henle-slynges nedadgående ben
        │
  Henle-slynges opadgående ben (tyndt)
        │
  Henle-slynges opadgående ben (tykt)
        │
  Distal tubulus (DCT)
        │
  Samlerør (collecting duct)
        │
        ▼ (urin)
```

## Nefrontyper

| Type | Placering | Henle-slynge | Funktion |
|------|-----------|--------------|----------|
| **Kortikalt nefron** (~85%) | Cortex | Kort, når kun til ydre medulla | Urindannelse |
| **Juxtamedullært nefron** (~15%) | Cortex/Medulla grænse | Lang, når dybt ind i medulla | Skaber osmotisk gradient → koncentreret urin |

## Nefronets segmenter og funktion

| Segment | Hvad sker |
|---------|-----------|
| **Glomerulus** | Filtrerer blod → 180 L/dag filtrat (primærurin) |
| **Proximal tubulus (PCT)** | Reabsorberer ~65% af NaCl, vand, glukose, aminosyrer, HCO₃⁻ |
| **Henle-slynges nedadgående ben** | Vand diffunderer ud → koncentrerer filtratet |
| **Henle-slynges opadgående ben** | Salt transporteres ud → fortynder filtratet |
| **Distal tubulus (DCT)** | Regulerer Ca²⁺, Na⁺, K⁺, pH (via parathyroidea, aldosteron) |
| **Samlerør (collecting duct)** | ADH-reguleret vandreabsorption → endelig urinkoncentration |

## Forskellige transportmekanismer

| Mekanisme | Hvor | Hvad |
|-----------|------|------|
| **Transcellulær transport** | Gennem cellerne | Via kanaler, transportører, aquaporiner |
| **Paracellulær transport** | Mellem cellerne | Passiv diffusion via tight junctions |
| **Transcytose** | Gennem cellerne | Vesikel-medieret transport (sjældent i nefronet) |

> [!warning] **Klinisk:**
> - Hvis nefroner ødelægges (f.eks. diabetisk nefropati, hypertension) → nedsat GFR → nyresvigt
> - Nefroner kan ikke regenereres – man har det antal man fødes med
